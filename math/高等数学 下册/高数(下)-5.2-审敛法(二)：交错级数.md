# 高数(下) 5.2：审敛法（二）—— 交错级数与任意项级数

> **前置知识：** 正项级数审敛法（比较法、比值法、根值法、积分法）。
> **本节核心：** 莱布尼茨判别法，绝对收敛与条件收敛，判断流程。
> **后续衔接：** 绝对收敛是幂级数一致收敛的基础，交错级数与傅里叶级数中 $(-1)^n$ 系数直接相关。

---

## 一、交错级数

各项**正负相间**的级数：

$$\sum_{n=1}^\infty (-1)^{n-1} u_n = u_1 - u_2 + u_3 - u_4 + \cdots \quad (u_n > 0)$$

也可写成 $\sum (-1)^n u_n$，只是第一项符号不同。

---

## 二、莱布尼茨判别法

### 定理

交错级数 $\sum(-1)^{n-1}u_n$（$u_n>0$）满足两个条件时**收敛**：

1. **单调递减：** $u_n \geq u_{n+1}$（从某项起）
2. **趋于零：** $\lim_{n\to\infty} u_n = 0$

### 直觉

一只蚂蚁在数轴上左右跳跃，每步比上一步短且步长趋于零——必然停在某个确定位置。偶数项部分和单调递增有上界，奇数项部分和单调递减有下界，二者夹逼到同一极限。

### 余项估计（交错级数估计定理）

$$\boxed{|r_n| = |S - S_n| \leq u_{n+1}}$$

误差不超过被舍去的第一项。用前 100 项近似的精度？看第 101 项即可。

**实例：** 用交错调和级数估计 $\ln 2$，精确到 $0.01$。

$|r_n| \leq \frac{1}{n+1} \leq 0.01 \Rightarrow n \geq 99$。取前 99 项即可。

> **技巧：** 估计定理给出的上界偏保守但严格保证。用这个上界确定项数不会出错。

**夹逼性质：** 满足莱布尼茨条件时，$S_{2k} \leq S \leq S_{2k+1}$。偶数部分和在极限下方，奇数在上方，每算一项摆动一次，幅度越来越小。

---

## 三、交错级数例题

### 例 1（交错调和级数）

$\displaystyle\sum_{n=1}^\infty \frac{(-1)^{n-1}}{n}$

$u_n = \frac{1}{n}$ 单调递减且趋于零，莱布尼茨两条件满足，**收敛**（和为 $\ln 2$）。

> **技巧：** 调和级数发散，但加上交错符号后收敛——正负抵消的力量不可小觑。

### 例 2（必要条件不满足）

$\displaystyle\sum_{n=1}^\infty \frac{(-1)^{n-1}\cdot n}{2n-1}$

$\lim u_n = \frac{1}{2} \neq 0$。必要条件不满足，无论用什么判别法都**发散**。

> **注意：** 通项不趋于零，直接宣告发散，无需再用莱布尼茨。

### 例 3（$p$ 级数交错版）

$\displaystyle\sum_{n=1}^\infty \frac{(-1)^{n-1}}{\sqrt{n}}$

$u_n = n^{-1/2}$ 单调递减且趋于零 → **收敛**（条件收敛，因为取绝对值后 $\sum \frac{1}{\sqrt{n}}$ 发散）。

### 例 4（需验证单调性）

$\displaystyle\sum_{n=1}^\infty (-1)^{n-1}\frac{n}{n^2+1}$

**趋零：** $\lim \frac{n}{n^2+1} = 0$。

**单调性：** 令 $f(x) = \frac{x}{x^2+1}$，$f'(x) = \frac{1-x^2}{(x^2+1)^2} < 0$（$x > 1$）。$u_n$ 从 $n \geq 2$ 起单调递减。

两条件满足 → **收敛**。

> **技巧：** 单调性不直观时，将 $u_n$ 视为连续函数 $f(x)$，用导数证递减。

### 例 5（莱布尼茨失效）

$\displaystyle\sum_{n=1}^\infty \frac{(-1)^{n-1}}{n + (-1)^{n-1}}$

分母含 $(-1)^{n-1}$，$u_n$ 不单调：$u_1=\frac12$，$u_2=1$，不满足递减。莱布尼茨不适用。

> **注意：** 不是看到 $(-1)^n$ 就能机械套用莱布尼茨——必须验证 $u_n$ 的单调性。

## 四、绝对收敛与条件收敛

### 定义

- **绝对收敛：** $\sum |u_n|$ 收敛
- **条件收敛：** $\sum u_n$ 收敛，但 $\sum |u_n|$ 发散

### 关键定理

$$\boxed{\text{绝对收敛} \;\Rightarrow\; \text{收敛}}$$

绝对值级数收敛意味着正负项的"总量"有限，抵消后只会更小。

**层级关系：**
$$\text{绝对收敛} \subset \text{收敛} \subset \text{所有级数}$$
$$\text{条件收敛} = \text{收敛} \setminus \text{绝对收敛}$$

形象地说：绝对收敛是好学生，怎么折腾都不出问题；条件收敛是走钢丝的人，顺序一乱就摔；发散是根本没出发。

## 五、判断流程图

```
                    任意项级数 Σuₙ
                         │
                    ┌────▼────┐
                    │Σ|uₙ| 收敛?│ ─── 用正项级数审敛法
                    └───┬───┘
             是         │         否
        ┌───────────────┤
        ▼               ▼
   ┌─────────┐    ┌──────────┐
   │  绝对收敛  │    │Σ|uₙ| 发散?│
   │  结束 ✓   │    └────┬─────┘
   └─────────┘    是    │    否（不可能*）
              ┌─────────┤
              ▼
    ┌──────────────────┐
    │ 原级数 Σuₙ 收敛?  │
    │ (莱布尼茨 / 定义) │
    └──────┬───────────┘
   是      │      否
   ▼       │      ▼
┌──────┐   │  ┌──────┐
│条件收敛│   │  │ 发散  │
│结束 ✓ │   │  │结束 ✗ │
└──────┘   │  └──────┘

* 判断 Σ|uₙ| 之后结论一定是收或散，不存在第三个选项。
```

**文字描述：**

**第一步：** 取绝对值 $\sum|u_n|$，用正项级数审敛法（比较法、比值法、根值法、积分法）判断。
- 若收敛 → **绝对收敛**，结束。

**第二步：** 若 $\sum|u_n|$ 发散，考察原级数本身。
- 若是交错级数 → 尝试莱布尼茨判别法。
- 若原级数收敛 → **条件收敛**；若发散 → **发散**。

## 六、任意项级数例题

### 例 1（直接绝对收敛）

$\displaystyle\sum_{n=1}^\infty \frac{(-1)^n}{n^2}$

取绝对值 $\sum \frac{1}{n^2}$，$p=2>1$，收敛 → **绝对收敛**。

### 例 2（条件收敛——交错调和）

$\displaystyle\sum_{n=1}^\infty \frac{(-1)^{n-1}}{n}$

取绝对值：$\sum \frac{1}{n}$ 发散。原级数由莱布尼茨收敛 → **条件收敛**。

### 例 3（条件收敛——$p$ 版）

$\displaystyle\sum_{n=1}^\infty \frac{(-1)^{n-1}}{\sqrt{n}}$

取绝对值：$p=\frac12$ 发散。原级数莱布尼茨收敛 → **条件收敛**。

### 例 4（含三角函数，三角不等式放缩）

$\displaystyle\sum_{n=1}^\infty \frac{\cos n}{n^2}$

$\left|\frac{\cos n}{n^2}\right| \leq \frac{1}{n^2}$，$\sum \frac{1}{n^2}$ 收敛 → **绝对收敛**。

> **技巧：** 遇到 $\cos n$、$\sin n$ 等不规则符号，优先尝试取绝对值放缩；若能被收敛的正项级数控制，就可判绝对收敛。这些不是交错级数，莱布尼茨用不了。

### 例 5（条件收敛综合题）

$\displaystyle\sum_{n=1}^\infty (-1)^n \frac{\ln n}{n}$

**取绝对值：** $\sum \frac{\ln n}{n}$。$n \geq 3$ 时 $\frac{\ln n}{n} > \frac{1}{n}$，比较法发散。

**原级数：** 令 $f(x) = \frac{\ln x}{x}$，$f'(x) = \frac{1-\ln x}{x^2}$，$x > e$ 时递减。莱布尼茨条件（从 $n \geq 3$ 起）满足 → 原级数收敛。

**结论：** **条件收敛**。

## 七、绝对收敛与条件收敛的重要性质

### 绝对收敛

- **可任意重排：** 无论如何打乱顺序，和不变。
- **柯西乘积：** 两个绝对收敛级数可以像多项式一样相乘，对幂级数至关重要。

### 条件收敛

- **黎曼重排定理：** 条件收敛级数通过重排项的顺序，可以收敛到任意预设的实数，甚至可以发散。原因：正项单独加起来发散到 $+\infty$，负项单独加起来发散到 $-\infty$，原级数收敛纯粹因正负项按特定顺序恰好抵消到某有限值。打乱顺序就打破了平衡。

> **注意：** 条件收敛的级数不能随意交换各项顺序。考试中说"因为收敛所以可以重排"是大错——只有绝对收敛才有这个资格。

## 八、易错点

### 1. 正负号不规则，硬用莱布尼茨
**错：** $\sum \frac{\cos n}{n^2}$ 有正有负，用莱布尼茨说明收敛。
**正：** 莱布尼茨只适用于严格正负交替的交错级数。$\cos n$ 符号不规则，应取绝对值并用比较法：$\left|\frac{\cos n}{n^2}\right|\leq \frac1{n^2}$，故绝对收敛。

### 2. 只验证趋零，忘了单调性
**错：** $\sum (-1)^{n-1} \frac{2+(-1)^n}{n}$，因为 $\frac{2+(-1)^n}{n} \to 0$，所以收敛。
**正：** $u_n$ 取值 $1,\frac{3}{2},\frac{1}{3},\frac{3}{4},\ldots$ 振荡不单调，莱布尼茨不适用。进一步按两项配对：$\frac{1}{2k-1}-\frac{3}{2k}\sim-\frac{1}{k}$，原级数发散。

### 3. 把绝对收敛等同于收敛
**错：** $\sum \frac{(-1)^{n-1}}{n}$ 收敛于 $\ln 2$，所以它绝对收敛。
**正：** 原级数收敛但绝对值级数发散 → 条件收敛，不是绝对收敛。

### 4. 认为"收敛就可以重排"
**错：** 条件收敛也是收敛，可以随便调整顺序。
**正：** 只有绝对收敛可以任意重排。条件收敛经重排可收敛到任何值（黎曼重排定理）。

### 5. 忽略"从某项起单调递减"
**错：** 发现 $u_1 < u_2$ 就断定单调性不满足。
**正：** 莱布尼茨只要求"从某项起"递减。前面有限项不递减不影响。

### 6. 费尽心思验证莱布尼茨，忘了直接判绝对收敛
**错：** $\sum \frac{(-1)^n}{n^2}$ 去验证单调性和趋零。
**正：** 取绝对值 $\sum \frac{1}{n^2}$（$p=2>1$）直接得绝对收敛，更省事且结论更强。

> **技巧：** 先走"取绝对值"路线。能判绝对收敛就不用碰莱布尼茨。

## 九、速查总结

| 级数类型 | 判断方法 |
|----------|----------|
| 正项级数 | 比较法、比值法、根值法、积分法 |
| 交错级数 | 莱布尼茨判别法（单调递减 + 趋于零） |
| 任意项级数 | 先判绝对收敛（取绝对值），不行再判条件收敛 |

| 概念 | 含义 |
|------|------|
| 绝对收敛 | $\sum|u_n|$ 收敛 → 原级数也收敛 |
| 条件收敛 | 原级数收敛但 $\sum|u_n|$ 发散 |
| 莱布尼茨条件 | 单调递减 + 趋于零 → 交错级数收敛 |
| 余项估计 | $|r_n| \leq u_{n+1}$，$S_{2k} \leq S \leq S_{2k+1}$ |

## 十、习题

### 基础题

**1.** 判断 $\displaystyle\sum_{n=1}^\infty \frac{(-1)^{n-1}}{n^3}$ 的敛散性，指出绝对收敛还是条件收敛。

**2.** 判断 $\displaystyle\sum_{n=1}^\infty (-1)^n \frac{n}{n+1}$ 的敛散性。

**3.** 用交错级数估计定理：$\sum_{n=1}^\infty \frac{(-1)^{n-1}}{n^2+1}$，需要取多少项使误差不超过 $0.001$？

### 提高题

**4.** 判断 $\displaystyle\sum_{n=1}^\infty (-1)^{n-1} \frac{2^n}{n!}$ 的敛散性（注意：不是交错级数只有莱布尼茨一条路）。

### 参考答案

**1.** 取绝对值 $\sum \frac{1}{n^3}$（$p=3>1$）收敛，**绝对收敛**。

**2.** $\lim \frac{n}{n+1} = 1 \neq 0$，通项不趋于零，**发散**。

**3.** $|r_n| \leq u_{n+1} = \frac{1}{(n+1)^2+1} \leq 0.001$，解得 $n \geq \sqrt{999} - 1 \approx 30.6$，取 $n = 31$。

**4.** 取绝对值 $\sum \frac{2^n}{n!}$，比值法：$\left|\frac{u_{n+1}}{u_n}\right| = \frac{2}{n+1} \to 0 < 1$，**绝对收敛**。

## 十一、后续衔接

交错级数与绝对收敛/条件收敛是后续内容的基石：
- **幂级数：** 在收敛区间内绝对收敛，端点处常变成交错级数或条件收敛。
- **傅里叶级数：** 系数常含 $(-1)^n$，绝对收敛与条件收敛是讨论收敛性的基本工具。
- **一致收敛：** Weierstrass M-判别法的本质是构造绝对收敛的优势级数。
