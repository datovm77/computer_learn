# 高数(下) 4.7：斯托克斯公式、散度、旋度、通量

> **前置知识：** 格林公式、高斯公式。  
> **本节核心：** 斯托克斯公式（空间曲线积分 ↔ 曲面积分），散度、旋度、通量的定义与计算，三大公式的统一结构。

---

## 一、斯托克斯公式

### 从格林公式说起

格林公式将平面闭曲线上的线积分转化为平面区域上的二重积分：

$$\oint_L P\,dx + Q\,dy = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dA$$

斯托克斯公式是其三维推广：将**空间闭曲线**上的线积分转化为以该曲线为边界的**曲面**上的面积分。

### 公式陈述

设 $\Sigma$ 是光滑有向曲面，$L$ 是 $\Sigma$ 的边界闭曲线，$L$ 的方向与 $\Sigma$ 的正侧满足**右手定则**，$P,Q,R$ 在包含 $\Sigma$ 的区域内有连续偏导数，则：

$$\oint_L P\,dx+Q\,dy+R\,dz = \iint_\Sigma \begin{vmatrix} dydz & dzdx & dxdy \\[4pt] \dfrac{\partial}{\partial x} & \dfrac{\partial}{\partial y} & \dfrac{\partial}{\partial z} \\[4pt] P & Q & R \end{vmatrix}$$

展开：

$$\oint_L P\,dx+Q\,dy+R\,dz = \iint_\Sigma \left(\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z}\right)dydz + \left(\frac{\partial P}{\partial z}-\frac{\partial R}{\partial x}\right)dzdx + \left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dxdy$$

### 右手定则

右手四指沿 $L$ 方向弯曲，拇指指向即为 $\Sigma$ 正侧法向量方向。等价地：从法向量一侧看，$L$ 是逆时针。

### 记忆口诀

行列式第一行是有向面积微元 $dydz,\,dzdx,\,dxdy$（轮换序 $x\to y\to z\to x$）；第二行是偏导算子；第三行是 $P,Q,R$。

展开规则——**后对前减前对后**：

| 分量 | 公式 | 记忆 |
|------|------|------|
| $dydz$ 分量 | $R_y - Q_z$ | $R$ 对 $y$ 减 $Q$ 对 $z$ |
| $dzdx$ 分量 | $P_z - R_x$ | $P$ 对 $z$ 减 $R$ 对 $x$ |
| $dxdy$ 分量 | $Q_x - P_y$ | $Q$ 对 $x$ 减 $P$ 对 $y$（格林公式！） |

### 格林公式是特例

令 $\Sigma$ 退化为 $xOy$ 平面上的区域 $D$（即 $z\equiv 0$，$R\equiv 0$），第三分量给出格林公式：

$$\oint_L P\,dx+Q\,dy = \iint_D (Q_x - P_y)\,dxdy$$

## 二、斯托克斯公式的使用方法

### 使用步骤

1. **确认方向**：$L$ 与 $\Sigma$ 正侧满足右手定则
2. **算旋度分量**：$R_y-Q_z$，$P_z-R_x$，$Q_x-P_y$
3. **计算曲面积分**：选合适投影方向，按第二类曲面积分处理

### 适用场景

| 场景 | 策略 |
|------|------|
| 曲线复杂但可张简单曲面 | 转为曲面积分 |
| 旋度恒为零 | 积分直接为零（无旋场） |
| 旋度为常向量 | 结果 = 旋度 $\cdot$ 单位法向量 $\times$ 面积 |
| 验证路径无关 | 单连通域内旋度 $=\vec{0}$ 即可 |

## 三、例题

### 例 1（直接使用斯托克斯公式）

计算 $\oint_L y\,dx + z\,dy + x\,dz$，$L$ 是平面 $x+y+z=1$ 与三个坐标面围成的三角形边界，从 $z$ 轴正向看取逆时针方向。

**解：** $P=y,\ Q=z,\ R=x$。

旋度各分量：

$$R_y - Q_z = 0-1 = -1, \quad P_z - R_x = 0-1 = -1, \quad Q_x - P_y = 0-1 = -1$$

旋度为常向量 $(-1,-1,-1)$。取 $\Sigma$ 为该三角形片，从 $z$ 轴正向看 $L$ 逆时针 → 法向量朝 $(1,1,1)$ 方向，单位法向量 $\vec{n}=\frac{1}{\sqrt3}(1,1,1)$。

$$\oint_L = \iint_\Sigma (-1)\,dydz + (-1)\,dzdx + (-1)\,dxdy = (-1,-1,-1)\cdot\frac{1}{\sqrt3}(1,1,1)\cdot S_\Sigma = -\sqrt3\cdot S_\Sigma$$

三角形顶点 $(1,0,0),(0,1,0),(0,0,1)$，边长 $\sqrt2$，面积 $= \frac{\sqrt3}{4}\cdot(\sqrt2)^2 = \frac{\sqrt3}{2}$。

$$\oint_L = -\sqrt3 \cdot \frac{\sqrt3}{2} = -\frac{3}{2}$$

---

### 例 2（旋度为常向量）

计算 $\oint_L z\,dx + x\,dy + y\,dz$，$L$ 是球面 $x^2+y^2+z^2=1$ 与平面 $x+y+z=0$ 的交线，从 $(1,1,1)$ 方向看取逆时针。

**解：** $P=z,\ Q=x,\ R=y$。旋度 $=(1,1,1)$。

取 $\Sigma$ 为平面 $x+y+z=0$ 截球的圆盘，法向量朝 $(1,1,1)$，$\vec{n}=\frac{1}{\sqrt3}(1,1,1)$。

$$\oint_L = (1,1,1)\cdot\frac{1}{\sqrt3}(1,1,1)\cdot S_\Sigma = \sqrt3 \cdot S_\Sigma$$

球心 $(0,0,0)$ 到平面距离 $d=0$，截面是大圆，半径 $r=1$，面积 $=\pi$。

$$\oint_L = \sqrt3\pi$$

> **旋度为常向量时**：斯托克斯 = rot$\vec{F}\cdot\vec{n}\cdot S$，无需逐分量投影。

---

### 例 3（选择最简曲面）

计算 $\oint_L (y-z)\,dx + (z-x)\,dy + (x-y)\,dz$，$L$ 是圆 $x^2+y^2=4,\ z=0$，从上方看逆时针。

**解：** $P=y-z,\ Q=z-x,\ R=x-y$。

旋度各分量均为 $-2$。取 $\Sigma$ 为 $z=0,\,x^2+y^2\leq 4$ 的水平圆盘，上侧（满足右手定则）。

水平圆盘的法向量纯竖直，$dydz=0$，$dzdx=0$，仅 $dxdy$ 项存活：

$$\oint_L = \iint_D (-2)\,dxdy = -2\cdot 4\pi = -8\pi$$

> 斯托克斯公式对曲面选取无限制（只要以 $L$ 为边界）。选平面圆盘远比选球帽简单。

---

### 例 4（验证路径无关）

判断 $\int_L yz\,dx + xz\,dy + xy\,dz$ 是否与路径无关。

**解：** $P=yz,\ Q=xz,\ R=xy$。

$$R_y - Q_z = x-x=0,\quad P_z - R_x = y-y=0,\quad Q_x - P_y = z-z=0$$

旋度恒为 $\vec{0}$，全空间单连通，**路径无关**。势函数 $u=xyz$（验证 $u_x=yz$）。

$$\int_L yz\,dx+xz\,dy+xy\,dz = x_By_Bz_B - x_Ay_Az_A$$

## 四、散度（Divergence）

### 定义

$$\text{div}\,\vec{F} = \nabla\cdot\vec{F} = \frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}$$

### 物理意义

单位体积内流体的**净涌出量**。

| 散度 | 含义 | 类比 |
|------|------|------|
| $>0$ | **源**：流体涌出 | 水龙头 |
| $<0$ | **汇**：流体消失 | 排水口 |
| $=0$ | **无源**：进出平衡 | 不可压缩流体 |

### 高斯公式的散度形式

$$\oiint_\Sigma \vec{F}\cdot d\vec{S} = \iiint_\Omega \text{div}\,\vec{F}\,dV$$

封闭面的总通量 = 内部散度的体积分。

### 例题

求 $\vec{F}=(x^2y, y^2z, z^2x)$ 在 $(1,1,1)$ 处的散度。

$$\text{div}\,\vec{F} = 2xy + 2yz + 2zx \Big|_{(1,1,1)} = 6$$

## 五、旋度（Curl / Rotation）

### 定义

$$\text{rot}\,\vec{F} = \nabla\times\vec{F} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\[4pt] \dfrac{\partial}{\partial x} & \dfrac{\partial}{\partial y} & \dfrac{\partial}{\partial z} \\[4pt] P & Q & R \end{vmatrix}$$

$$= (R_y-Q_z)\,\vec{i} + (P_z-R_x)\,\vec{j} + (Q_x-P_y)\,\vec{k}$$

### 物理意义

流体微元旋转角速度的两倍。方向 = 旋转轴（右手定则），模 = 旋转强度。

### 核心结论

单连通域内：

$$\text{rot}\,\vec{F} = \vec{0} \iff \text{保守场} \iff \text{存在势函数} \iff \text{线积分路径无关}$$

### 斯托克斯公式的旋度形式

$$\oint_L \vec{F}\cdot d\vec{r} = \iint_\Sigma (\text{rot}\,\vec{F})\cdot d\vec{S}$$

沿边界的**环量** = 曲面上**旋度的通量**。

### 例题

求 $\vec{F}=(xz, -y^2, x^2y)$ 的旋度。

$$R_y - Q_z = x^2,\quad P_z - R_x = x - 2xy = x(1-2y),\quad Q_x - P_y = 0$$

$$\text{rot}\,\vec{F} = (x^2,\; x(1-2y),\; 0)$$

## 六、通量（Flux）

### 定义

$$\Phi = \iint_\Sigma \vec{F}\cdot d\vec{S} = \iint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy$$

单位时间内沿正侧穿过 $\Sigma$ 的流体量。$\Phi>0$ 净流向正侧，$\Phi<0$ 净流向负侧。

### 计算策略

| 曲面类型 | 方法 |
|----------|------|
| 封闭曲面 | 高斯公式 |
| 非封闭但可补成封闭 | 补面 + 高斯 |
| 简单曲面 | 直接投影 |

### 例题

求 $\vec{F}=(x,y,z)$ 穿过球面 $x^2+y^2+z^2=a^2$（外侧）的通量。

$$\Phi = \iiint_\Omega \text{div}\,\vec{F}\,dV = \iiint_\Omega 3\,dV = 3\cdot\frac{4}{3}\pi a^3 = 4\pi a^3$$

---

## 七、三大公式的统一视角

| 公式 | 转化 | 核心算子 | 维度提升 |
|------|------|------|------|
| **牛顿-莱布尼茨** | $\int_a^b f'\,dx = f(b)-f(a)$ | 导数 | 点 → 线 |
| **格林** | $\oint_L \to \iint_D$ | $Q_x-P_y$ | 平面曲线 → 平面区域 |
| **高斯** | $\oiint_\Sigma \to \iiint_\Omega$ | $\nabla\cdot\vec{F}$ | 封闭曲面 → 体 |
| **斯托克斯** | $\oint_L \to \iint_\Sigma$ | $\nabla\times\vec{F}$ | 空间曲线 → 曲面 |

**统一本质（广义 Stokes 定理）：** 边界上的积分 = 内部"微分算子"的积分。

---

## 八、散度与旋度的运算性质

### 恒等式

| 恒等式 | 含义 | 记忆 |
|--------|------|------|
| $\text{div}(\text{rot}\,\vec{F}) = 0$ | 旋度场无源 | 先旋后散 = 0 |
| $\text{rot}(\nabla u) = \vec{0}$ | 梯度场无旋 | 先梯后旋 = 0 |

### 乘积公式

- $\text{div}(\varphi\vec{F}) = \varphi\,\text{div}\,\vec{F} + \vec{F}\cdot\nabla\varphi$
- $\text{rot}(\varphi\vec{F}) = \varphi\,\text{rot}\,\vec{F} + \nabla\varphi\times\vec{F}$

## 九、综合例题

### 例 5（斯托克斯 + 投影计算）

计算 $\oint_L (y^2-z^2)\,dx + (z^2-x^2)\,dy + (x^2-y^2)\,dz$，$L$ 是平面 $x+y+z=\frac{3}{2}$ 截圆柱面 $x^2+y^2=1$ 所得的椭圆，从上方看逆时针。

**解：** $P=y^2-z^2,\ Q=z^2-x^2,\ R=x^2-y^2$。

旋度分量：$R_y-Q_z = -2y-2z$，$P_z-R_x = -2z-2x$，$Q_x-P_y = -2x-2y$。

取 $\Sigma$ 为平面 $z=\frac32-x-y$ 上被圆柱截出的椭圆盘，上侧。投影到 $D:x^2+y^2\leq 1$（$z_x=-1,\,z_y=-1$）：

设旋度分量为 $A,B,C$，上侧投影公式给出：

$$\oint_L = \iint_D (A+B+C)\,dxdy$$

$$A+B+C = -4x-4y-4z = -4x-4y-4(\tfrac32-x-y) = -6$$

$$\oint_L = \iint_D (-6)\,dxdy = -6\pi$$

---

### 例 6（非封闭曲面通量：补面 + 高斯）

求 $\vec{F}=(x^3, y^3, z^3)$ 穿过上半球面 $\Sigma: x^2+y^2+z^2=a^2,\,z\geq 0$（外侧）的通量。

**解：** 补底面 $\Sigma_0: z=0,\,x^2+y^2\leq a^2$（下侧）。

散度 $=3(x^2+y^2+z^2)$。高斯公式（上半球体 $\Omega$）：

$$\oiint_{\Sigma+\Sigma_0}\vec{F}\cdot d\vec{S} = 3\int_0^{2\pi}d\theta\int_0^{\pi/2}\sin\phi\,d\phi\int_0^a \rho^4\,d\rho = 3\cdot 2\pi\cdot 1\cdot\frac{a^5}{5} = \frac{6\pi a^5}{5}$$

底面通量：$z=0$ 时 $R=z^3=0$，底面贡献为零。

$$\iint_\Sigma \vec{F}\cdot d\vec{S} = \frac{6\pi a^5}{5}$$

## 十、易错点

1. **右手定则方向搞反**：反了则结果差一个负号。从法向量一侧看，$L$ 必须是逆时针。
2. **旋度分量顺序**：是 $R_y-Q_z$，不是 $Q_z-R_y$，减号方向容易记反。
3. **散度是标量，旋度是向量**：$\nabla\cdot$ 得标量，$\nabla\times$ 得向量，不可混用。
4. **斯托克斯右边是第二类曲面积分**：有方向性，投影时正负号不能丢。
5. **"旋度为零 → 路径无关"需要单连通**：空间有洞时结论不成立。

## 速查公式卡

$$\boxed{\oint_L \vec{F}\cdot d\vec{r} = \iint_\Sigma (\nabla\times\vec{F})\cdot d\vec{S}} \quad\text{（斯托克斯）}$$

$$\boxed{\text{div}\,\vec{F} = \frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}} \quad\text{（散度）}$$

$$\boxed{\text{rot}\,\vec{F} = (R_y-Q_z)\,\vec{i}+(P_z-R_x)\,\vec{j}+(Q_x-P_y)\,\vec{k}} \quad\text{（旋度）}$$

$$\boxed{\Phi = \iint_\Sigma \vec{F}\cdot d\vec{S} = \iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy} \quad\text{（通量）}$$
