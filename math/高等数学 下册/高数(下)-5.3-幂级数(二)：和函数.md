# 高数(下) 5.3：幂级数（二）—— 和函数

> **适合人群：** 已掌握收敛半径与收敛域，现在要把幂级数真正"加起来"得到一个函数。  
> **学习目标：** 掌握求和函数的标准技术（逐项求导、逐项积分），理解幂级数作为函数的性质。

---

## 一、和函数是什么？

### 定义

在收敛域上，幂级数 $\sum_{n=0}^\infty a_n x^n$ 的值随 $x$ 变化，定义了一个函数：

$$S(x) = \sum_{n=0}^\infty a_n x^n, \quad x \in \text{收敛域}$$

$S(x)$ 就是幂级数的**和函数**。

> **目标：** 把无穷级数的和写成一个"闭合形式"（初等函数表达式）。

### 例子

$$\sum_{n=0}^\infty x^n = \frac{1}{1-x}, \quad |x|<1$$

这是最基本的和函数——等比级数的和。大量求和函数的问题都可以通过对它做变形得到。

---

## 二、幂级数的分析性质

### 性质 1：连续性

和函数 $S(x)$ 在收敛区间 $(-R,R)$ 内**连续**。

如果在端点 $x=R$（或 $-R$）处也收敛，则 $S(x)$ 在该端点**单侧连续**。

> **实用价值：** $S(R) = \lim_{x\to R^-} S(x)$。有时候直接在 $x=R$ 处代入不方便，但用极限可以算。

### 性质 2：逐项求导

$$S'(x) = \sum_{n=1}^\infty n a_n x^{n-1}, \quad |x|<R$$

**收敛半径不变**，但端点收敛性可能改变。

### 性质 3：逐项积分

$$\int_0^x S(t)\,dt = \sum_{n=0}^\infty \frac{a_n}{n+1} x^{n+1}, \quad |x|<R$$

**收敛半径不变**，端点收敛性可能改变。

> **核心思想：** 在收敛区间内，幂级数可以像多项式一样逐项求导、逐项积分。这两个操作是求和函数的主要工具。

---

## 三、求和函数的基本策略

### 策略总结

| 情况 | 方法 |
|------|------|
| 能直接认出是哪个已知级数 | 直接写出和 |
| 通项含 $n$ 的多项式因子（如 $n$, $n^2$） | **逐项求导**：先提出 $x$ 的适当次幂，识别等比级数，再求导 |
| 通项含 $\frac{1}{n}$ 或 $\frac{1}{n+1}$ | **逐项积分**：先求导化简（或直接积分） |
| 通项形式复杂 | 设 $S(x)$，建立微分方程，解方程 |

### 万能出发点

大多数求和函数问题的终极基础是：

$$\sum_{n=0}^\infty x^n = \frac{1}{1-x}, \quad |x|<1$$

对它求导：$\sum_{n=1}^\infty nx^{n-1} = \frac{1}{(1-x)^2}$

再乘以 $x$：$\sum_{n=1}^\infty nx^n = \frac{x}{(1-x)^2}$

对它积分：$\sum_{n=0}^\infty \frac{x^{n+1}}{n+1} = -\ln(1-x)$

即 $\sum_{n=1}^\infty \frac{x^n}{n} = -\ln(1-x), \quad -1\leq x < 1$

## 四、例题

### 例 1（逐项求导型）

求 $S(x) = \sum_{n=1}^\infty nx^n$ 的和函数（$|x|<1$）。

**解法：** 提出 $x$，然后识别求导。

$$S(x) = x\sum_{n=1}^\infty nx^{n-1} = x\left(\sum_{n=0}^\infty x^n\right)' = x\cdot\frac{1}{(1-x)^2} = \frac{x}{(1-x)^2}$$

### 例 2（逐项求导两次）

求 $S(x) = \sum_{n=1}^\infty n^2 x^n$ 的和函数（$|x|<1$）。

**解法：** 注意 $n^2 = n(n-1)+n$，拆开：

$$S(x) = \sum_{n=2}^\infty n(n-1)x^n + \sum_{n=1}^\infty nx^n$$

第二项已知 $= \frac{x}{(1-x)^2}$。

第一项：$\sum_{n=2}^\infty n(n-1)x^n = x^2\sum_{n=2}^\infty n(n-1)x^{n-2} = x^2\left(\sum_{n=0}^\infty x^n\right)'' = x^2\cdot\frac{2}{(1-x)^3}$

$$S(x) = \frac{2x^2}{(1-x)^3} + \frac{x}{(1-x)^2} = \frac{x(1+x)}{(1-x)^3}$$

### 例 3（逐项积分型）

求 $S(x) = \sum_{n=1}^\infty \frac{x^n}{n}$ 的和函数。

**解法：** 先求导化简。

$$S'(x) = \sum_{n=1}^\infty x^{n-1} = \frac{1}{1-x}, \quad |x|<1$$

积回去（注意 $S(0)=0$）：

$$S(x) = \int_0^x \frac{1}{1-t}\,dt = -\ln(1-x), \quad |x|<1$$

检查端点 $x=-1$：$S(-1) = \sum\frac{(-1)^n}{n} = -\ln 2$，利用 Abel 定理（单侧连续性）也可以验证。

**收敛域上的和函数：**

$$S(x) = -\ln(1-x), \quad -1\leq x < 1$$

### 例 4（先求导后积分）

求 $S(x) = \sum_{n=1}^\infty \frac{x^n}{n(n+1)}$（先在 $|x|<1$ 内求和，再讨论端点）。

**解法：** 通项含 $\frac{1}{n(n+1)}$，逐项求导两次或者裂项。

裂项：$\frac{1}{n(n+1)} = \frac{1}{n}-\frac{1}{n+1}$

$$S(x) = \sum_{n=1}^\infty\frac{x^n}{n} - \sum_{n=1}^\infty\frac{x^n}{n+1}$$

第一部分：$-\ln(1-x)$

第二部分：$\sum_{n=1}^\infty\frac{x^n}{n+1} = \frac{1}{x}\sum_{n=1}^\infty\frac{x^{n+1}}{n+1} = \frac{1}{x}\left[\sum_{m=2}^\infty\frac{x^m}{m}\right] = \frac{1}{x}\left[-\ln(1-x)-x\right]$

$$S(x) = -\ln(1-x) - \frac{1}{x}\left[-\ln(1-x)-x\right] = -\ln(1-x)+\frac{\ln(1-x)}{x}+1$$

$$= \left(1-\frac{1}{x}\right)\cdot(-\ln(1-x))+1 = \frac{x-1}{x}\cdot(-\ln(1-x))+1$$

化简：$S(x) = 1+\frac{(1-x)\ln(1-x)}{x}$（$x\neq 0,\,x<1$），$S(0)=0$；在 $x=1$ 处由极限得到 $S(1)=1$。

### 例 5（建立微分方程）

求 $S(x) = \sum_{n=0}^\infty \frac{x^{2n+1}}{(2n+1)!!}$ 的和函数（这里 $(2n+1)!! = 1\cdot3\cdot5\cdots(2n+1)$）。

**解法：** 直接凑已知级数困难，建立微分方程。

$$S'(x) = \sum_{n=0}^\infty \frac{(2n+1)x^{2n}}{(2n+1)!!} = \sum_{n=0}^\infty \frac{x^{2n}}{(2n-1)!!}$$

约定 $(-1)!!=1$。利用递推 $(2n+1)!!=(2n+1)(2n-1)!!$，有：

$$S'(x)=1+\sum_{n=1}^\infty\frac{x^{2n}}{(2n-1)!!}=1+x\sum_{n=0}^\infty\frac{x^{2n+1}}{(2n+1)!!}=1+xS(x)$$

于是 $S'(x)-xS(x)=1$，且 $S(0)=0$。解这个一阶线性微分方程：

$$\left(e^{-x^2/2}S(x)\right)'=e^{-x^2/2}$$

$$S(x)=e^{x^2/2}\int_0^x e^{-t^2/2}\,dt$$

> **技巧总结：** 求和函数的关键是"消去通项中碍事的因子"——$n$ 在分子用求导消，$n$ 在分母用积分消。

## 五、常用已知级数和函数

| 幂级数 | 和函数 | 收敛范围 |
|--------|--------|----------|
| $\sum_{n=0}^\infty x^n$ | $\frac{1}{1-x}$ | $|x|<1$ |
| $\sum_{n=1}^\infty nx^{n-1}$ | $\frac{1}{(1-x)^2}$ | $|x|<1$ |
| $\sum_{n=1}^\infty nx^n$ | $\frac{x}{(1-x)^2}$ | $|x|<1$ |
| $\sum_{n=1}^\infty \frac{x^n}{n}$ | $-\ln(1-x)$ | $-1\leq x<1$ |
| $\sum_{n=0}^\infty \frac{x^n}{n!}$ | $e^x$ | $(-\infty,+\infty)$ |
| $\sum_{n=0}^\infty (-1)^n x^{2n}$ | $\frac{1}{1+x^2}$ | $|x|<1$ |
| $\sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{2n+1}$ | $\arctan x$ | $|x|\leq 1$ |

> **这些是做题的"积木"**——遇到求和函数，目标就是通过求导/积分/代换，把问题变形成上表中的某一个。

## 六、求数值级数的和

幂级数的和函数还有一个重要应用：**求数值级数的和**。

### 方法

把数值级数看成某个幂级数在特定 $x$ 值处的值：

1. 识别数值级数 $\sum a_n$ 是某幂级数 $S(x)$ 在 $x=x_0$ 处的值
2. 先求 $S(x)$ 的闭合形式
3. 代入 $x=x_0$ 得到答案

### 例

求 $\sum_{n=1}^\infty \frac{n}{2^n}$ 的值。

注意 $\frac{n}{2^n} = n\cdot\left(\frac12\right)^n$。

而 $\sum_{n=1}^\infty nx^n = \frac{x}{(1-x)^2}$，令 $x=\frac12$：

$$\sum_{n=1}^\infty \frac{n}{2^n} = \frac{1/2}{(1-1/2)^2} = \frac{1/2}{1/4} = 2$$

### 再例

求 $\sum_{n=1}^\infty \frac{1}{n\cdot 2^n}$。

$\sum_{n=1}^\infty\frac{x^n}{n} = -\ln(1-x)$，令 $x=\frac12$：

$$\sum_{n=1}^\infty\frac{1}{n\cdot 2^n} = -\ln\frac12 = \ln 2$$

---

## 七、易错点

1. **逐项求导/积分只在开区间内成立**——端点处需要用 Abel 定理（连续性）单独处理。
2. **积分后别忘了常数**：$S(x)=\int_0^x S'(t)\,dt + S(0)$，$S(0)$ 通常就是 $a_0$。
3. **提 $x$ 的幂次时注意 $x=0$ 的情况**：除以 $x$ 后要单独补上 $S(0)$ 的值。
4. **求导会失去端点收敛性**：$\sum\frac{x^n}{n}$ 在 $x=-1$ 收敛，但求导后 $\sum x^{n-1}$ 在 $x=-1$ 不收敛。
