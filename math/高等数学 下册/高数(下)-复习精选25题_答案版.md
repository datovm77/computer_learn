## 一、重积分

### 第 1 题 ★（二重积分换序）
计算 $\displaystyle I=\int_0^1 dx\int_x^1 e^{-y^2}\,dy$。

**答案：** $\dfrac{1}{2}(1-e^{-1})$

**【思路分析】**
题目给出的积分限是外层 $x$、内层 $y$（实际计算时先对 $y$ 积分，再对 $x$ 积分）。但内层被积函数 $e^{-y^2}$ 对 $y$ 积——$e^{-y^2}$ 没有初等原函数（$\int e^{-y^2}dy$ 只能用误差函数 $\text{erf}(y)$ 表示），直接积不出来。这说明必须**改变积分次序**：换序后，让 $y$ 作为外层变量，积完 $x$ 后留下外层对 $y$ 的单项式 $\times e^{-y^2}$，那就能搞定了。

**【详细求解】**

**步骤 1：画出积分区域**

原积分限对应：
- $x$ 从 $0$ 到 $1$ 扫过；
- 固定 $x$ 后，$y$ 从下面的线 $y=x$ 到上面的线 $y=1$。

画在 $xy$ 平面上，这是三条线围成的三角形：
- 左边界：$x=0$
- 下边界：$y=x$（对角线）
- 上边界：$y=1$（水平线）

三个顶点：$(0,0)$、$(0,1)$、$(1,1)$。

**步骤 2：决定新次序——改为"先 $x$ 后 $y$"**

交换次序后，外层走 $y$，内层走 $x$：
- $y$ 从 $0$ 到 $1$；
- 固定 $y$ 后，$x$ 从最左边 $x=0$ 到最右边 $x=y$（因为三角形右边是 $y=x$ 即 $x=y$）。

$$I=\int_{y=0}^{1} dy\int_{x=0}^{y} e^{-y^2}\,dx.$$

**步骤 3：先积内层 $x$**

内层被积函数与 $x$ 无关，直接积出长度：

$$\int_{x=0}^{y} e^{-y^2}\,dx = e^{-y^2}\cdot x\Big|_{0}^{y} = y\,e^{-y^2}.$$

**步骤 4：再积外层 $y$**

$$I = \int_{0}^{1} y\,e^{-y^2}\,dy.$$

令 $u=-y^2$，$du=-2y\,dy$，则 $y\,dy = -\frac12 du$：

$$I = \int_{y=0}^{1} e^{-y^2}\cdot y\,dy = \int_{u=0}^{-1} e^{u}\left(-\frac12\right)du = \frac12\int_{-1}^{0} e^{u}\,du = \frac12 e^{u}\Big|_{-1}^{0} = \frac12(1-e^{-1}).$$

$\boxed{\displaystyle I = \frac{1}{2}(1-e^{-1})}$

**【易错提醒】**
- ⚠️ 换序时最容易出错的是**新积分的上下限**。技巧：画图，用"先定外层变量的范围，再定内层变量随外层怎么变"来推导，不要死记硬背。
- ⚠️ 换序后内层积分是 $\int_0^y e^{-y^2}dx$，注意是 $dx$ 不是 $dy$——$e^{-y^2}$ 在这里是常数。

> **要点：** 看到内层有"积不出"的函数（$e^{-y^2}$、$\sin y^2$、$\dfrac{\sin y}{y}$ 等），先想换序。换序的核心是把怪异函数暴露在外层，让内层只积简单的多项式。

**【补充解法：截面长度法】**
也可以直接从区域截面看：对固定的 $y\in[0,1]$，区域内的 $x$ 长度为 $y-0=y$，所以
$$
I=\int_0^1 e^{-y^2}\cdot y\,dy=\frac12(1-e^{-1}).
$$
这本质上就是换序，但思考重点从“改积分限”变成“按水平截面累加面积权重”。

### 第 2 题（二重积分·极坐标）
计算 $\displaystyle I=\iint_D e^{-(x^2+y^2)}\,dA$，$D$ 为圆盘 $x^2+y^2\le 1$。

**答案：** $\pi(1-e^{-1})$

**【思路分析】**
两个信号告诉我们用极坐标：（1）积分区域是圆盘——极坐标的区域描述是 $r\le1$，干净利落；（2）被积函数 $e^{-(x^2+y^2)}=e^{-r^2}$ 只依赖 $r$，与 $\theta$ 无关。直角坐标系下要算 $\iint e^{-(x^2+y^2)}dxdy$ 极其麻烦且积不出来，但极坐标下就是个单变量积分。

**【详细求解】**

**步骤 1：极坐标变换**

直角坐标 → 极坐标：
$$x = r\cos\theta,\quad y = r\sin\theta,\quad dA = dx\,dy = r\,dr\,d\theta.$$
其中 $r\,dr\,d\theta$ 里的 $r$ 是 Jacobi 行列式 $\left|\dfrac{\partial(x,y)}{\partial(r,\theta)}\right|=r$，**不能漏掉**。

区域 $D$ 在极坐标下：$0\le r\le 1,\ 0\le\theta\le 2\pi$。
被积函数：$x^2+y^2=r^2$，故 $e^{-(x^2+y^2)}=e^{-r^2}$。

**步骤 2：化为累次积分**

$$I = \int_0^{2\pi} d\theta \int_0^1 e^{-r^2}\cdot r\,dr.$$

由于被积函数与 $\theta$ 无关，$\theta$ 积分立即给出 $2\pi$：

$$I = 2\pi \int_0^1 r\,e^{-r^2}\,dr.$$

**步骤 3：计算 $r$ 积分**

令 $u=-r^2$，$du=-2r\,dr$，则 $r\,dr = -\dfrac12 du$：

$$\int_0^1 r\,e^{-r^2}\,dr = \int_{r=0}^{1} e^{-r^2}\,r\,dr = \int_{u=0}^{-1} e^{u}\left(-\frac12\right)du = \frac12\int_{-1}^{0} e^{u}\,du = \frac12(1-e^{-1}).$$

**步骤 4：综合**

$$I = 2\pi \cdot \frac12(1-e^{-1}) = \pi(1-e^{-1}).$$

$\boxed{I = \pi(1-e^{-1})}$

**【易错提醒】**
- ⚠️ **$r\,dr$ 里的 $r$ 是极坐标最常见的失分点。** $dA$ 变成 $r\,dr\,d\theta$，不是 $dr\,d\theta$。初学者最容易写 $e^{-r^2}dr\,d\theta$，那就全错了。
- ⚠️ 这个积分在概率论里很重要：$\int_{-\infty}^{\infty} e^{-x^2}dx=\sqrt\pi$ 的证明就是通过平方后转为本题这样的二重积分算出来的。

> **要点：** "圆域 + $x^2+y^2$ 组合函数" = 极坐标。$e^{-(x^2+y^2)}$、$\sin(x^2+y^2)$、$(x^2+y^2)^n$ 都是极坐标的典型被积函数。

**【补充解法：同心圆环法】**
把圆盘分成半径为 $r$、厚度为 $dr$ 的薄圆环，圆环面积近似为 $2\pi r\,dr$，圆环上被积函数恒为 $e^{-r^2}$。于是
$$
I=\int_0^1 e^{-r^2}\,2\pi r\,dr=\pi(1-e^{-1}).
$$
这种写法适合快速处理只依赖 $r=\sqrt{x^2+y^2}$ 的圆域积分。

### 第 3 题 ★（三重积分·柱坐标）
计算 $\displaystyle I=\iiint_\Omega (x^2+y^2)\,dV$，$\Omega=\{x^2+y^2\le 4,\ 0\le z\le 3\}$。

**答案：** $24\pi$

**【思路分析】**
区域是直圆柱——$xy$ 面上半径 $2$ 的圆盘，$z$ 从 $0$ 到 $3$。被积函数 $x^2+y^2$ 仅与点到 $z$ 轴的距离有关，在柱坐标下就是 $r^2$。柱坐标专门用来处理这种"旋转对称"结构：$r,\theta$ 部分用极坐标、$z$ 部分直来直去。

柱坐标变换：
$$x=r\cos\theta,\quad y=r\sin\theta,\quad z=z,\quad dV=r\,dr\,d\theta\,dz.$$

**【详细求解】**

**步骤 1：写出柱坐标下的积分**

区域对应：$0\le r\le 2,\ 0\le\theta\le 2\pi,\ 0\le z\le 3$。被积函数 $x^2+y^2=r^2$。

$$I = \int_0^{2\pi} d\theta \int_0^2 r\,dr \int_0^3 r^2\,dz.$$

**步骤 2：分离变量逐层计算**

三个积分变量相互独立，各自积分限都是常数，直接分别算：

$$\int_0^{2\pi} d\theta = 2\pi, \quad \int_0^3 dz = 3, \quad \int_0^2 r\cdot r^2\,dr = \int_0^2 r^3\,dr = \frac{2^4}{4} = 4.$$

**步骤 3：相乘**

$$I = 2\pi \times 4 \times 3 = 24\pi.$$

$\boxed{I = 24\pi}$

**【易错提醒】**
- ⚠️ 注意 $dV = r\,dr\,d\theta\,dz$ 中的 $r$ 来自 Jacobi，和极坐标的 $dA = r\,dr\,d\theta$ 完全一致，$z$ 部分没有缩放。
- ⚠️ 被积函数 $x^2+y^2 = r^2$ 与体积元中的 $r$ 合并后是 $r^3$，积分得到 $2^4/4=4$。如果误写成 $r^2$ 积分得到 $2^3/3=8/3$，结果就错了。

> **要点：** 柱坐标 = 极坐标 + 直线 $z$。适合旋转体区域（圆柱、圆锥、旋转抛物面），被积函数含 $x^2+y^2$ 时尤其好用。

**【补充解法：先压缩高度】**
因为被积函数与 $z$ 无关，圆柱高度恒为 $3$，可先把三重积分化为平面积分：
$$
I=3\iint_{x^2+y^2\le4}(x^2+y^2)\,dA
=3\int_0^{2\pi}\int_0^2 r^2\cdot r\,dr\,d\theta=24\pi.
$$
这等价于“高度 $\times$ 圆盘关于原点的极惯性矩”。

### 第 4 题（三重积分·球坐标）
计算 $\displaystyle I=\iiint_\Omega \sqrt{x^2+y^2+z^2}\,dV$，$\Omega$ 为单位球 $x^2+y^2+z^2\le 1$。

**答案：** $\pi$

**【思路分析】**
被积函数 $\sqrt{x^2+y^2+z^2}$ 是点到原点的距离，区域是球——这正是球坐标 $(\rho,\varphi,\theta)$ 的完美搭配。球坐标下 $r = \rho$，$dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$，积分限很简单：$\rho$ 从 $0$ 到 $1$，$\varphi$ 从 $0$ 到 $\pi$（纬度），$\theta$ 从 $0$ 到 $2\pi$（经度）。

球坐标与直角坐标的关系：
$$x=\rho\sin\varphi\cos\theta,\quad y=\rho\sin\varphi\sin\theta,\quad z=\rho\cos\varphi.$$

**【详细求解】**

**步骤 1：写出球坐标下的积分**

被积函数 $\sqrt{x^2+y^2+z^2} = \rho$，体积元 $dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$，合并得 $\rho\cdot\rho^2\sin\varphi = \rho^3\sin\varphi$。

$$I = \int_0^{2\pi} d\theta \int_0^{\pi} \sin\varphi\,d\varphi \int_0^{1} \rho^3\,d\rho.$$

**步骤 2：分别计算三个积分**

三者独立，可逐项算：

$$\int_0^{2\pi} d\theta = 2\pi,\quad
\int_0^{\pi} \sin\varphi\,d\varphi = \big[-\cos\varphi\big]_0^{\pi} = -(-1) - (-1) = 1+1 = 2,$$
$$\int_0^{1} \rho^3\,d\rho = \frac14\rho^4\Big|_0^1 = \frac14.$$

**步骤 3：相乘**

$$I = 2\pi \times 2 \times \frac14 = \pi.$$

$\boxed{I = \pi}$

**【易错提醒】**
- ⚠️ $\varphi$ 的范围是 $0$ 到 $\pi$（从北极到南极），**不是** $0$ 到 $2\pi$。$\theta$ 才是绕 $z$ 轴旋转的角度（$0$ 到 $2\pi$），两者别混。
- ⚠️ $\int_0^{\pi}\sin\varphi\,d\varphi = 2$ 这个结果建议背下来，算球坐标的题频繁出现。
- ⚠️ 如果被积函数是 $z$ 或 $x^2$ 呢？那就不能简单分离了，需要利用 $\varphi$ 的三角函数，把被积函数展开后再积分。

> **要点：** 球坐标三步曲——区域是球 $\rightarrow$ 设 $(\rho,\varphi,\theta)$；被积函数含 $\sqrt{x^2+y^2+z^2}$ $\rightarrow$ 换 $\rho$；$dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$。三层积分限都独立，直接分离乘出来。

**【补充解法：球壳法】**
半径为 $\rho$ 的薄球壳体积近似为 $4\pi\rho^2\,d\rho$，壳上被积函数为 $\rho$，所以
$$
I=\int_0^1 \rho\cdot4\pi\rho^2\,d\rho
=4\pi\int_0^1\rho^3\,d\rho=\pi.
$$
当区域是球、被积函数只与到原点距离有关时，球壳法比完整球坐标更短。

### 第 5 题 ★（曲面面积）
求锥面 $z=\sqrt{x^2+y^2}$ 被柱面 $x^2+y^2=2x$ 所割下部分的面积。

**答案：** $\sqrt{2}\,\pi$

**【思路分析】**
曲面面积问题的标准流程：曲面 $z=f(x,y)$ → 求偏导 $z_x,z_y$ → 计算 $\sqrt{1+z_x^2+z_y^2}$ → 确定投影区域 $D_{xy}$ → 在 $D_{xy}$ 上积分这个"坡度系数"。

本题有两层：锥面是被割的曲面，柱面是划定范围的"刀"。所以第一步：明确锥面方程 $z=\sqrt{x^2+y^2}$；第二步：柱面 $x^2+y^2=2x$ 决定投影区域（它在 $xy$ 面上的投影就是 $x^2+y^2\le 2x$）；第三步：把锥面的坡度系数算出来，然后在投影区域上积分。

**【详细求解】**

**步骤 1：计算曲面面积元 $dS$**

$$z = \sqrt{x^2+y^2} \quad\Rightarrow\quad \frac{\partial z}{\partial x} = \frac{x}{\sqrt{x^2+y^2}},\quad \frac{\partial z}{\partial y} = \frac{y}{\sqrt{x^2+y^2}}.$$

于是

$$\sqrt{1+z_x^2+z_y^2} = \sqrt{1 + \frac{x^2}{x^2+y^2} + \frac{y^2}{x^2+y^2}} = \sqrt{1 + \frac{x^2+y^2}{x^2+y^2}} = \sqrt{1+1} = \sqrt{2}.$$

$dS = \sqrt{1+z_x^2+z_y^2}\,dA = \sqrt{2}\,dA$。这个锥面的坡度系数恒为 $\sqrt{2}$，说明面积 = $\sqrt{2}$ × 投影面积。

**步骤 2：确定投影区域 $D_{xy}$**

柱面 $x^2+y^2=2x$ 在 $xy$ 面上的投影即其水平截面。配方：

$$x^2+y^2-2x=0 \ \Rightarrow\ (x-1)^2+y^2=1.$$

这是圆心在 $(1,0)$、半径为 $1$ 的圆。

$$D_{xy}: (x-1)^2+y^2\le 1.$$

**步骤 3：用极坐标算投影面积**

圆 $(x-1)^2+y^2=1$ 的极坐标方程：$r^2 = 2r\cos\theta \ \Rightarrow\ r = 2\cos\theta$（$\cos\theta\ge0$，即 $\theta\in[-\frac\pi2,\frac\pi2]$）。

$$A = \iint_\Sigma dS = \sqrt{2}\iint_{D_{xy}} dA
= \sqrt{2}\int_{\theta=-\pi/2}^{\pi/2} d\theta \int_{r=0}^{2\cos\theta} r\,dr.$$

先积内层 $r$：

$$\int_0^{2\cos\theta} r\,dr = \left[\frac{r^2}{2}\right]_0^{2\cos\theta} = 2\cos^2\theta.$$

再积外层 $\theta$：

$$A = \sqrt{2}\int_{-\pi/2}^{\pi/2} 2\cos^2\theta\,d\theta = 2\sqrt{2}\int_{-\pi/2}^{\pi/2} \cos^2\theta\,d\theta.$$

$\cos^2\theta$ 的 $\left[-\frac\pi2,\frac\pi2\right]$ 区间积分 = $\frac\pi2$（可用 $\cos^2\theta = \frac{1+\cos2\theta}{2}$ 验证）：

$$\int_{-\pi/2}^{\pi/2} \cos^2\theta\,d\theta = \int_{-\pi/2}^{\pi/2} \frac{1+\cos2\theta}{2}\,d\theta
= \frac12\big[\theta + \tfrac12\sin2\theta\big]_{-\pi/2}^{\pi/2} = \frac12\left(\frac\pi2+\frac\pi2\right) = \frac\pi2.$$

所以

$$A = 2\sqrt{2} \cdot \frac\pi2 = \sqrt{2}\,\pi.$$

$\boxed{A = \sqrt{2}\,\pi}$

**【易错提醒】**
- ⚠️ **注意区域边界**：柱面 $x^2+y^2=2x$ 的极坐标是 $r=2\cos\theta$，这不是以原点为圆心的圆！$r$ 的上限是 $\theta$ 的函数，不能写成常数。
- ⚠️ $\theta$ 的范围是 $-\pi/2$ 到 $\pi/2$，不是 $0$ 到 $2\pi$。因为 $r=2\cos\theta\ge0$ 要求 $\cos\theta\ge0$。
- ⚠️ 曲面面积公式是 $\iint\sqrt{1+z_x^2+z_y^2}\,dA$，**不是** $\iint\sqrt{1+z_x^2+z_y^2}\,dS$（别在公式里用 $dS$ 表示投影面积元）。

> **要点：** 曲面面积问题的本质是"把曲面的小面积元投影到 $xy$ 面，再乘坡度系数"。坐标系的选择由投影区域的形状决定——本题投影是圆，故用极坐标。

**【补充解法：曲面参数化】**
直接把锥面参数化为
$$
\vec r(r,\theta)=(r\cos\theta,\ r\sin\theta,\ r),\quad
0\le r\le2\cos\theta,\ -\frac\pi2\le\theta\le\frac\pi2.
$$
有
$$
\left|\vec r_r\times\vec r_\theta\right|=\sqrt2\,r,
$$
故
$$
A=\int_{-\pi/2}^{\pi/2}\int_0^{2\cos\theta}\sqrt2\,r\,dr\,d\theta=\sqrt2\,\pi.
$$
参数化法不需要先写 $z_x,z_y$，但仍要准确确定柱面的投影范围。

## 二、曲线积分

### 第 6 题（第一类曲线积分）
计算 $\displaystyle I=\oint_L e^{\sqrt{x^2+y^2}}\,ds$，$L$ 为圆周 $x^2+y^2=a^2$（$a>0$）。

**答案：** $2\pi a\,e^a$

**解析：** 圆周参数化 $x=a\cos\theta,\ y=a\sin\theta$，$ds=a\,d\theta$。在 $L$ 上 $\sqrt{x^2+y^2}=a$ 为常数：

$$I=\int_0^{2\pi} e^a\cdot a\,d\theta=2\pi a\,e^a.$$

**【补充解法：常值乘弧长】**
第一类曲线积分可看成“沿曲线加权求长度”。本题权重 $e^{\sqrt{x^2+y^2}}$ 在圆周上恒为 $e^a$，圆周长为 $2\pi a$，所以
$$
I=e^a\cdot 2\pi a.
$$

> **要点：** 第一类曲线积分（对弧长）的 $ds$ 永远为正，与方向无关。被积函数在曲线上能化简就先化简。

## 三、格林公式

### 第 7 题 ★（格林公式·直接用）
计算 $\displaystyle I=\oint_L (x^2-2xy)\,dx+(x^2y-x)\,dy$，$L$ 为矩形 $0\le x\le 2,\ 0\le y\le 1$ 的正向边界。

**答案：** $4$

**【思路分析】**
$L$ 是闭曲线（矩形边界），$P,Q$ 在区域内没有奇点（多项式函数处处可导）——这就是格林公式的标准使用场景。格林公式把闭曲线上的第二类曲线积分转化为区域上的二重积分，计算量大大简化。如果不使用格林公式，需要把矩形的四条边分别参数化后逐段计算，工作量很大。

**【知识点回顾】**
格林公式：$\displaystyle\oint_L P\,dx+Q\,dy = \iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dA$，其中 $D$ 是 $L$ 所围的区域，$L$ 取正方向（逆时针）。

**【详细求解】**

**步骤 1：写出 $P,Q$ 并计算偏导**

$$P = x^2 - 2xy,\quad Q = x^2y - x.$$

$$\frac{\partial P}{\partial y} = -2x,\quad \frac{\partial Q}{\partial x} = 2xy - 1.$$

由格林公式：

$$I = \iint_D\Big((2xy-1) - (-2x)\Big)dA = \iint_D(2xy + 2x - 1)\,dA.$$

**步骤 2：将二重积分化为累次积分**

$D$ 是矩形 $[0,2]\times[0,1]$。

$$I = \int_{x=0}^{2} dx \int_{y=0}^{1} (2xy + 2x - 1)\,dy.$$

**步骤 3：先积内层 $y$**

固定 $x$：$\displaystyle\int_0^1 (2xy + 2x - 1)\,dy = \left[xy^2 + 2xy - y\right]_{y=0}^{1} = x + 2x - 1 = 3x - 1.$

**步骤 4：再积外层 $x$**

$$I = \int_0^2 (3x - 1)\,dx = \left[\frac32 x^2 - x\right]_0^2 = \frac32\cdot4 - 2 = 6 - 2 = 4.$$

$\boxed{I = 4}$

**【补充解法：直接沿四边积分校验】**
若不用格林公式，也可按矩形边界逆时针分四段算：
- $y=0,\ x:0\to2$：$\displaystyle\int_0^2 x^2\,dx=\frac83$；
- $x=2,\ y:0\to1$：$\displaystyle\int_0^1 (4y-2)\,dy=0$；
- $y=1,\ x:2\to0$：$\displaystyle\int_2^0 (x^2-2x)\,dx=\frac43$；
- $x=0,\ y:1\to0$：积分为 $0$。

四段相加为 $\frac83+\frac43=4$，与格林公式结果一致。

**【易错提醒】**
- ⚠️ **$\partial Q/\partial x - \partial P/\partial y$ 的顺序不要搞反。** 是 $Q$ 对 $x$ 减 $P$ 对 $y$，不是反过来。
- ⚠️ 矩形的正方向是逆时针（沿边界走，区域始终在左侧）。题目说"正向边界"就是指逆时针方向，直接套格林公式即可。

> **要点：** 面对闭曲线上的第二类曲线积分，**先检查格林公式的适用条件**（闭曲线？$P,Q$ 可导？区域内无奇点？）。满足条件时，格林公式把线积分降为二重积分，是曲线积分最有效的简化手段。

### 第 8 题 ★★（格林公式·含奇点挖洞）
计算 $\displaystyle I=\oint_L \frac{-y\,dx+x\,dy}{x^2+y^2}$，$L$ 为 $x^2+y^2=4$，逆时针方向。

**答案：** $2\pi$

**【思路分析】**
这道题是格林公式最经典的"陷阱"题。很多同学算 $\partial Q/\partial x = \partial P/\partial y$ 后直接说积分为零——**这是错的**。格林公式要求 $P,Q$ 在**整个区域内部**有连续偏导数，但这里 $(0,0)$ 处分母为零，$P,Q$ 无定义。原点（奇点）在 $L$ 之内，所以不能直接套格林公式。

这里需要"曲线救国"：挖去奇点周围的小区域（"挖洞"），在剩下的环形区域上用格林公式，再把小圆上的积分算出来。

**【详细求解】**

**步骤 1：识别奇点**

$$P = \frac{-y}{x^2+y^2},\quad Q = \frac{x}{x^2+y^2}.$$

分母 $x^2+y^2=0$ 仅在原点 $(0,0)$。原点是奇点，且原点被 $L$ 包围。

**步骤 2：验证 $Q_x = P_y$（在 $r\ne0$ 处）**

$$\frac{\partial Q}{\partial x} = \frac{(x^2+y^2)\cdot 1 - x\cdot 2x}{(x^2+y^2)^2} = \frac{y^2 - x^2}{(x^2+y^2)^2},$$

$$\frac{\partial P}{\partial y} = \frac{(x^2+y^2)\cdot(-1) - (-y)\cdot 2y}{(x^2+y^2)^2} = \frac{-x^2 - y^2 + 2y^2}{(x^2+y^2)^2} = \frac{y^2 - x^2}{(x^2+y^2)^2}.$$

所以 $\displaystyle\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 0$（只要 $x^2+y^2\ne0$）。

**步骤 3：挖洞构造无奇点区域**

在原点周围挖去半径为 $\varepsilon$（$0<\varepsilon<2$）的小圆盘。取小圆边界 $l$ 为**顺时针**方向（这样 $l$ 和 $L$ 围成的环形区域称为复连通区域，其正向边界为 $L$（逆时针）$\cup\ l$（顺时针））。

在环形区域 $D$（大圆内、小圆外）上，$P,Q$ 处处有连续偏导，可用格林公式：

$$\oint_L P\,dx+Q\,dy + \oint_l P\,dx+Q\,dy = \iint_D 0\,dA = 0.$$

因此

$$I = \oint_L = -\oint_l = \oint_{-l},$$

其中 $-l$ 表示 **$l$ 的逆时针方向**（便于参数化）。

**步骤 4：计算小圆上的积分（逆时针）**

小圆参数化：$x = \varepsilon\cos\theta,\ y = \varepsilon\sin\theta\ (0\le\theta\le 2\pi)$。

$$dx = -\varepsilon\sin\theta\,d\theta,\quad dy = \varepsilon\cos\theta\,d\theta.$$

代入被积表达式：

$$
\begin{aligned}
-y\,dx + x\,dy &= -(\varepsilon\sin\theta)\cdot(-\varepsilon\sin\theta\,d\theta) + (\varepsilon\cos\theta)\cdot(\varepsilon\cos\theta\,d\theta) \\
&= \varepsilon^2(\sin^2\theta + \cos^2\theta)\,d\theta = \varepsilon^2\,d\theta.
\end{aligned}
$$

分母 $x^2+y^2 = \varepsilon^2$。所以

$$\frac{-y\,dx+x\,dy}{x^2+y^2} = \frac{\varepsilon^2\,d\theta}{\varepsilon^2} = d\theta.$$

于是

$$I = \oint_{-l} d\theta = \int_0^{2\pi} d\theta = 2\pi.$$

$\boxed{I = 2\pi}$

**【直接参数法验证】**
本题也可以用直接参数化的方法验证：大圆 $x=2\cos\theta,y=2\sin\theta$，$dx=-2\sin\theta d\theta,dy=2\cos\theta d\theta$，代入得 $\frac{-y\,dx+x\,dy}{x^2+y^2} = \frac{4d\theta}{4} = d\theta$，积分为 $2\pi$。但大圆上的直接计算偶然简单是因为圆的半径是常数——如果 $L$ 是任意包含原点的闭曲线，直接参数化就不好算了，挖洞法的通用性更强。

**【补充解法：极角微分】**
在去掉原点的区域内，有
$$
d\theta=\frac{-y\,dx+x\,dy}{x^2+y^2}.
$$
因此积分就是极角沿曲线的总增量。圆周逆时针绕原点一圈，极角增加 $2\pi$，所以 $I=2\pi$。这也解释了为什么任意绕原点一圈的简单闭曲线都会得到同样结果。

**【易错提醒】**
- ⚠️ **$Q_x = P_y$ 只说明 $\nabla\times\vec F=0$，在有奇点的情况下不能说曲线积分为零。** 本题是考试最高频的"挖洞"经典，没有之一。
- ⚠️ 挖洞时取小圆**顺时针**，这样才能与大圆（逆时针）构成复连通区域的正向边界。如果都取逆时针，格林公式的符号会出错。
- ⚠️ 挖洞的结果与 $\varepsilon$ 无关——无论挖多大多小的洞，答案都是 $2\pi$。这是拓扑性质：$\frac{-y\,dx+x\,dy}{x^2+y^2}$ 是角度 1-形式，其绕奇点的积分就是 $2\pi$。

> **要点：** 判定流程——$\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$？是 $\rightarrow$ 区域内有奇点吗？有 $\rightarrow$ 挖洞法。答案是 $2\pi n$，其中 $n$ 是曲线绕原点的圈数（本题 $n=1$）。

### 第 9 题（格林公式·路径无关与全微分）
计算 $\displaystyle I=\int_{(1,1)}^{(2,3)}(2xy+y)\,dx+(x^2+x)\,dy$。

**答案：** $16$

**解析：** $P=2xy+y$，$Q=x^2+x$。$\dfrac{\partial Q}{\partial x}=2x+1=\dfrac{\partial P}{\partial y}$，在全平面成立 → 积分与路径无关。求势函数 $u$ 使 $du=P\,dx+Q\,dy$：

由 $u_x=2xy+y$ 积分得 $u=x^2y+xy+g(y)$；再 $u_y=x^2+x+g'(y)$，与 $Q$ 比较得 $g'(y)=0$。故 $u=x^2y+xy$。

$$I=u(2,3)-u(1,1)=(4\cdot 3+2\cdot 3)-(1\cdot 1+1\cdot 1)=18-2=16.$$

**【补充解法：选折线路径直接算】**
既然已知路径无关，可选最方便的折线：先从 $(1,1)$ 到 $(2,1)$，再从 $(2,1)$ 到 $(2,3)$。

第一段 $y=1,\ dy=0$：
$$
\int_1^2(2x+1)\,dx=[x^2+x]_1^2=4.
$$
第二段 $x=2,\ dx=0$：
$$
\int_1^3(4+2)\,dy=12.
$$
总和 $4+12=16$。

> **要点：** 验证 $Q_x=P_y$（单连通区域内）→ 路径无关 → 找势函数代入端点。比硬算任意路径快得多。

## 四、高斯公式

### 第 10 题 ★（高斯公式·直接用）
计算 $\displaystyle I=\oiint_\Sigma x\,dydz+y\,dzdx+z\,dxdy$，$\Sigma$ 为球面 $x^2+y^2+z^2=a^2$ 外侧。

**答案：** $4\pi a^3$

**解析：** 闭曲面外侧，$P=x,\ Q=y,\ R=z$，$\dfrac{\partial P}{\partial x}+\dfrac{\partial Q}{\partial y}+\dfrac{\partial R}{\partial z}=3$。高斯公式：

$$I=\iiint_\Omega 3\,dV=3\cdot\frac43\pi a^3=4\pi a^3.$$

**【补充解法：直接看球面法向量】**
球面外法向单位向量为 $\vec n=\frac{(x,y,z)}{a}$，而 $\vec F=(x,y,z)=a\vec n$。所以
$$
\vec F\cdot\vec n=a,\qquad
I=\oiint_\Sigma a\,dS=a\cdot4\pi a^2=4\pi a^3.
$$

> **要点：** $\vec F=(x,y,z)$ 的散度恒为 3，通量 = 3 × 体积。记住这个常数散度的快捷结论。

### 第 11 题 ★★（高斯公式·含奇点挖球）
计算 $\displaystyle I=\oiint_\Sigma \frac{x\,dydz+y\,dzdx+z\,dxdy}{(x^2+y^2+z^2)^{3/2}}$，$\Sigma$ 为任意包含原点的光滑闭曲面，外侧。

**答案：** $4\pi$

**【思路分析】**
这道题是第 8 题（格林挖洞）在高维的对应版。被积函数 $\frac{\vec r}{r^3}$ 是"点电荷的电场"（在物理上对应库仑定律），它的散度在除原点外处处为零。但原点是奇点且位于 $\Sigma$ 内部，不能直接套高斯公式说积分为零。

处理方法与第 8 题完全对应：挖去一个小球面，在剩余区域上用高斯公式，再补上小球面的通量。

**【详细求解】**

**步骤 1：向量形式化**

记 $\vec F = \dfrac{(x,y,z)}{(x^2+y^2+z^2)^{3/2}} = \dfrac{\vec r}{r^3}$，其中 $r = \sqrt{x^2+y^2+z^2}$。
所求积分即为 $\displaystyle I = \oiint_\Sigma \vec F\cdot d\vec S$（第二类曲面积分）。

**步骤 2：计算散度（$r\ne0$ 处）**

设 $P = \dfrac{x}{r^3},\ Q = \dfrac{y}{r^3},\ R = \dfrac{z}{r^3}$。用 $\dfrac{\partial r}{\partial x} = \dfrac{x}{r}$：

$$\frac{\partial P}{\partial x} = \frac{1\cdot r^3 - x\cdot 3r^2\cdot\frac{x}{r}}{r^6} = \frac{r^3 - 3x^2r}{r^6} = \frac{r^2 - 3x^2}{r^5}.$$

同理：
$$\frac{\partial Q}{\partial y} = \frac{r^2-3y^2}{r^5},\quad \frac{\partial R}{\partial z} = \frac{r^2-3z^2}{r^5}.$$

求和：
$$\nabla\cdot\vec F = \frac{(r^2-3x^2)+(r^2-3y^2)+(r^2-3z^2)}{r^5} = \frac{3r^2-3(x^2+y^2+z^2)}{r^5} = 0.$$

所以 $\nabla\cdot\vec F = 0$ 对一切 $r\ne0$ 成立。

**步骤 3：挖球法**

由于原点在 $\Sigma$ 内，散度公式在包含原点的区域上无效。挖去半径为 $\varepsilon$ 的小球 $B_\varepsilon(0)$，取球面 $S_\varepsilon$（**内侧**，即法向量指向原点）。记 $\Omega'$ 为 $\Sigma$ 与 $S_\varepsilon$ 之间的区域。

在 $\Omega'$ 上 $\vec F$ 处处有连续偏导，高斯公式给出：

$$\oiint_\Sigma \vec F\cdot d\vec S + \oiint_{S_\varepsilon(\text{内})} \vec F\cdot d\vec S = \iiint_{\Omega'} 0\,dV = 0.$$

因此

$$I = -\oiint_{S_\varepsilon(\text{内})} \vec F\cdot d\vec S = \oiint_{S_\varepsilon(\text{外})} \vec F\cdot d\vec S.$$

**步骤 4：计算小球面上的通量（外侧）**

在 $S_\varepsilon$ 上（外侧），$r=\varepsilon$，外法向单位向量 $\hat n = \dfrac{\vec r}{\varepsilon}$。

$$\vec F = \frac{\vec r}{\varepsilon^3} = \frac{1}{\varepsilon^2}\hat n,\quad \vec F\cdot\hat n = \frac{1}{\varepsilon^2}.$$

于是

$$I = \oiint_{S_\varepsilon} \frac{1}{\varepsilon^2}\,dS = \frac{1}{\varepsilon^2}\cdot 4\pi\varepsilon^2 = 4\pi.$$

$\boxed{I = 4\pi}$

**【补充解法：曲面变形思想】**
在不穿过原点的前提下，可以把任意闭曲面连续变形为包住原点的小球面。由于外壳区域内 $\nabla\cdot\vec F=0$，变形前后的通量相同；而小球面上的通量直接为
$$
\frac1{\varepsilon^2}\cdot4\pi\varepsilon^2=4\pi.
$$
这就是挖球法的几何化说法。

**【易错提醒】**
- ⚠️ **挖球时小球的法向方向容易搞错。** 环形区域的边界由两个面组成：外曲面 $\Sigma$ 取外侧 = $\hat n$ 向外；内曲面 $S_\varepsilon$ 对于环形区域来说内侧 = $\hat n$ 指向原点。上式的符号推导中，先把整体等式写出来，再移项，比心算符号可靠得多。
- ⚠️ 结果 $4\pi$ 与 $\varepsilon$ 无关，与 $\Sigma$ 的具体形状也无关。物理意义：点电荷的通量就是 $4\pi$ 倍电荷量（高斯定理）。
- ⚠️ 对比一下参数化直接算：如果 $\Sigma$ 正好是球面 $r=a$，直接算也会得到 $\frac{1}{a^2}\cdot 4\pi a^2 = 4\pi$。但挖球法的优势在于它对**任意**包含原点的闭曲面都成立。

> **要点：** "散度为 0 + 区域内有奇点" → 挖洞/挖球法。格林对应 $2\pi$，高斯对应 $4\pi$，都是拓扑不变量。方法总结——（1）挖去奇点周围的小圆/球；（2）在无奇点区域上用格林/高斯得 0；（3）补算小圆/球上的积分并取相反符号。

## 五、斯托克斯公式与场论

### 第 12 题 ★（斯托克斯公式）
计算 $\displaystyle I=\oint_L y\,dx+z\,dy+x\,dz$，$L$ 为平面 $x+y+z=1$ 与三坐标面所围三角形的边界，从 $z$ 轴正向看为逆时针。

**答案：** $-\dfrac32$

**解析：** $\vec F=(y,z,x)$。旋度

$$\nabla\times\vec F=\left(\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z},\ \frac{\partial P}{\partial z}-\frac{\partial R}{\partial x},\ \frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)=(0-1,\ 0-1,\ 0-1)=(-1,-1,-1).$$

取 $\Sigma$ 为平面三角形，由 $z=1-x-y$，有向面积元 $d\vec S=(-z_x,-z_y,1)\,dA=(1,1,1)\,dA$（与从 $+z$ 看逆时针的方向一致）。斯托克斯公式：

$$I=\iint_\Sigma(\nabla\times\vec F)\cdot d\vec S=\iint_{D_{xy}}(-1,-1,-1)\cdot(1,1,1)\,dA=\iint_{D_{xy}}(-3)\,dA.$$

$D_{xy}$ 是 $xy$ 面上三角形 $x\ge0,y\ge0,x+y\le1$，面积 $\dfrac12$：

$$I=-3\cdot\frac12=-\frac32.$$

**【补充解法：沿三边直接参数化】**
取与“从 $+z$ 轴看为逆时针”一致的方向：
$$
(0,0,1)\to(1,0,0)\to(0,1,0)\to(0,0,1).
$$
三段积分分别为
$$
-\frac12,\quad -\frac12,\quad -\frac12,
$$
故总积分为 $-\frac32$。直接法能校验斯托克斯公式中的方向符号。

> **要点：** 平面 $z=ax+by+c$ 的有向面积元 $(-a,-b,1)\,dA$ 直接把曲面积分投影到 $xy$ 面，省去参数化。方向用右手定则与"从某轴看逆时针"对应。

### 第 13 题（散度与旋度）
设 $\vec F_1=(x^2y,\ y^2z,\ z^2x)$，$\vec F_2=(xz,\ -y^2,\ x^2y)$。
（1）求 $\nabla\cdot\vec F_1$ 在 $(1,1,1)$ 处的值；
（2）求 $\nabla\times\vec F_2$。

**答案：** （1）$6$；（2）$(x^2,\ x-2xy,\ 0)$

**解析：**
（1）散度：
$$\nabla\cdot\vec F_1=\frac{\partial(x^2y)}{\partial x}+\frac{\partial(y^2z)}{\partial y}+\frac{\partial(z^2x)}{\partial z}=2xy+2yz+2xz.$$
在 $(1,1,1)$ 处：$2+2+2=6$。

（2）旋度：
$$\nabla\times\vec F_2=\begin{vmatrix}\vec i&\vec j&\vec k\\[2pt]\partial_x&\partial_y&\partial_z\\[2pt]xz&-y^2&x^2y\end{vmatrix}=\left(\frac{\partial(x^2y)}{\partial y}-0,\ \frac{\partial(xz)}{\partial z}-\frac{\partial(x^2y)}{\partial x},\ 0-\frac{\partial(xz)}{\partial y}\right)=(x^2,\ x-2xy,\ 0).$$

**【补充校验：分量公式】**
若记 $\vec F_2=(P,Q,R)$，则
$$
\nabla\times\vec F_2=(R_y-Q_z,\ P_z-R_x,\ Q_x-P_y).
$$
逐项代入得 $(x^2-0,\ x-2xy,\ 0-0)$。这个写法比行列式更便于检查第二分量的负号。

> **要点：** 散度是标量（三个偏导之和），旋度是向量（行列式展开，"后对前减前对后"）。两者别混。

## 六、常数项级数

### 第 14 题（收敛必要条件与部分和）
判断下列级数的敛散性：
（1）$\displaystyle\sum_{n=1}^\infty\frac{n}{n+1}$；
（2）$\displaystyle\sum_{n=1}^\infty\ln\frac{n+1}{n}$。

**答案：** （1）发散；（2）发散

**解析：**
（1）通项 $\dfrac{n}{n+1}\to 1\ne0$，不满足收敛的必要条件 $\sum u_n$ 收敛 $\Rightarrow u_n\to0$，故**发散**。
> 逆否命题是判发散利器：通项不趋于零，级数必发散。

（2）通项 $\ln\frac{n+1}{n}\to0$，必要条件满足，不能下结论。求部分和（裂项相消）：
$$S_n=\sum_{k=1}^n\ln\frac{k+1}{k}=\sum_{k=1}^n[\ln(k+1)-\ln k]=\ln(n+1)\to+\infty.$$
部分和无界，故**发散**。

**【补充解法：极限比较】**
第（2）题也可用等价无穷小：
$$
\ln\frac{n+1}{n}=\ln\left(1+\frac1n\right)\sim\frac1n.
$$
与调和级数 $\sum\frac1n$ 极限比较，故发散。

> **要点：** $u_n\to0$ 是收敛的必要非充分条件（调和级数 $\sum 1/n$ 即反例）。能裂项求 $S_n$ 就求，求不出再上审敛法。

## 七、正项级数审敛法

### 第 15 题 ★（比值审敛法）
判断下列级数的敛散性：
（1）$\displaystyle\sum_{n=1}^\infty\frac{n!}{3^n}$；
（2）$\displaystyle\sum_{n=1}^\infty\frac{n^n}{3^n\,n!}$。

**答案：** （1）发散；（2）收敛

**【思路分析】**
这两道题都含有 $n!$ 和 $a^n$ 的组合——比值法 $\rho=\lim\frac{u_{n+1}}{u_n}$ 是最对口的武器。因为 $u_{n+1}$ 和 $u_n$ 之间的 $n!$ 相消时效果很好，$a^n$ 也容易比。注意第（2）小题化简中会出现 $(1+\frac1n)^n\to e$ 这个经典极限。

**【详细求解】**

**（1）$\displaystyle\sum\frac{n!}{3^n}$**

**步骤 1：计算比值**

$$\frac{u_{n+1}}{u_n} = \frac{(n+1)!}{3^{n+1}} \cdot \frac{3^n}{n!} = \frac{(n+1)!}{n!} \cdot \frac{3^n}{3^{n+1}} = (n+1) \cdot \frac13 = \frac{n+1}{3}.$$

**步骤 2：取极限**

$$\rho = \lim_{n\to\infty} \frac{u_{n+1}}{u_n} = \lim_{n\to\infty} \frac{n+1}{3} = +\infty > 1.$$

$\rho>1$ → **发散**。

**（2）$\displaystyle\sum\frac{n^n}{3^n\,n!}$**

**步骤 1：计算比值**

$$
\begin{aligned}
\frac{u_{n+1}}{u_n}
&= \frac{(n+1)^{n+1}}{3^{n+1}(n+1)!} \cdot \frac{3^n n!}{n^n} \\
&= \frac{(n+1)^{n+1}}{n^n} \cdot \frac{n!}{(n+1)!} \cdot \frac{3^n}{3^{n+1}} \\
&= \frac{(n+1)^{n+1}}{n^n} \cdot \frac{1}{n+1} \cdot \frac13.
\end{aligned}
$$

合并 $(n+1)^{n+1}/(n+1) = (n+1)^n$：

$$\frac{u_{n+1}}{u_n} = \frac{(n+1)^n}{n^n} \cdot \frac13 = \left(\frac{n+1}{n}\right)^n \cdot \frac13 = \left(1 + \frac1n\right)^n \cdot \frac13.$$

**步骤 2：取极限**

$$\rho = \lim_{n\to\infty} \frac{u_{n+1}}{u_n} = \frac13 \cdot \lim_{n\to\infty} \left(1+\frac1n\right)^n = \frac{e}{3} \approx 0.906 < 1.$$

$\rho<1$ → **收敛**。

**【补充解法：Stirling 估计看第（2）题】**
由 $n!\sim\sqrt{2\pi n}\left(\frac ne\right)^n$，
$$
\frac{n^n}{3^n n!}\sim
\frac{1}{\sqrt{2\pi n}}\left(\frac e3\right)^n.
$$
因为 $\frac e3<1$，它比等比级数还多一个 $\frac1{\sqrt n}$ 因子，所以收敛。这个方法能直观看出 $e/3$ 从哪里来。

**【易错提醒】**
- ⚠️ 第（2）小题中，$n^n$ 和 $(n+1)^{n+1}$ 不要急着展开成幂，而是用比值化简的技巧：先消去 $n!$，再把 $(n+1)^{n+1}/(n+1) = (n+1)^n$，最后合并为 $(1+1/n)^n$。
- ⚠️ 记住经典极限：$\lim(1+1/n)^n = e$。在含 $n^n$ 的比值法中经常出现。
- ⚠️ 当 $\rho=1$ 时比值法失效，需要改用其他方法（比较法、积分法等）。

> **要点：** $n!$ 用比值法最好——相邻项的 $n!$ 能约掉，剩下多项式/指数。含 $n^n$ 的比值会化简到 $(1+1/n)^n\to e$。记住：$\rho<1$ 收敛，$\rho>1$ 发散，$\rho=1$ 换方法。

### 第 16 题（比较法与根值法）
判断下列级数的敛散性：
（1）$\displaystyle\sum_{n=1}^\infty\frac{1}{\sqrt{n^2+1}}$；
（2）$\displaystyle\sum_{n=1}^\infty\left(\frac{n}{2n+1}\right)^n$。

**答案：** （1）发散；（2）收敛

**解析：**
（1）通项 $\dfrac{1}{\sqrt{n^2+1}}\sim\dfrac1n$（$n\to\infty$），取 $v_n=\dfrac1n$，极限比较法 $\lim\frac{u_n}{v_n}=\lim\frac{n}{\sqrt{n^2+1}}=1$。$\sum\frac1n$ 发散（$p=1$），故原级数**发散**。

（2）通项是 $n$ 次方形式，用根值法 $\rho=\lim\sqrt[n]{u_n}=\lim\frac{n}{2n+1}=\frac12<1$，**收敛**。

**【补充解法：直接比较】**
（1）因 $\sqrt{n^2+1}\le n+1$，故
$$
\frac1{\sqrt{n^2+1}}\ge\frac1{n+1},
$$
而 $\sum\frac1{n+1}$ 发散，所以原级数发散。

（2）因 $0<\frac{n}{2n+1}<\frac12$，所以
$$
0<\left(\frac{n}{2n+1}\right)^n<\left(\frac12\right)^n,
$$
由比较法知原级数收敛。

> **要点：** 找 $p$-级数作参照时，先估通项的"有效阶"：$\sqrt{n^2+1}\sim n$，故 $v_n=1/n$。含 $[\,\cdot\,]^n$ 的通项首选根值法。

## 八、交错级数

### 第 17 题 ★★（绝对收敛与条件收敛）
判断 $\displaystyle\sum_{n=2}^\infty\frac{(-1)^n\ln n}{n}$ 是绝对收敛、条件收敛还是发散。

**答案：** 条件收敛

**【思路分析】**
任意项级数的判定套路是固定的"两步走"：

```
                 ┌── 绝对收敛(结束)
                 │
∑uₙ → 取绝对值 → 正项级数审敛法 ──┤
                 │               ┌── 交错级数? → 莱布尼茨 → 收敛→条件收敛
                 └── 发散 ──────┤
                               └── 非交错 → 其他方法
```

先用正项级数审敛法判 $\sum|u_n|$——如果收敛，就是绝对收敛，直接结束。如果发散，还需要看原级数是否收敛（本题是交错级数，用莱布尼茨判别法）。

**【详细求解】**

**第一步：判绝对值级数（正项级数）**

$$\sum_{n=2}^\infty\left|\frac{(-1)^n\ln n}{n}\right| = \sum_{n=2}^\infty \frac{\ln n}{n}.$$

这是一个正项级数。用比较法：当 $n\ge3$ 时 $\ln n > 1$，所以

$$\frac{\ln n}{n} > \frac{1}{n}\quad (n\ge3).$$

而调和级数 $\sum\frac1n$ 发散（$p$-级数 $p=1$）。由比较法——"小发散则大发散"——得 $\sum\frac{\ln n}{n}$ 发散。

结论：绝对值级数发散，故原级数**不是绝对收敛**。

**第二步：判原级数（交错级数）**

原级数 $\displaystyle\sum_{n=2}^\infty(-1)^n\frac{\ln n}{n}$ 是交错级数，用莱布尼茨判别法。

记 $u_n = \dfrac{\ln n}{n}$，需验证两个条件：

**条件①：$u_n \to 0$。** 由 $\displaystyle\lim_{n\to\infty}\frac{\ln n}{n} = 0$（当 $n$ 很大时，$n$ 的增长速度远快于 $\ln n$），✓ 成立。

**条件②：$u_n$ 单调递减。** 考察函数 $f(x)=\dfrac{\ln x}{x}$（$x>0$）：

$$f'(x) = \frac{1\cdot x - \ln x\cdot 1}{x^2} = \frac{1-\ln x}{x^2}.$$

当 $x>e$ 时 $f'(x)<0$，$f(x)$ 单调递减。因此当 $n\ge3$ 时 $u_n$ 单调递减，✓ 成立。

莱布尼茨条件满足，原级数**收敛**。

**第三步：综合结论**

原级数收敛，但绝对值级数发散 → **条件收敛**。

$\boxed{\text{条件收敛}}$

**【补充解法：积分判别绝对发散】**
绝对值级数也可用积分判别：
$$
\int_2^A\frac{\ln x}{x}\,dx=\frac12(\ln A)^2-\frac12(\ln2)^2\to+\infty.
$$
所以 $\sum\frac{\ln n}{n}$ 发散；再配合莱布尼茨判别原级数收敛，仍得条件收敛。

**【易错提醒】**
- ⚠️ **先判绝对值再判原级数，顺序不能颠倒。** 如果 $\sum|u_n|$ 收敛，直接就是绝对收敛，不需要再管原级数。
- ⚠️ 比较法中的 $\frac{\ln n}{n} > \frac1n$ 是从 $n\ge3$ 起才成立（$n=2$ 时 $\ln2\approx0.69<1$）。级数的敛散性只取决于**尾部**（前有限项可任意改动），所以从 $n\ge3$ 起成立就够了。
- ⚠️ 单调递减的验证：不要只看前几项，要用导数或 $u_{n+1}/u_n$ 严格证明。

> **要点：** 任意项级数判定流程——（1）取绝对值变成正项级数；（2）用正项级数审敛法判敛散性：收敛→绝对收敛，结束；发散→进入第（3）步；（3）看原级数是否是交错级数——是则莱布尼茨，收敛→条件收敛，发散→发散；否则用其他方法。

## 九、幂级数收敛域

### 第 18 题 ★（收敛半径与端点讨论）
求 $\displaystyle\sum_{n=1}^\infty\frac{(x-1)^n}{n\cdot 2^n}$ 的收敛域。

**答案：** $[-1,3)$

**解析：** 令 $t=x-1$，级数 $\sum\frac{t^n}{n\cdot2^n}$。用比值法（或系数公式）：

$$\rho=\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|=\lim\frac{n\cdot2^n}{(n+1)\cdot2^{n+1}}=\frac12\ \Rightarrow\ R=\frac1\rho=2.$$

收敛区间 $|t|<2$，即 $x\in(-1,3)$。讨论端点：
- $x=3$（$t=2$）：$\sum\frac{2^n}{n\cdot2^n}=\sum\frac1n$ 发散；
- $x=-1$（$t=-2$）：$\sum\frac{(-2)^n}{n\cdot2^n}=\sum\frac{(-1)^n}{n}$ 收敛（莱布尼茨）。

故收敛域 $\boxed{[-1,3)}$。

**【补充解法：化为对数级数】**
令 $u=\frac{x-1}{2}$，则原级数为
$$
\sum_{n=1}^{\infty}\frac{u^n}{n}.
$$
已知 $\sum\frac{u^n}{n}$ 在 $u\in[-1,1)$ 收敛，故
$$
-1\le\frac{x-1}{2}<1 \quad\Rightarrow\quad -1\le x<3.
$$
这种方法把端点讨论直接转化为熟悉的对数级数。

> **要点：** $\sum a_n(x-x_0)^n$ 的收敛区间以 $x_0$ 为中心对称，半径 $R$ 与 $\sum a_n x^n$ 相同。端点必须单独判，最容易漏。

### 第 19 题（缺项幂级数）
求 $\displaystyle\sum_{n=1}^\infty\frac{n}{2^n}x^{2n}$ 的收敛域。

**答案：** $(-\sqrt2,\sqrt2)$

**解析：** 级数只含 $x$ 的偶次幂，"缺项"，不能直接套系数公式 $R=1/\lim|a_{n+1}/a_n|$（会误得 $R=2$）。直接对通项用比值法：

$$\lim_{n\to\infty}\left|\frac{u_{n+1}(x)}{u_n(x)}\right|=\lim\frac{(n+1)x^{2(n+1)}/2^{n+1}}{n\,x^{2n}/2^n}=\lim\frac{n+1}{n}\cdot\frac{x^2}{2}=\frac{x^2}{2}.$$

由 $\frac{x^2}{2}<1$ 得 $|x|<\sqrt2$，$R=\sqrt2$。端点 $x=\pm\sqrt2$：通项 $\dfrac{n}{2^n}\cdot 2^n=n\to\infty\ne0$，发散。故收敛域 $\boxed{(-\sqrt2,\sqrt2)}$。

**【补充解法：令 $t=x^2$】**
把它看成关于 $t$ 的幂级数：
$$
\sum_{n=1}^{\infty}\frac{n}{2^n}t^n=\sum_{n=1}^{\infty}n\left(\frac t2\right)^n.
$$
已知 $\sum n q^n$ 当且仅当 $|q|<1$ 收敛，所以 $|t/2|<1$。又 $t=x^2\ge0$，得到 $x^2<2$，即 $|x|<\sqrt2$；端点仍因通项不趋零而发散。

> **要点：** 缺项幂级数（如 $x^{2n}$、$x^{2n+1}$）一律对通项整体用比值法或根值法求收敛域，不要用 $R=1/\rho$ 公式。

## 十、幂级数和函数

### 第 20 题 ★★（求和函数与应用）
（1）求 $\displaystyle\sum_{n=1}^\infty\frac{x^n}{n}$ 的和函数 $S(x)$，并写出收敛域；
（2）求 $\displaystyle\sum_{n=1}^\infty\frac{1}{n\cdot2^n}$ 的值；
（3）求 $\displaystyle\sum_{n=1}^\infty n\,x^n$ 的和函数。

**答案：** （1）$S(x)=-\ln(1-x)$，$x\in[-1,1)$；（2）$\ln2$；（3）$\dfrac{x}{(1-x)^2}$，$x\in(-1,1)$

**【思路分析】**
"和函数"问题的本质：给定一个幂级数 $\sum a_n x^n$，想找出一个封闭形式的函数 $S(x)$（比如 $\ln$、$e^x$、有理函数）使得 $S(x)=\sum a_n x^n$。核心工具是**对已知展开 $\frac1{1-x}=\sum x^n$ 进行求导和积分操作**：

- 通项分母含 $n$（如 $\frac{x^n}{n}$）→ 逐项求导能消去分母 → 得到 $\sum x^{n-1}$（等比级数）→ 积分还原
- 通项分子含 $n$（如 $n x^n$）→ 它是 $\sum x^n$ 的导数形式 → 对 $\frac1{1-x}$ 求导得到

第（2）问是（1）的一个重要应用：常数项级数 $\sum\frac1{n\cdot2^n}$ 就是和函数在 $x=\frac12$ 处的值。

**【详细求解】**

**（1）求 $\displaystyle\sum_{n=1}^\infty\frac{x^n}{n}$ 的和函数**

**步骤 1：逐项求导，消去分母 $n$**

$$S(x) = \sum_{n=1}^\infty \frac{x^n}{n}, \quad S'(x) = \sum_{n=1}^\infty \frac{n x^{n-1}}{n} = \sum_{n=1}^\infty x^{n-1} = \sum_{k=0}^\infty x^{k}.$$

（令 $k=n-1$）这就是等比级数，公比 $q=x$，当 $|x|<1$ 时收敛：

$$S'(x) = \frac{1}{1-x},\quad |x|<1.$$

**步骤 2：积分还原，得 $S(x)$**

由 $S'(x) = \frac{1}{1-x}$，且 $S(0) = 0$（$x=0$ 时级数每项为零），

$$S(x) = \int_0^x S'(t)\,dt = \int_0^x \frac{dt}{1-t} = -\ln(1-t)\Big|_0^x = -\ln(1-x).$$

**步骤 3：确定收敛域**

系数公式：$R=\lim\left|\frac{a_n}{a_{n+1}}\right|=\lim\frac{1/(n)}{1/(n+1)}=1$，故 $|x|<1$ 内绝对收敛。

端点在原级数中验证（不能只在和函数中代入来判断收敛性）：
- $x=1$：$\sum\frac1n$ 发散（调和级数）→ 不收敛
- $x=-1$：$\sum\frac{(-1)^n}{n}$ 莱布尼茨收敛 → 收敛

综上：$S(x)=-\ln(1-x)$，收敛域 $x\in[-1,1)$。

**（2）求常数项级数 $\displaystyle\sum\frac{1}{n\cdot2^n}$ 的值**

这就是和函数 $S(x)$ 在 $x=\frac12$ 处的值（$\frac12$ 在收敛域 $[-1,1)$ 内）：

$$\sum_{n=1}^\infty\frac{1}{n\cdot2^n} = S\!\left(\frac12\right) = -\ln\!\left(1-\frac12\right) = -\ln\frac12 = \ln2.$$

**（3）求 $\displaystyle\sum_{n=1}^\infty n x^n$ 的和函数**

**思路：** 对比 $\frac{d}{dx}x^n = n x^{n-1}$，所以 $n x^n = x \cdot n x^{n-1} = x \cdot \frac{d}{dx}x^n$。

从已知展开出发：

$$\sum_{n=0}^\infty x^n = \frac{1}{1-x},\quad |x|<1.$$

两边求导：

$$\sum_{n=1}^\infty n x^{n-1} = \frac{1}{(1-x)^2},\quad |x|<1.$$

两边乘以 $x$：

$$\sum_{n=1}^\infty n x^n = \frac{x}{(1-x)^2},\quad |x|<1.$$

收敛域：$|x|<1$，端点 $x=\pm1$ 时通项 $n(\pm1)^n$ 不趋于零，发散。

**【补充解法：有限和求导后取极限】**
对第（3）题，也可先写有限等比和
$$
\sum_{n=1}^{N}x^n=\frac{x(1-x^N)}{1-x}.
$$
两边对 $x$ 求导再乘 $x$，得到 $\sum_{n=1}^{N}n x^n$ 的表达式；当 $|x|<1$ 时含 $x^N$ 的余项趋于 $0$，极限仍为
$$
\sum_{n=1}^{\infty}n x^n=\frac{x}{(1-x)^2}.
$$
这个方法适合需要严格处理“先有限、后取极限”的场合。

**【易错提醒】**
- ⚠️ **逐项求导 / 逐项积分只能在收敛域内进行。** 在 $|x|<R$ 的任意闭子区间上可以逐项操作，求导/积分后的级数收敛半径不变。
- ⚠️ 写收敛域时要**用原级数判断端点**，不能只用最终和函数去代。比如 $S(x)=-\ln(1-x)$ 在 $x=-1$ 处有有限值 $-\ln2$，但原级数 $\sum\frac{x^n}{n}$ 能否在 $x=-1$ 收敛需要单独判断。
- ⚠️ 第（2）问中 $x=\frac12$ 要在收敛域内。如果误用 $x=2$（不在收敛域内），和函数表达式算出来也没意义。

> **要点：** 求和函数两个核心套路——
> - "分母有 $n$" → **求导**：$S(x)=\sum\frac{x^n}{n}$，$S'(x)=\sum x^{n-1}=\frac1{1-x}$，再积分
> - "分子有 $n$" → **利用导数**：$\sum n x^n = x(\sum x^n)' = \frac{x}{(1-x)^2}$
> - 和函数最重要的应用：$\sum a_n = S(x_0)$，把常数项级数求和问题转化为在某点代的函数值。

## 十一、函数的幂级数展开

### 第 21 题 ★（间接展开）
将 $f(x)=\arctan x$ 展开为 $x$ 的幂级数，并写出收敛域。

**答案：** $\displaystyle\arctan x=\sum_{n=0}^\infty\frac{(-1)^n}{2n+1}x^{2n+1}=x-\frac{x^3}{3}+\frac{x^5}{5}-\cdots,\quad x\in[-1,1]$

**解析：** 用已知展开 $\dfrac{1}{1+t}=\sum_{n=0}^\infty(-1)^n t^n$（$|t|<1$）。令 $t=u^2$：

$$\frac{1}{1+u^2}=\sum_{n=0}^\infty(-1)^n u^{2n},\quad |u|<1.$$

由 $\arctan x=\int_0^x\frac{du}{1+u^2}$，逐项积分：

$$\arctan x=\int_0^x\sum_{n=0}^\infty(-1)^n u^{2n}\,du=\sum_{n=0}^\infty(-1)^n\frac{x^{2n+1}}{2n+1},\quad |x|<1.$$

收敛域：$R=1$。端点 $x=1$：$\sum\frac{(-1)^n}{2n+1}$ 由莱布尼茨判别法收敛；$x=-1$：$\sum\frac{(-1)^n(-1)^{2n+1}}{2n+1}=-\sum\frac{(-1)^n}{2n+1}$ 也收敛。故 $x\in[-1,1]$。

**【补充解法：由导数反推】**
设
$$
F(x)=\sum_{n=0}^{\infty}\frac{(-1)^n}{2n+1}x^{2n+1}.
$$
在 $|x|<1$ 内逐项求导：
$$
F'(x)=\sum_{n=0}^{\infty}(-1)^n x^{2n}=\frac1{1+x^2}.
$$
又 $F(0)=0=\arctan0$，所以 $F(x)=\arctan x$。这能反向验证积分展开的正确性。

> **要点：** 间接展开法——利用 $\frac{1}{1-x}$、$e^x$、$\sin x$、$(1+x)^\alpha$ 等基本展开，配合**逐项求导/逐项积分**得到目标函数。$\arctan x$ 是"积分法"的代表。注意逐项积分后收敛域端点可能"扩进来"（这里两端都收敛）。

## 十二、傅里叶级数

### 第 22 题 ★★（傅里叶展开与求和）
将 $f(x)=x^2$ 在 $[-\pi,\pi]$ 上展开为傅里叶级数，并由此求 $\displaystyle\sum_{n=1}^\infty\frac{1}{n^2}$ 与 $\displaystyle\sum_{n=1}^\infty\frac{(-1)^{n+1}}{n^2}$。

**答案：** $\displaystyle x^2=\frac{\pi^2}{3}+4\sum_{n=1}^\infty\frac{(-1)^n}{n^2}\cos nx$；$\sum\frac1{n^2}=\frac{\pi^2}{6}$；$\sum\frac{(-1)^{n+1}}{n^2}=\frac{\pi^2}{12}$

**【思路分析】**
把 $f(x)=x^2$ 展成傅里叶级数是一个标准又关键的例题，原因有二：
1. 计算 $a_n$ 时需要**两次分部积分**，是积分技巧的典型训练；
2. 展开后代入特殊点（$x=\pi$ 和 $x=0$）可以得到 $\sum\frac1{n^2}=\frac{\pi^2}{6}$（巴塞尔问题）这个著名结果——这是傅里叶级数"求常数项级数和"的经典手法。

$f(x)=x^2$ 是偶函数，所以 $b_n=0$，只需求 $a_0$ 和 $a_n$。

**【详细求解】**

**步骤 1：计算 $a_0$**

$$a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} x^2\,dx = \frac{1}{\pi}\cdot\frac{2\pi^3}{3} = \frac{2\pi^2}{3}.$$

**步骤 2：计算 $a_n$（偶函数简化）**

$$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x^2\cos nx\,dx = \frac{2}{\pi}\int_0^{\pi} x^2\cos nx\,dx.$$

**步骤 3：分部积分 ①**

令 $u = x^2$，$dv = \cos nx\,dx$，则 $du = 2x\,dx$，$v = \frac{\sin nx}{n}$：

$$
\begin{aligned}
\int_0^{\pi} x^2\cos nx\,dx
&= \left[x^2 \cdot \frac{\sin nx}{n}\right]_0^{\pi} - \int_0^{\pi} \frac{\sin nx}{n} \cdot 2x\,dx \\
&= (\pi^2\cdot\frac{\sin n\pi}{n} - 0) - \frac{2}{n}\int_0^{\pi} x\sin nx\,dx.
\end{aligned}
$$

$\sin n\pi = 0$，第一项为零。剩下 $-\frac{2}{n}\int_0^{\pi} x\sin nx\,dx$。

**步骤 4：分部积分 ②**

令 $u = x$，$dv = \sin nx\,dx$，则 $du = dx$，$v = -\frac{\cos nx}{n}$：

$$
\begin{aligned}
\int_0^{\pi} x\sin nx\,dx
&= \left[x\cdot \left(-\frac{\cos nx}{n}\right)\right]_0^{\pi} + \int_0^{\pi} \frac{\cos nx}{n}\,dx \\
&= -\frac{\pi\cos n\pi}{n} + \frac{1}{n}\int_0^{\pi} \cos nx\,dx \\
&= -\frac{\pi(-1)^n}{n} + \frac{1}{n}\left[\frac{\sin nx}{n}\right]_0^{\pi} \\
&= -\frac{\pi(-1)^n}{n} + 0.
\end{aligned}
$$

所以 $\displaystyle\int_0^{\pi} x\sin nx\,dx = -\frac{\pi(-1)^n}{n}$。

**步骤 5：代回求 $a_n$**

$$
\begin{aligned}
\int_0^{\pi} x^2\cos nx\,dx
&= -\frac{2}{n} \cdot \left(-\frac{\pi(-1)^n}{n}\right) = \frac{2\pi(-1)^n}{n^2}.
\end{aligned}
$$

$$a_n = \frac{2}{\pi}\cdot\frac{2\pi(-1)^n}{n^2} = \frac{4(-1)^n}{n^2}.$$

**步骤 6：写出傅里叶级数**

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty a_n\cos nx = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty\frac{(-1)^n}{n^2}\cos nx.$$

$x^2$ 在 $[-\pi,\pi]$ 上连续，且 $f(-\pi)=f(\pi)=\pi^2$，所以傅里叶级数处处收敛于 $x^2$：

$$\boxed{x^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty\frac{(-1)^n}{n^2}\cos nx,\quad x\in[-\pi,\pi]}.$$

**步骤 7：求 $\displaystyle\sum\frac1{n^2}$（取 $x=\pi$）**

$x=\pi$ 时 $\cos n\pi = (-1)^n$：

$$\pi^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty\frac{(-1)^n\cdot(-1)^n}{n^2} = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty\frac1{n^2}.$$

解得

$$\sum_{n=1}^\infty\frac1{n^2} = \frac{\pi^2}{6}.$$

**步骤 8：求 $\displaystyle\sum\frac{(-1)^{n+1}}{n^2}$（取 $x=0$）**

$x=0$ 时 $\cos 0 = 1$：

$$0 = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty\frac{(-1)^n}{n^2}\ \Rightarrow\ \sum_{n=1}^\infty\frac{(-1)^n}{n^2} = -\frac{\pi^2}{12}.$$

所以 $\displaystyle\sum_{n=1}^\infty\frac{(-1)^{n+1}}{n^2} = \frac{\pi^2}{12}$。

**【补充解法：用 Parseval 求 $\sum1/n^2$】**
也可先用第 23 题中 $f(x)=x$ 的正弦级数系数 $b_n=\frac{2(-1)^{n+1}}n$。Parseval 等式给出
$$
\frac1\pi\int_{-\pi}^{\pi}x^2\,dx=\sum_{n=1}^{\infty}b_n^2
=4\sum_{n=1}^{\infty}\frac1{n^2}.
$$
左边为 $\frac{2\pi^2}{3}$，因此 $\sum\frac1{n^2}=\frac{\pi^2}{6}$。这条路不需要在 $x^2$ 的展开式中取 $x=\pi$，但依赖 Parseval 定理。

**【易错提醒】**
- ⚠️ **分部积分时注意符号。** 第一步分部积分中 $[uv]$ 项为零是因为 $\sin n\pi=0$，部分同学会在这里忘记把 $x=\pi$ 代进去检查。
- ⚠️ **$\cos n\pi = (-1)^n$**，这个关系每个傅里叶题都会用到。类似的还有 $\sin n\pi = 0$。
- ⚠️ $a_0$ 的系数是 $\frac12$，而 $a_n$（$n\ge1$）没有 $\frac12$。所以展开式中 $a_0/2 = \pi^2/3$，不要写成 $a_0 = \pi^2/3$。

> **要点：** 本题展示了傅里叶级数最强大的应用之一——**求常数项级数的和**。在展开式中代入特殊的 $x$ 值（如 $x=\pi, 0, \frac\pi2$），利用 $\cos nx$ 在这些点的值，可以解出许多经典求和公式。$\sum\frac1{n^2}=\frac{\pi^2}{6}$（巴塞尔问题）是最著名的一个。

### 第 23 题 ★（傅里叶级数与端点收敛）
将 $f(x)=x$（$-\pi<x<\pi$）展开为傅里叶级数，并讨论 $x=\pi$ 处级数收敛到何值。

**答案：** $\displaystyle x=2\sum_{n=1}^\infty\frac{(-1)^{n+1}}{n}\sin nx$（$-\pi<x<\pi$）；$x=\pi$ 处收敛到 $0$。

**解析：** $x$ 是奇函数，$a_0=a_n=0$。

$$b_n=\frac1\pi\int_{-\pi}^\pi x\sin nx\,dx=\frac{2}{\pi}\int_0^\pi x\sin nx\,dx.$$

分部积分：$\displaystyle\int_0^\pi x\sin nx\,dx=\left[-\frac{x\cos nx}{n}\right]_0^\pi+\frac1n\int_0^\pi\cos nx\,dx=-\frac{\pi(-1)^n}{n}$，故 $b_n=\dfrac{2(-1)^{n+1}}{n}$。

$$x=2\sum_{n=1}^\infty\frac{(-1)^{n+1}}{n}\sin nx,\quad -\pi<x<\pi.$$

**端点讨论：** $f$ 周期延拓后在 $x=\pi$ 处间断（左极限 $\pi$，右极限 $-\pi$）。由狄利克雷收敛定理，间断点处级数收敛于左右极限的平均：

$$\frac{f(\pi^-)+f(-\pi^+)}{2}=\frac{\pi+(-\pi)}{2}=0.$$

（也可直接验证：$\sin n\pi=0$，级数每项为 $0$，和为 $0$，与定理一致。）

**【补充应用：取特殊点得到莱布尼茨级数】**
在展开式中取 $x=\frac\pi2$：
$$
\frac\pi2=2\left(1-\frac13+\frac15-\frac17+\cdots\right),
$$
所以
$$
1-\frac13+\frac15-\frac17+\cdots=\frac\pi4.
$$
这说明傅里叶级数不仅能表示函数，也能求经典常数项级数。

> **要点：** 狄利克雷定理——连续点处级数收敛到 $f(x)$，间断点处收敛到左右极限的算术平均。这是傅里叶题必考的"端点取值"问题。

## 十三、微分方程

### 第 24 题 ★（一阶线性微分方程）
求解 $\displaystyle y'-\frac{2}{x}y=x^3$（$x\ne0$）。

**答案：** $\displaystyle y=\frac{x^4}{2}+C\,x^2$（$C$ 为任意常数）

**解析：** 标准一阶线性 $y'+p(x)y=q(x)$，此处 $p(x)=-\dfrac2x$，$q(x)=x^3$。积分因子

$$\mu(x)=e^{\int p\,dx}=e^{-2\ln|x|}=|x|^{-2}=x^{-2}\quad(x\ne0).$$

方程两边乘 $\mu$，左边凑成全导数：

$$x^{-2}y'-2x^{-3}y=x\ \Rightarrow\ (x^{-2}y)'=x.$$

积分：$x^{-2}y=\dfrac{x^2}{2}+C$，故

$$y=\frac{x^4}{2}+C\,x^2.$$

严格地说，由于方程在 $x=0$ 处无定义，通解应理解为在任一不跨过 $0$ 的区间上成立；若同时考虑 $(-\infty,0)$ 与 $(0,\infty)$，两侧的常数可以不同。

**【补充解法：降成可分离形式】**
令 $y=x^2u(x)$，则
$$
y'=2xu+x^2u'.
$$
代入原方程：
$$
2xu+x^2u'-\frac2x\cdot x^2u=x^3
\quad\Rightarrow\quad x^2u'=x^3.
$$
所以 $u'=x$，$u=\frac{x^2}{2}+C$，从而
$$
y=x^2u=\frac{x^4}{2}+Cx^2.
$$

> **要点：** 一阶线性方程的通法是积分因子。识别特征：$y'$ 与 $y$ 各出现一次（线性），$y$ 的系数是 $x$ 的函数。也可以用通解公式 $y=e^{-\int p}(\int q\,e^{\int p}dx+C)$，但乘积分因子凑全导更不易错。

### 第 25 题 ★★（二阶常系数·共振）
求解 $\displaystyle y''+y=\cos x$。

**答案：** $\displaystyle y=C_1\cos x+C_2\sin x+\frac{x}{2}\sin x$

**【思路分析】**
二阶常系数非齐次线性方程 $y''+y=\cos x$ 的标准求解流程：
1. 解齐次方程 $y''+y=0$ → 得 $y_h$
2. 根据右端 $f(x)=\cos x$ 的形式设特解 $y_p$
3. 将 $y_p$ 代入非齐次方程定系数

关键在于：右端 $\cos x$ 对应复数特征根 $\pm i$，而齐次方程的特征根正好也是 $\pm i$。这就产生了**共振**（数学上也叫"参数激励"），特解形式必须乘以 $x$（即设 $y_p = x(a\cos x+b\sin x)$），不能设 $y_p = a\cos x+b\sin x$。

**【知识点回顾】**
二阶常系数非齐次 $y''+py'+qy=f(x)$：
- 齐次解：由特征方程 $r^2+pr+q=0$ 的根决定
- 特解设法与右端 $f(x)$ 有关。对于 $f(x)=e^{\alpha x}(P_m(x)\cos\beta x+Q_m(x)\sin\beta x)$：
  - $\alpha+i\beta$ 不是特征根 → 特解不乘 $x$
  - $\alpha+i\beta$ 是单特征根（共振）→ 特解乘 $x$
  - $\alpha+i\beta$ 是重根 → 特解乘 $x^2$

本题 $\alpha=0,\ \beta=1$，$\alpha+i\beta=i$ 是单特征根，故乘 $x$。

**【详细求解】**

**步骤 1：齐次通解**

特征方程：$r^2+1=0$，解得 $r=\pm i$。

齐次通解：$y_h = C_1\cos x + C_2\sin x$。

**步骤 2：特解设法**

右端 $f(x)=\cos x$，对应 $\alpha=0,\ \beta=1$，即 $\alpha+i\beta=i$。
$i$ 是特征根（$\pm i$），发生共振，故设

$$y_p = x\,(a\cos x + b\sin x).$$

**步骤 3：求导代入**

$$
\begin{aligned}
y_p' &= (a\cos x+b\sin x) + x(-a\sin x+b\cos x) \\
    &= a\cos x + b\sin x - a x\sin x + b x\cos x, \\[4pt]
y_p'' &= -a\sin x + b\cos x - a\sin x - a x\cos x + b\cos x - b x\sin x \\
      &= -2a\sin x + 2b\cos x - a x\cos x - b x\sin x \\
      &= -2a\sin x + 2b\cos x - x(a\cos x+b\sin x).
\end{aligned}
$$

**步骤 4：代入原方程定系数**

$$y_p''+y_p = (-2a\sin x + 2b\cos x - x(a\cos x+b\sin x)) + x(a\cos x+b\sin x) = -2a\sin x + 2b\cos x.$$

令其等于 $\cos x$：$-2a\sin x + 2b\cos x = \cos x$。

比较系数：$\begin{cases} -2a = 0 \ \Rightarrow\ a=0, \\ 2b = 1 \ \Rightarrow\ b=\dfrac12. \end{cases}$

故特解 $y_p = \dfrac{x}{2}\sin x$。

**步骤 5：写出通解**

$$y = y_h + y_p = C_1\cos x + C_2\sin x + \frac{x}{2}\sin x.$$

$\boxed{y = C_1\cos x + C_2\sin x + \dfrac{x}{2}\sin x}$

**【补充解法：复指数法】**
先解复方程
$$
Y''+Y=e^{ix},
$$
最后取实部。因 $e^{ix}$ 与齐次解共振，设
$$
Y_p=Axe^{ix}.
$$
代入得
$$
Y_p''+Y_p=2iA e^{ix}.
$$
令 $2iA=1$，得 $A=\frac1{2i}=-\frac i2$。于是
$$
Y_p=-\frac i2xe^{ix}=\frac{x}{2}\sin x-\frac i2x\cos x,
$$
取实部得到 $y_p=\frac{x}{2}\sin x$，通解同上。

**【物理直觉与易错提醒】**
- ⚠️ **为什么乘 $x$？** 没有乘 $x$ 的话，设 $y_p=a\cos x+b\sin x$ 代入后方程左边为 $0$（因为 $\cos x,\sin x$ 是齐次解），无法匹配右端 $\cos x$。乘 $x$ 后求导会"多出来" $\sin x,\cos x$ 项，从而解出系数。这在物理上对应：驱动力频率等于系统固有频率 → 振幅随时间线性增长（共振）。
- ⚠️ 共振时特解 $y_p=\frac{x}{2}\sin x$ 的振幅 $\frac{x}{2}$ 随 $x$ 增大而无限增大 → 这是**无界解**。如果方程的物理背景是简谐振子，意味着外力的频率与振子固有频率一致时，振幅会无限增大（最终导致系统破坏）。
- ⚠️ 但不要混淆：本题的"共振"是数学上的特解乘以 $x$，与泰勒展开中的共振无关。

> **要点：** 二阶常系数非齐次方程的特解设法——口诀——**"看右端，查特征；跟谁一样，就乘 $x$"**。$f(x)=e^{\alpha x}\cos\beta x$ 时，看 $\alpha+i\beta$ 是否等于特征根：不是 → 直接设；是（共振）→ 乘以 $x$。
