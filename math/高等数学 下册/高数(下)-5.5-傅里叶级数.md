## 一、从幂级数到傅里叶级数

幂级数用多项式基 $1, x, x^2, \ldots$ 表示函数——泰勒展开把光滑函数变成多项式。但遇到**尖角**（$|x|$ 在 $x=0$）、**跳跃**（阶跃函数）、**周期振荡**（方波），幂级数就失效了。

傅里叶的突破：**换一套基函数**——用三角函数系：

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx)$$

| | 幂级数 | 傅里叶级数 |
|---|---|---|
| **基函数** | $1, x, x^2, x^3, \ldots$ | $1, \cos x, \sin x, \cos 2x, \sin 2x, \ldots$ |
| **擅长的函数** | 光滑、解析 | 周期函数、分段光滑 |
| **可否处理间断** | 不行 | 可以（收敛到平均值） |
| **可否处理尖角** | 不行 | 可以（收敛略慢） |
| **天然适配** | 局部逼近（$x\to 0$） | 全局逼近（整个区间） |
| **物理意义** | 不太直观 | 直接对应频率分量 |
| **核心工具** | 逐次求导 | 积分求系数 |
| **收敛依赖** | 高阶导数存在 | 分段光滑即可 |

> **重点：** 幂级数和傅里叶级数不是谁取代谁——幂级数适合局部光滑行为（微扰展开），傅里叶级数适合全局周期行为（信号处理、振动分析）。两者各占一席。

## 二、物理直觉：信号分解

### 2.1 钢琴键的启示

按下一个 A4 键（440 Hz），你听到的不只是 440 Hz 的正弦波。它还包含：
- **基频** 440 Hz —— 定音高
- **二次谐波** 880 Hz，三次谐波 1320 Hz，四次谐波 1760 Hz …

不同乐器弹同一个音，基频相同，但各次谐波的相对强度不同——这就是音色。小提琴二次谐波强，单簧管只有奇次谐波。

**傅里叶级数做的事情：给定一个周期信号，精确计算每个频率分量（谐波）的强度。**
- $a_n$（余弦系数）= $n$ 倍基频处的偶对称分量强度
- $b_n$（正弦系数）= $n$ 倍基频处的奇对称分量强度

把 $a_n$、$b_n$ 按频率排列，就得到了**频谱**。方波的频谱：只有奇次谐波（$n=1,3,5,\ldots$），幅度以 $1/n$ 递减。

> **技巧：** 拿到展开式，先看频谱——哪些 $n$ 非零？衰减多快？衰减越快（如 $1/n^2$），波形越光滑；衰减越慢（如 $1/n$），越接近方波，间断点附近振荡越强。

### 2.2 为什么必须是三角函数？

1. **正交性**：不同频率的三角函数内积为零，可以逐个分离系数。
2. **正弦波是 LTI 系统的特征函数**：线性时不变系统对正弦输入的响应仍是同频率正弦波。
3. **三角函数在 $[-\pi,\pi]$ 上完备**：任何满足狄利克雷条件的周期函数都能用它们精确表示。

## 三、三角函数系的正交性

在 $[-\pi,\pi]$ 上，三角函数系 $1, \cos x, \sin x, \cos 2x, \sin 2x, \ldots$ 构成正交函数系。

$$\int_{-\pi}^\pi \cos mx \cos nx\,dx = \begin{cases} 0 & m \neq n \\ \pi & m = n \neq 0 \\ 2\pi & m = n = 0 \end{cases}$$

$$\int_{-\pi}^\pi \sin mx \sin nx\,dx = \begin{cases} 0 & m \neq n \\ \pi & m = n \neq 0 \end{cases}$$

$$\int_{-\pi}^\pi \cos mx \sin nx\,dx = 0 \quad (\forall m,n)$$

$$\int_{-\pi}^\pi 1 \cdot \cos nx\,dx = 0,\qquad \int_{-\pi}^\pi 1 \cdot \sin nx\,dx = 0 \quad (n \geq 1)$$

（推导均用积化和差公式。）

正交性的含义：就像线性代数中正交向量能逐个投影分离坐标，我们也可以逐个分离频率分量而互不干扰——这是傅里叶方法精妙的核心。

## 四、傅里叶系数（欧拉-傅里叶公式）

假设 $f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx)$。

**求 $a_0$：** 两边在 $[-\pi,\pi]$ 上积分，右边除第一项外全部积分为零（正交性）：
$\int_{-\pi}^\pi f(x)dx = a_0\pi$

**求 $a_n$（$n \geq 1$）：** 两边乘 $\cos nx$ 再积分，只有 $\cos^2 nx$ 项非零：
$\int_{-\pi}^\pi f(x)\cos nx\,dx = a_n\pi$

**求 $b_n$：** 同理乘 $\sin nx$ 积分。

最终公式：

$$\boxed{a_n = \frac{1}{\pi}\int_{-\pi}^\pi f(x)\cos nx\,dx,\quad n=0,1,2,\ldots}$$

$$\boxed{b_n = \frac{1}{\pi}\int_{-\pi}^\pi f(x)\sin nx\,dx,\quad n=1,2,3,\ldots}$$

> **重点：** 级数第一项写 $\frac{a_0}{2}$ 而不是 $a_0$，是为了让 $a_0$ 的公式与 $a_n$（$n\geq 1$）统一——令 $n=0$ 时 $\cos 0x = 1$ 即可。但写级数时千万记住：**第一项是 $\frac{a_0}{2}$，不是 $a_0$！**

---

## 五、收敛定理（狄利克雷条件）

设 $f(x)$ 以 $2\pi$ 为周期，在 $[-\pi,\pi]$ 上满足：
1. **分段连续**：只有有限个第一类间断点
2. **分段单调**：只有有限个极值点

则傅里叶级数收敛，且：

$$\text{级数的和} = \begin{cases} f(x) & x \text{ 为连续点} \\[6pt] \dfrac{f(x^-)+f(x^+)}{2} & x \text{ 为间断点} \\[6pt] \dfrac{f(-\pi^+)+f(\pi^-)}{2} & x = \pm\pi \text{（端点）} \end{cases}$$

- 狄利克雷条件极宽松——绝大多数工程函数的傅里叶级数都收敛。
- 间断点处级数值是"跳一半"——左右极限均值。考试常在这里设陷阱。
- $x=\pm\pi$ 是周期延拓造成的特殊点，需单独检查。

**收敛速度规律：**

| 光滑程度 | 系数衰减 | 典型例子 |
|---|---|---|
| 有跳跃间断 | $a_n,b_n \sim O(1/n)$ | 方波、锯齿波 |
| 连续但导数有间断 | $a_n,b_n \sim O(1/n^2)$ | $f(x)=|x|$、三角波 |
| 一阶导数连续 | $a_n,b_n \sim O(1/n^3)$ | — |
| 无穷次可导 | 指数衰减 | 纯正弦/余弦 |

> **技巧：** 从系数衰减速度反推函数光滑程度。做完题若算出 $b_n \sim 1/n$，原函数大概率有跳跃间断——对照验证。

## 六、吉布斯现象（Gibbs Phenomenon）

用傅里叶级数的**有限项和**逼近有**跳跃间断**的函数时，间断点附近会出现过冲（overshoot）：**无论取多少项，过冲都不会消失**，只会被压缩到越来越靠近间断点。

定量结论：过冲幅度约等于跳跃高度的 **9%**（精确值约为 8.95%，来源于 $\frac{1}{\pi}\int_0^\pi \frac{\sin t}{t}dt - \frac12$）。

以方波为例：$N=1$ 项是一条正弦曲线；$N=11$ 项已接近方波，但跳跃处紧贴着一个尖峰；$N=101$ 项尖峰更窄更靠近间断点，但峰值丝毫不减。

本质原因：正弦函数系表示间断需要无限多高频分量叠加。有限项截断就是用光滑函数逼近间断——无论如何都有残余振荡。这被称为"傅里叶级数的耳朵"，历史上曾引起极大争议（拉格朗日以此反对傅里叶），吉布斯在 1899 年给出完整解释。

> **重点：** 吉布斯现象说明傅里叶级数在间断点处**不是一致收敛的**。任取 $N$ 项，总存在靠近间断点的位置使误差超过跳跃量的 ~9%。题目要求讨论逼近误差时务必提到这一点。

## 七、计算例题

### 例 1：$f(x)=x$ 在 $[-\pi,\pi]$ 上（奇函数）

周期 $2\pi$ 延拓。

**奇偶性：** $f(x)=x$ 是奇函数 → $a_n = 0$（$n=0,1,\ldots$）。

**计算 $b_n$：** $f(x)\sin nx$ 是偶函数，在 $[0,\pi]$ 上积分乘 2：

$$b_n = \frac{2}{\pi}\int_0^\pi x\sin nx\,dx$$

分部积分（$u=x$，$dv=\sin nx\,dx$）：

$$\int_0^\pi x\sin nx\,dx = \left.-\frac{x}{n}\cos nx\right|_0^\pi + \frac{1}{n}\int_0^\pi \cos nx\,dx = -\frac{\pi}{n}(-1)^n$$

$$b_n = \frac{2}{\pi} \cdot \left(-\frac{\pi}{n}(-1)^n\right) = \frac{2(-1)^{n+1}}{n}$$

**级数：**

$$x = 2\sum_{n=1}^\infty \frac{(-1)^{n+1}}{n}\sin nx,\quad -\pi < x < \pi$$

**端点：** $x=\pm\pi$ 处级数值 $= \frac{-\pi+\pi}{2} = 0$。

**频谱特征：** 所有 $b_n \neq 0$，$b_n \sim 1/n$ —— 有跳跃间断（在 $x=\pm\pi$ 周期延拓处），衰减较慢。

---

### 例 2：方波 $f(x)=\begin{cases}-1,&-\pi\leq x<0\\1,&0\leq x\leq\pi\end{cases}$（奇函数）

**奇偶性：** 奇函数 → $a_n = 0$。

**计算 $b_n$：**

$$b_n = \frac{2}{\pi}\int_0^\pi 1\cdot\sin nx\,dx = \frac{2}{\pi}\left[-\frac{\cos nx}{n}\right]_0^\pi = \frac{2}{\pi}\cdot\frac{1-(-1)^n}{n}$$

- $n$ 偶数（$n=2k$）：$(-1)^n=1$，$b_n=0$
- $n$ 奇数（$n=2k+1$）：$(-1)^n=-1$，$b_n = \frac{4}{n\pi}$

**级数：**

$$f(x) = \frac{4}{\pi}\sum_{k=0}^\infty \frac{\sin(2k+1)x}{2k+1} = \frac{4}{\pi}\left(\sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5} + \cdots\right)$$

**间断点 $x=0$：** 级数值 $= \frac{-1+1}{2} = 0$，展开式每项 $\sin 0 = 0$。$\checkmark$

**莱布尼茨公式：** 在连续点 $x=\frac{\pi}{2}$ 代入：$1 = \frac{4}{\pi}(1 - \frac13 + \frac15 - \frac17 + \cdots)$，即 $\frac{\pi}{4} = 1 - \frac13 + \frac15 - \frac17 + \cdots$ —— 经典考题中的数项级数求值。

**频谱特征：** 只有奇次谐波，$b_n \sim 1/n$（$1/f$ 谱）。有跳跃间断，吉布斯现象明显。

---

### 例 3：$f(x)=|x|$ 在 $[-\pi,\pi]$ 上（偶函数，$a_n \neq 0$）

周期 $2\pi$ 延拓。三角波——连续但导数有间断（$x=0, \pm\pi$ 处有尖角）。

**奇偶性：** 偶函数 → $b_n = 0$。

**计算 $a_0$：**

$$a_0 = \frac{1}{\pi}\int_{-\pi}^\pi |x|dx = \frac{2}{\pi}\int_0^\pi x\,dx = \frac{2}{\pi}\cdot\frac{\pi^2}{2} = \pi$$

**计算 $a_n$（$n \geq 1$）：**

$$a_n = \frac{2}{\pi}\int_0^\pi x\cos nx\,dx$$

分部积分（$u=x$，$dv=\cos nx\,dx$）：

$$\int_0^\pi x\cos nx\,dx = \left.\frac{x}{n}\sin nx\right|_0^\pi - \frac{1}{n}\int_0^\pi \sin nx\,dx = 0 + \frac{\cos n\pi - 1}{n^2} = \frac{(-1)^n-1}{n^2}$$

$$a_n = \frac{2}{\pi}\cdot\frac{(-1)^n-1}{n^2}$$

- $n$ 偶数：$a_n = 0$
- $n$ 奇数（$n=2k+1$）：$a_n = -\frac{4}{n^2\pi}$

**级数：**

$$|x| = \frac{\pi}{2} - \frac{4}{\pi}\sum_{k=0}^\infty \frac{\cos(2k+1)x}{(2k+1)^2} = \frac{\pi}{2} - \frac{4}{\pi}\left(\cos x + \frac{\cos 3x}{9} + \frac{\cos 5x}{25} + \cdots\right)$$

**特殊值：** $x=0$ 给出 $\frac{\pi^2}{8} = 1 + \frac{1}{3^2} + \frac{1}{5^2} + \cdots$。$x=\pi$ 处级数连续（三角波在 $\pm\pi$ 无间断），$f(\pi)=\pi$，验证一致。

**频谱特征：** 只有奇次余弦谐波，$a_n \sim 1/n^2$ —— 函数连续，衰减快，无 Gibbs 现象。

---

### 例 4：$[0,\pi]$ 上的延拓对比（$f(x)=x$）

$f(x)=x$ 只定义在 $[0,\pi]$ 上，展开不唯一。

**奇延拓 → 纯正弦级数：** 结果与例 1 相同。
$$x = 2\sum_{n=1}^\infty \frac{(-1)^{n+1}}{n}\sin nx,\quad 0 \leq x < \pi$$

**偶延拓 → 纯余弦级数：** 延拓到 $[-\pi,\pi]$ 上得 $f(x)=|x|$，结果与例 3 相同。
$$x = \frac{\pi}{2} - \frac{4}{\pi}\sum_{k=0}^\infty \frac{\cos(2k+1)x}{(2k+1)^2},\quad 0 \leq x \leq \pi$$

> **重点：** 同一个函数在 $[0,\pi]$ 上，奇延拓和偶延拓给出的级数完全不同——一个全是正弦，一个全是余弦。延拓方式由**边界条件**决定：固定端（$f(0)=f(\pi)=0$）适合正弦展开；自由端（$f'(0)=f'(\pi)=0$）适合余弦展开。

## 八、奇偶函数的简化

### 偶函数 → 余弦级数

$f(x)$ 偶 $\implies$ $f(x)\sin nx$ 奇 $\implies$ $b_n=0$：

$$a_n = \frac{2}{\pi}\int_0^\pi f(x)\cos nx\,dx \quad (n=0,1,2,\ldots)$$

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty a_n \cos nx$$

### 奇函数 → 正弦级数

$f(x)$ 奇 $\implies$ $f(x)\cos nx$ 奇 $\implies$ $a_n=0$：

$$b_n = \frac{2}{\pi}\int_0^\pi f(x)\sin nx\,dx \quad (n=1,2,3,\ldots)$$

$$f(x) = \sum_{n=1}^\infty b_n \sin nx$$

> **技巧：** 拿到题目先花 10 秒判断奇偶性——计算量直接减半。最怕忘记判断，吭哧算完 $a_n$ 发现全是零。

## 九、周期为 $2l$ 的函数

当周期不是 $2\pi$ 而是 $2l$ 时，做变量代换 $t = \frac{\pi x}{l}$ 将 $[-l,l]$ 映射到 $[-\pi,\pi]$。

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty \left(a_n\cos\frac{n\pi x}{l} + b_n\sin\frac{n\pi x}{l}\right)$$

$$a_n = \frac{1}{l}\int_{-l}^l f(x)\cos\frac{n\pi x}{l}\,dx,\quad b_n = \frac{1}{l}\int_{-l}^l f(x)\sin\frac{n\pi x}{l}\,dx$$

**记忆口诀：** $\pi \to l$，$nx \to \frac{n\pi x}{l}$，$\frac{1}{\pi} \to \frac{1}{l}$。

奇/偶函数在 $[0,l]$ 上的简化同样适用：
- 偶函数：$a_n = \frac{2}{l}\int_0^l f(x)\cos\frac{n\pi x}{l}dx$，$b_n=0$
- 奇函数：$b_n = \frac{2}{l}\int_0^l f(x)\sin\frac{n\pi x}{l}dx$，$a_n=0$

## 十、进阶提要

Parseval 恒等式（能量守恒）：$\frac{1}{\pi}\int_{-\pi}^\pi [f(x)]^2dx = \frac{a_0^2}{2} + \sum_{n=1}^\infty (a_n^2+b_n^2)$，总能量 = 各频率分量能量之和。复指数形式 $f(x)=\sum c_n e^{inx}$ 利用欧拉公式给出更紧凑的表达。两者在后续的傅里叶变换中全面展开。

## 十一、易错点

1. **级数第一项是 $\frac{a_0}{2}$，不是 $a_0$**：公式为了统一才让 $a_0$ 的积分形式与 $a_n$ 一致，写级数时必须除以 2。

2. **间断点处级数值取左右极限的平均**：$\frac{f(x^-)+f(x^+)}{2}$，不是任取一边。

3. **端点 $x=\pm\pi$ 需单独检查**：周期延拓可能在端点制造新的间断，级数值 $= \frac{f(-\pi^+)+f(\pi^-)}{2}$。

4. **先判断奇偶性再算**：奇函数 $a_n=0$，偶函数 $b_n=0$——省一半工作量。

5. **分部积分后注意边界项**：$\sin n\pi = 0$，$\cos n\pi = (-1)^n$。

6. **周期 $2l$ 时代换公式不要记混**：$\pi \to l$，$nx \to \frac{n\pi x}{l}$，$\frac{1}{\pi} \to \frac{1}{l}$。

7. **奇延拓 ↔ 正弦级数，偶延拓 ↔ 余弦级数**：奇 ↔ sin，偶 ↔ cos——不要记反。

8. **积分 $\int \cos nx\,dx$ 和 $\int \sin nx\,dx$ 记得除 $n$**：$\int \cos nx = \frac{1}{n}\sin nx$，$\int \sin nx = -\frac{1}{n}\cos nx$。

求 $f(x) = \begin{cases} -x, & -\pi \leq x < 0 \\ x, & 0 \leq x \leq \pi \end{cases}$ 在 $[-\pi,\pi]$ 上的傅里叶级数展开。（提示：判断奇偶性。）

<summary><b>答案</b></summary>

$f(x)=|x|$ 是偶函数 → $b_n=0$。与例 3 计算一致：
$$a_0=\pi,\qquad a_n=\frac{2}{\pi}\int_0^\pi x\cos nx\,dx=\frac{2[(-1)^n-1]}{\pi n^2}$$
$$f(x)=\frac{\pi}{2}-\frac{4}{\pi}\sum_{k=0}^\infty \frac{\cos(2k+1)x}{(2k+1)^2}$$

### 习题 2（偶函数，余弦级数）
求 $f(x) = x^2$（$-\pi \leq x \leq \pi$）的傅里叶级数展开。（提示：偶函数，$b_n=0$，需两次分部积分。）

<details>
<summary><b>答案</b></summary>

$$a_0 = \frac{2}{\pi}\int_0^\pi x^2dx = \frac{2\pi^2}{3}$$
$$a_n = \frac{2}{\pi}\int_0^\pi x^2\cos nx\,dx = \frac{4(-1)^n}{n^2}$$
$$x^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty \frac{(-1)^n}{n^2}\cos nx,\quad -\pi \leq x \leq \pi$$

在 $x=\pi$ 处可得 $\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}$（巴塞尔问题）。
</details>

---

### 习题 3（分段函数，含间断）
求 $f(x) = \begin{cases} 0, & -\pi \leq x < 0 \\ \pi, & 0 \leq x < \pi \end{cases}$（周期 $2\pi$ 延拓）的傅里叶级数，验证 $x=0$ 处级数值。

<details>
<summary><b>答案</b></summary>

$$a_0 = \frac{1}{\pi}\int_0^\pi \pi\,dx = \pi,\quad a_n = \frac{1}{\pi}\int_0^\pi \pi\cos nx\,dx = 0\;(n\geq 1)$$
$$b_n = \frac{1}{\pi}\int_0^\pi \pi\sin nx\,dx = \frac{1-(-1)^n}{n}$$

$$f(x) = \frac{\pi}{2} + \sum_{k=0}^\infty \frac{2}{2k+1}\sin(2k+1)x$$

$x=0$ 处：级数值 $= \frac{0+\pi}{2} = \frac{\pi}{2}$，与 $a_0/2 = \pi/2$ 一致。$\checkmark$
</details>

### 习题 4（周期 $2l$）
将 $f(x) = x$（$-1 < x < 1$，周期 $2$）展开为傅里叶级数。

<details>
