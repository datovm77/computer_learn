## 第一部分：格林公式

### 一、格林公式的诞生——为什么需要它？

你已经会计算第二类曲线积分 $\oint_L P\,dx + Q\,dy$ 了。但有些曲线弯弯绕绕，参数化之后算到手酸。

格林公式的精妙之处在于：**它把沿边界曲线的积分，翻译成了在区域内部的二重积分。**

曲线虽然弯曲复杂，但它围起来的区域往往是规则的圆、矩形、三角形——二重积分反而好算。这就是格林公式的价值：用"内部"的简单去驯服"边界"的复杂。

---

### 二、公式的陈述

设 $D$ 是平面上由分段光滑闭曲线 $L$ 所围成的有界闭区域，$P(x,y)$、$Q(x,y)$ 在 $D$（含边界 $L$）上有连续一阶偏导数，则：

$$\boxed{\oint_L P\,dx + Q\,dy = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) dA}$$

其中 $L$ 取**正方向**——即沿此方向行走时，区域 $D$ 始终在你的**左手边**（逆时针为正方向）。

---

### 三、公式的三种理解方式

#### 理解一：几何直觉——微环量的叠加

想象把区域 $D$ 切成无数个小方块。每个小方块的边界都有一个"微环量"（小圈积分），而相邻小块的公共边方向相反，彼此抵消。最终只剩下**最外圈边界** $L$ 上的积分活了下来。

这就是：外部环量 = 所有内部微旋转之和，即 $\oint_L = \iint_D$。

#### 理解二：物理直觉——流场的旋转

把 $(P, Q)$ 看作平面流速场。$\oint_L P\,dx + Q\,dy$ 是流体沿 $L$ 的**环量**（circulation），衡量流体绕 $L$ 旋转的倾向。

而 $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}$ 是该流场在每一点的**旋转强度**（二维旋度）。格林公式说的是：**总环量 = 内部所有微旋转的累积**。

#### 理解三：代数直觉——反对称微分

格林公式本质上是二维的"分部积分"。牛顿-莱布尼茨公式说"边界值 = 内部导数的积分"（$f(b)-f(a) = \int_a^b f'\,dx$），格林公式是它在二维平面上的推广。

---

### 四、使用条件（必须牢记！）

| 条件 | 含义 | 不满足时怎么办 |
|------|------|----------------|
| $L$ 封闭 | 曲线首尾相连 | 不能直接用格林公式，需补线段构成封闭曲线 |
| $L$ 取正方向 | 逆时针（外边界）；如有内边界则内边界取顺时针 | 反向走差一个负号 |
| $P,Q$ 在 $D$ 内连续可偏导 | 区域内部没有奇点 | 挖去奇点，用复连通域的格林公式 |

> **致命易错点：** 格林公式要求 $P,Q$ 在**整个区域 $D$ 内部**都有连续偏导。如果被积函数在某一点无定义（比如原点），就不能直接用格林公式，必须"挖洞"处理。

---

### 五、格林公式的三大应用

#### 应用一：简化曲线积分计算

**思路：** 曲线复杂但区域简单时，右转二重积分。

#### 应用二：求平面区域的面积

由格林公式，若取 $P,Q$ 使得 $Q_x - P_y = 1$，则：

$$S_D = \iint_D 1\,dA = \oint_L P\,dx + Q\,dy$$

常用的三组选择：

$$S_D = \oint_L x\,dy = -\oint_L y\,dx = \frac{1}{2}\oint_L (x\,dy - y\,dx)$$

> **直觉：** 面积可以通过沿边界"扫一圈"得到——这正是测量仪器（面积仪）的工作原理。

#### 应用三：判定曲线积分与路径无关

在**单连通域**（没有洞的区域）内，以下四条等价：

$$\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y} \iff \oint_L P\,dx+Q\,dy = 0 \iff \text{路径无关} \iff \exists u,\; du=P\,dx+Q\,dy$$

> **记忆：** $Q_x = P_y$ 是"通行证"——有了它，积分就不在乎你走哪条路了。

---

### 六、复连通域的格林公式

如果区域 $D$ 有"洞"（比如去掉原点的圆环区域），怎么办？

设 $D$ 由外边界 $L_1$（正方向=逆时针）和内边界 $L_2$（正方向=顺时针）围成，则：

$$\oint_{L_1^+} P\,dx+Q\,dy + \oint_{L_2^-} P\,dx+Q\,dy = \iint_D (Q_x - P_y)\,dA$$

其中 $L_2^-$ 表示内边界取顺时针。

**典型手法：** 当 $Q_x - P_y = 0$ 但区域不单连通时，在奇点外围画一个小圆 $l$，利用等式：

$$\oint_{L^+} = \oint_{l^+}$$

把复杂曲线 $L$ 上的积分"等价替换"为逆时针小圆 $l^+$ 上的积分，小圆上参数化好算。

## 第一部分例题

### 例 1：直接使用格林公式（基础）

计算 $\oint_L (x^2-2xy)\,dx + (x^2y-x)\,dy$，$L$ 为矩形 $0\leq x\leq 2,\; 0\leq y\leq 1$ 的正方向边界。

**解：** 验证使用条件：$L$ 封闭、正方向、$P,Q$ 处处连续可偏导。

$$P = x^2 - 2xy,\quad Q = x^2y - x$$

$$\frac{\partial Q}{\partial x} = 2xy - 1, \quad \frac{\partial P}{\partial y} = -2x$$

$$Q_x - P_y = (2xy-1) - (-2x) = 2xy + 2x - 1$$

由格林公式：

$$\oint_L = \iint_D (2xy+2x-1)\,dA = \int_0^2 dx \int_0^1 (2xy+2x-1)\,dy$$

$$= \int_0^2 \left[xy^2+2xy-y\right]_0^1 dx = \int_0^2 (x+2x-1)\,dx = \int_0^2 (3x-1)\,dx = \left[\frac{3x^2}{2}-x\right]_0^2 = 4$$

> **对比：** 如果不用格林公式，需要把矩形的四条边分别参数化后逐段计算，工作量大得多。

---

### 例 2：格林公式求面积

求星形线 $\begin{cases} x = a\cos^3 t \\ y = a\sin^3 t \end{cases}$（$0\leq t\leq 2\pi$）所围面积。

**解：** 用面积公式 $S = \frac{1}{2}\oint_L (x\,dy - y\,dx)$。

$$dx = -3a\cos^2 t\sin t\,dt, \quad dy = 3a\sin^2 t\cos t\,dt$$

$$x\,dy - y\,dx = a\cos^3 t \cdot 3a\sin^2 t\cos t\,dt - a\sin^3 t \cdot (-3a\cos^2 t\sin t)\,dt$$

$$= 3a^2\cos^4 t\sin^2 t\,dt + 3a^2\sin^4 t\cos^2 t\,dt = 3a^2\cos^2 t\sin^2 t(\cos^2 t+\sin^2 t)\,dt$$

$$= 3a^2\cos^2 t\sin^2 t\,dt = \frac{3a^2}{4}\sin^2 2t\,dt$$

$$S = \frac{1}{2}\int_0^{2\pi}\frac{3a^2}{4}\sin^2 2t\,dt = \frac{3a^2}{8}\cdot\pi = \frac{3\pi a^2}{8}$$

> **点评：** 直接算面积需要用二重积分处理非标准区域，而格林公式将面积问题转化为曲线积分，参数化即可。

---

### 例 3：路径无关与全微分求积

计算 $\int_{(1,1)}^{(2,3)} (2xy+y)\,dx + (x^2+x)\,dy$。

**解法一：判断路径无关 + 选简单路径**

$$P = 2xy+y, \quad Q = x^2+x$$

$$\frac{\partial P}{\partial y} = 2x+1, \quad \frac{\partial Q}{\partial x} = 2x+1$$

$P_y = Q_x$，在全平面（单连通域）成立，故路径无关。

选折线路径：$(1,1)\to(2,1)\to(2,3)$

第一段：$y=1,\; dy=0,\; x: 1\to 2$

$$\int_1^2 (2x\cdot1+1)\,dx = \left[x^2+x\right]_1^2 = 6-2 = 4$$

第二段：$x=2,\; dx=0,\; y: 1\to 3$

$$\int_1^3 (4+2)\,dy = 6\cdot 2 = 12$$

$$\text{总计} = 4 + 12 = 16$$

**解法二：求原函数（全微分方法）**

由 $u_x = P = 2xy+y$，积分得 $u = x^2y + xy + \varphi(y)$。

再由 $u_y = x^2 + x + \varphi'(y) = Q = x^2+x$，得 $\varphi'(y) = 0$，故 $\varphi(y) = C$。

原函数 $u = x^2y + xy$。

$$\int_{(1,1)}^{(2,3)} = u(2,3) - u(1,1) = (4\cdot3+2\cdot3) - (1+1) = 18-2 = 16$$

> **两种解法对比：** 解法一适合"看一眼就知道路径无关"的场景；解法二更系统化，当起终点距离远或折线不好选时更方便。

### 例 4：含奇点的曲线积分（复连通域处理）

计算 $\oint_L \frac{-y\,dx+x\,dy}{x^2+y^2}$，$L$ 是以原点为圆心、半径为 2 的圆，逆时针方向。

**分析：** 令 $P = \frac{-y}{x^2+y^2}$，$Q = \frac{x}{x^2+y^2}$。

先检查 $Q_x - P_y$：

$$\frac{\partial Q}{\partial x} = \frac{(x^2+y^2)-x\cdot 2x}{(x^2+y^2)^2} = \frac{y^2-x^2}{(x^2+y^2)^2}$$

$$\frac{\partial P}{\partial y} = \frac{-(x^2+y^2)+y\cdot 2y}{(x^2+y^2)^2} = \frac{y^2-x^2}{(x^2+y^2)^2}$$

所以 $Q_x - P_y = 0$！但**不能直接说积分为零**——因为 $P,Q$ 在原点无定义，而原点在 $L$ 围成的区域**内部**，区域不是单连通的。

**挖洞法：** 在原点画小圆 $l: x^2+y^2=\varepsilon^2$（$\varepsilon$ 足够小），取顺时针方向。在环形区域 $D$（大圆减小圆）内 $Q_x - P_y = 0$，由复连通域的格林公式：

$$\oint_{L^+} + \oint_{l^-} = \iint_D 0\,dA = 0$$

故 $\oint_L = -\oint_{l^-} = \oint_{l^+}$（把小圆改为逆时针）。

在小圆 $l$ 上参数化：$x=\varepsilon\cos t,\; y=\varepsilon\sin t,\; t\in[0,2\pi]$。

$$\oint_{l^+} = \int_0^{2\pi}\frac{-\varepsilon\sin t\cdot(-\varepsilon\sin t)+\varepsilon\cos t\cdot\varepsilon\cos t}{\varepsilon^2}\,dt = \int_0^{2\pi}\frac{\varepsilon^2(\sin^2 t+\cos^2 t)}{\varepsilon^2}\,dt = 2\pi$$

$$\oint_L \frac{-y\,dx+x\,dy}{x^2+y^2} = 2\pi$$

> **核心教训：** 遇到 $Q_x = P_y$ 时不要急着说"积分为零"。先检查奇点是否在区域内——如果在，必须用挖洞法。这道题是考试的高频经典。

---

### 例 5：格林公式 + 对称性结合

计算 $\oint_L (x^3-y^3)\,dx + (x^3+y^3)\,dy$，$L$ 为圆 $x^2+y^2=1$，逆时针方向。

**解：** $P = x^3-y^3$，$Q = x^3+y^3$。

$$Q_x - P_y = 3x^2 - (-3y^2) = 3x^2 + 3y^2 = 3(x^2+y^2)$$

由格林公式：

$$\oint_L = \iint_D 3(x^2+y^2)\,dA$$

区域为单位圆盘，用极坐标：

$$= 3\int_0^{2\pi}d\theta\int_0^1 r^2\cdot r\,dr = 3\cdot 2\pi\cdot\frac{1}{4} = \frac{3\pi}{2}$$

> **点评：** 被积式 $Q_x - P_y$ 含 $x^2+y^2$，遇到圆形区域立刻想到极坐标，一气呵成。

---

### 例 6：补线法（曲线不封闭时的格林公式）

计算 $\int_L (e^x\sin y - 2y)\,dx + (e^x\cos y - 2)\,dy$，$L$ 为从 $A(0,0)$ 到 $B(1,\pi)$ 沿抛物线 $y=\pi x^2$ 的弧段。

**解：** 先检查 $Q_x - P_y$：

$$P = e^x\sin y - 2y,\quad Q = e^x\cos y - 2$$

$$Q_x = e^x\cos y,\quad P_y = e^x\cos y - 2$$

$$Q_x - P_y = e^x\cos y - (e^x\cos y - 2) = 2 \neq 0$$

不为零，不路径无关。但如果补一段简单曲线 $L_1$（从 $B$ 回到 $A$），构成封闭曲线，就可以用格林公式。

补线段 $L_1$：从 $(1,\pi)$ 沿直线 $y=\pi x$ 回到 $(0,0)$（方向：$B\to A$）。此时 $L+L_1$ 正向围成区域

$$D=\{(x,y)\mid 0\leq x\leq 1,\; \pi x^2\leq y\leq \pi x\}$$

由格林公式：

$$\int_L+\int_{L_1}=\iint_D 2\,dA=2\int_0^1(\pi x-\pi x^2)\,dx=\frac{\pi}{3}$$

再算补线 $L_1$。在 $L_1$ 上，令 $x=t,\; y=\pi t,\; t:1\to0$，则 $dx=dt,\; dy=\pi dt$。

$$\int_{L_1}=\int_1^0\left[\left(e^t\sin(\pi t)-2\pi t\right)+\left(e^t\cos(\pi t)-2\right)\pi\right]dt$$

$$=\int_1^0\left[e^t(\sin\pi t+\pi\cos\pi t)-2\pi t-2\pi\right]dt$$

注意 $\frac{d}{dt}(e^t\sin\pi t)=e^t(\sin\pi t+\pi\cos\pi t)$，所以

$$\int_{L_1}=\left[e^t\sin\pi t-\pi t^2-2\pi t\right]_1^0=3\pi$$

因此

$$\int_L=\frac{\pi}{3}-3\pi=-\frac{8\pi}{3}$$

> **点评：** 补线法的关键是先判断封闭曲线的正方向，再用"整体积分 - 补线积分"求原曲线积分。

## 第二部分：高斯公式

### 七、从格林到高斯——维度的跃迁

格林公式把平面闭曲线的线积分转化为区域上的二重积分：**一维边界 → 二维内部**。

高斯公式把空间封闭曲面的面积分转化为体积上的三重积分：**二维边界 → 三维内部**。

它们是同一个哲学的不同化身：**边界上的总效应 = 内部微观效应的累积**。

---

### 八、高斯公式的陈述

设空间闭区域 $\Omega$ 由分片光滑封闭曲面 $\Sigma$ 围成，$P,Q,R$ 在 $\Omega$（含边界）上有连续一阶偏导数，$\Sigma$ 取**外侧**，则：

$$\boxed{\oiint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy = \iiint_\Omega \left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}\right) dV}$$

或写成向量形式（用散度）：

$$\oiint_\Sigma \vec{F}\cdot d\vec{S} = \iiint_\Omega \text{div}\,\vec{F}\,dV$$

---

### 九、公式的理解

#### 物理直觉：流体的源与汇

把 $\vec{F}=(P,Q,R)$ 看作流速场。

- **左边** $\oiint_\Sigma \vec{F}\cdot d\vec{S}$：流体穿过封闭曲面 $\Sigma$ 向外的**总通量**（单位时间净流出量）
- **右边** $\iiint_\Omega (\nabla\cdot\vec{F})\,dV$：区域内部所有**源/汇强度的累加**

高斯公式说：**净流出量 = 内部的"生产量"**。如果内部有源（散度 $>0$），流体会从表面涌出；如果全是汇（散度 $<0$），流体被表面吸入。

#### 记忆口诀

格林公式右边是 $Q_x - P_y$（"叉乘式"——有减号，有交叉）。  
高斯公式右边是 $P_x + Q_y + R_z$（"点乘式"——全加号，各管各的）。

> **对比记忆：** 格林 = 旋转（减号，antisymmetric）；高斯 = 发散（加号，symmetric）。

---

### 十、使用条件

| 条件 | 含义 | 不满足时怎么办 |
|------|------|----------------|
| $\Sigma$ 封闭 | 曲面完全包裹住区域（无缺口） | 补面使其封闭，再减去补面上的积分 |
| $\Sigma$ 取外侧 | 法向量指向区域外部 | 取外侧为标准，注意最终符号 |
| $P,Q,R$ 在 $\Omega$ 内连续可偏导 | 体内无奇点 | 挖去奇点（类似格林公式的挖洞法） |

---

### 十一、高斯公式的典型应用场景

| 场景 | 做法 |
|------|------|
| 封闭曲面上的面积分 | 直接用高斯公式转为三重积分 |
| 非封闭曲面 | 补面 → 高斯公式算全部 → 减去补面的积分 |
| 散度为常数 | 直接等于常数 $\times$ 体积 |
| 散度为零 | 通量为零（无源场，进出平衡） |
| 验证某场是否无源 | 检查 $\nabla\cdot\vec{F} = 0$ |

## 第二部分例题

### 例 7：直接使用高斯公式（基础）

计算 $\oiint_\Sigma x^2\,dydz + y^2\,dzdx + z^2\,dxdy$，$\Sigma$ 为立方体 $0\leq x,y,z\leq 1$ 的外侧表面。

**解：** $P=x^2,\; Q=y^2,\; R=z^2$。

$$\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z} = 2x+2y+2z$$

由高斯公式：

$$\oiint_\Sigma = \iiint_\Omega (2x+2y+2z)\,dV = \int_0^1\int_0^1\int_0^1 (2x+2y+2z)\,dxdydz$$

由对称性，$\iiint 2x\,dV = \iiint 2y\,dV = \iiint 2z\,dV$，只算一个：

$$\iiint_\Omega 2x\,dV = 2\int_0^1 x\,dx\int_0^1 dy\int_0^1 dz = 2\cdot\frac{1}{2}\cdot 1\cdot 1 = 1$$

$$\oiint_\Sigma = 1+1+1 = 3$$

---

### 例 8：高斯公式 + 球坐标

计算 $\oiint_\Sigma (x^2+y^2+z^2)(x\,dydz+y\,dzdx+z\,dxdy)$，$\Sigma$ 为球面 $x^2+y^2+z^2=a^2$ 外侧。

**解：** $P = x(x^2+y^2+z^2) = xr^2$，$Q = yr^2$，$R = zr^2$（其中 $r^2=x^2+y^2+z^2$）。

$$P_x = r^2 + x\cdot 2x = r^2+2x^2$$

类似地 $Q_y = r^2+2y^2$，$R_z = r^2+2z^2$。

$$P_x+Q_y+R_z = 3r^2+2(x^2+y^2+z^2) = 3r^2+2r^2 = 5r^2$$

由高斯公式，用球坐标 $(\rho,\phi,\theta)$，其中 $r^2 = \rho^2$：

$$\oiint_\Sigma = \iiint_\Omega 5\rho^2\cdot\rho^2\sin\phi\,d\rho\,d\phi\,d\theta = 5\int_0^{2\pi}d\theta\int_0^\pi\sin\phi\,d\phi\int_0^a \rho^4\,d\rho$$

$$= 5\cdot 2\pi\cdot 2\cdot\frac{a^5}{5} = 4\pi a^5$$

---

### 例 9：补面法（非封闭曲面）

计算 $\iint_\Sigma x^2\,dydz + y^2\,dzdx + z^2\,dxdy$，$\Sigma$ 为半球面 $z=\sqrt{a^2-x^2-y^2}$（上侧）。

**解：** 半球面不封闭，补底面 $\Sigma_0: z=0,\; x^2+y^2\leq a^2$（取下侧——朝外方向朝下）。

$\Sigma + \Sigma_0$ 构成封闭上半球体 $\Omega$ 的外侧。由高斯公式：

$$\oiint_{\Sigma+\Sigma_0} = \iiint_\Omega (2x+2y+2z)\,dV$$

**算三重积分：** 用柱坐标 $x=r\cos\theta,\; y=r\sin\theta$。

$$\iiint_\Omega 2x\,dV = 2\int_0^{2\pi}\cos\theta\,d\theta\int_0^a r^2\,dr\int_0^{\sqrt{a^2-r^2}}dz = 0 \quad\text{（因为 $\int_0^{2\pi}\cos\theta\,d\theta=0$）}$$

同理 $\iiint 2y\,dV = 0$。

$$\iiint_\Omega 2z\,dV = 2\int_0^{2\pi}d\theta\int_0^a r\,dr\int_0^{\sqrt{a^2-r^2}} z\,dz = 2\cdot 2\pi\int_0^a r\cdot\frac{a^2-r^2}{2}\,dr$$

$$= 2\pi\int_0^a (a^2 r - r^3)\,dr = 2\pi\left[\frac{a^2 r^2}{2}-\frac{r^4}{4}\right]_0^a = 2\pi\cdot\frac{a^4}{4} = \frac{\pi a^4}{2}$$

**算底面积分：** 在 $\Sigma_0$（下侧）上，法向量朝下，即 $\cos\gamma < 0$。

$$\iint_{\Sigma_0} x^2\,dydz + y^2\,dzdx + z^2\,dxdy$$

$\Sigma_0$ 是平面 $z=0$，法向量 $\vec{n}=(0,0,-1)$。面积分 $= \iint_{\Sigma_0}(P\cos\alpha+Q\cos\beta+R\cos\gamma)\,dS$。

但更直接地：$\Sigma_0$ 投影到 $xOy$ 平面时，下侧意味着 $dxdy$ 取负号。在 $z=0$ 上 $R=z^2=0$，而 $dydz=0$、$dzdx=0$（因为曲面在 $z=0$ 上没有 $z$ 方向的分量）。

所以底面积分 $= 0$。

$$\iint_\Sigma = \frac{\pi a^4}{2} - 0 = \frac{\pi a^4}{2}$$

---

### 例 10：含奇点的高斯公式（挖球法）

计算 $\oiint_\Sigma \frac{x\,dydz+y\,dzdx+z\,dxdy}{(x^2+y^2+z^2)^{3/2}}$，$\Sigma$ 为任意包含原点的光滑封闭曲面，外侧。

**分析：** 令 $P=\frac{x}{r^3},\; Q=\frac{y}{r^3},\; R=\frac{z}{r^3}$（$r=\sqrt{x^2+y^2+z^2}$）。

在原点外，验证散度：

$$P_x = \frac{r^3 - x\cdot 3r^2\cdot\frac{x}{r}}{r^6} = \frac{r^2-3x^2}{r^5}$$

类似地 $Q_y = \frac{r^2-3y^2}{r^5}$，$R_z = \frac{r^2-3z^2}{r^5}$。

$$\nabla\cdot\vec{F} = \frac{3r^2-3(x^2+y^2+z^2)}{r^5} = \frac{3r^2-3r^2}{r^5} = 0$$

散度为零，但原点是奇点！用**挖球法**：在原点画小球面 $\sigma: x^2+y^2+z^2=\varepsilon^2$，取内侧（朝向原点）。

在 $\Sigma$ 和 $\sigma$ 之间的区域 $\Omega'$ 内散度为 0：

$$\oiint_\Sigma + \oiint_{\sigma^{\text{内侧}}} = 0 \implies \oiint_\Sigma = -\oiint_{\sigma^{\text{内侧}}} = \oiint_{\sigma^{\text{外侧}}}$$

在小球面 $\sigma$ 上（外侧），$\vec{n} = \frac{1}{\varepsilon}(x,y,z)$，$r=\varepsilon$：

$$\vec{F}\cdot\vec{n}\,dS = \frac{(x,y,z)}{r^3}\cdot\frac{(x,y,z)}{r}\,dS = \frac{r^2}{r^4}\,dS = \frac{1}{\varepsilon^2}\,dS$$

$$\oiint_\sigma \frac{1}{\varepsilon^2}\,dS = \frac{1}{\varepsilon^2}\cdot 4\pi\varepsilon^2 = 4\pi$$

$$\oiint_\Sigma \frac{x\,dydz+y\,dzdx+z\,dxdy}{(x^2+y^2+z^2)^{3/2}} = 4\pi$$

> **深刻意义：** 这就是"立体角"结果——从原点看任何封闭曲面都恰好覆盖 $4\pi$ 个立体角。这个结论与曲面形状无关！在电磁学中，这就是高斯定律的数学基础。

### 例 11：利用散度为常数快速计算

计算 $\oiint_\Sigma x\,dydz + y\,dzdx + z\,dxdy$，$\Sigma$ 为椭球面 $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$ 外侧。

**解：** $P=x,\; Q=y,\; R=z$。

$$P_x+Q_y+R_z = 1+1+1 = 3$$

由高斯公式：

$$\oiint_\Sigma = \iiint_\Omega 3\,dV = 3V_{\text{椭球}}$$

椭球体积 $V = \frac{4}{3}\pi abc$。

$$\oiint_\Sigma = 3\cdot\frac{4}{3}\pi abc = 4\pi abc$$

> **秒杀：** 散度为常数时，高斯公式 = 常数 $\times$ 体积。记住常见体的体积公式就是秒级速度。

---

### 例 12：高斯公式的逆用——利用面积分求体积

已知 $\oiint_\Sigma x\,dydz + y\,dzdx + z\,dxdy = 3V$（由例11推导），我们可以用面积分来**求体积**：

$$V = \frac{1}{3}\oiint_\Sigma x\,dydz + y\,dzdx + z\,dxdy$$

这和格林公式求面积异曲同工。

### 例 13：多种解法对比

计算 $\oiint_\Sigma (2x+1)\,dydz + 2(y+1)\,dzdx + (2z+3)\,dxdy$，$\Sigma$ 为球面 $x^2+y^2+z^2=4$ 外侧。

**解法一：高斯公式**

$$P_x+Q_y+R_z = 2+2+2 = 6$$

$$\oiint_\Sigma = 6\iiint_\Omega dV = 6\cdot\frac{4}{3}\pi\cdot 8 = 64\pi$$

**解法二：拆分 + 对称性**

$$\oiint_\Sigma = \oiint_\Sigma 2x\,dydz+2y\,dzdx+2z\,dxdy + \oiint_\Sigma dydz+2\,dzdx+3\,dxdy$$

第一部分：$\vec{F}_1=(2x,2y,2z)$，$\nabla\cdot\vec{F}_1=6$，由高斯公式得 $6\cdot\frac{32\pi}{3}=64\pi$。

第二部分：$\vec{F}_2=(1,2,3)$ 是常向量场，散度为 0，所以通量为 0。

$$\oiint_\Sigma = 64\pi + 0 = 64\pi$$

> **技巧：** 常向量场穿过封闭曲面的通量恒为零（进去多少出来多少）。遇到被积式中有常数项，可以放心拆掉。

## 第三部分：格林公式与高斯公式的对比总结

### 十二、两大公式的统一视角

| | 格林公式 | 高斯公式 |
|---|---|---|
| **维度** | 二维（平面） | 三维（空间） |
| **左边** | 曲线积分 $\oint_L P\,dx+Q\,dy$ | 曲面积分 $\oiint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy$ |
| **右边** | 二重积分 $\iint_D (Q_x-P_y)\,dA$ | 三重积分 $\iiint_\Omega (P_x+Q_y+R_z)\,dV$ |
| **核心算子** | 二维旋度 $Q_x - P_y$ | 散度 $\nabla\cdot\vec{F}$ |
| **物理含义** | 环量 = 微旋转之和 | 通量 = 微源/汇之和 |
| **边界方向** | 正方向（区域在左边） | 外侧 |
| **奇点处理** | 挖小圆 | 挖小球 |
| **求几何量** | 面积 = $\frac12\oint(x\,dy-y\,dx)$ | 体积 = $\frac13\oiint(x\,dydz+y\,dzdx+z\,dxdy)$ |

---

### 十三、解题策略速查表

**第二类曲线积分 $\oint_L P\,dx+Q\,dy$：**

```
曲线封闭？
├── 是 → P,Q 在区域内处处连续可偏导？
│       ├── 是 → 格林公式：转为 ∬(Qx-Py)dA
│       └── 否（有奇点）→ 挖洞法
└── 否 → Qx = Py？
        ├── 是 → 路径无关 → 求原函数或选简单路径
        └── 否 → 补线构成封闭 → 格林公式 → 减去补线上的积分
```

**第二类曲面积分 $\oiint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy$：**

```
曲面封闭？
├── 是 → P,Q,R 在体内处处连续可偏导？
│       ├── 是 → 高斯公式：转为 ∭(Px+Qy+Rz)dV
│       └── 否（有奇点）→ 挖球法
└── 否 → 补面使其封闭 → 高斯公式算整体 → 减去补面上的积分
```

---

### 十四、常见陷阱与避坑指南

1. **格林公式方向弄反**：正方向 = 区域在左边 = 外边界逆时针、内边界顺时针。搞反差一个负号。

2. **高斯公式忘记取外侧**：法向量必须指向区域外部。补面时注意补面的"外侧"是相对于补成的封闭体而言的。

3. **奇点在区域内却直接用公式**：这是最常见的致命错误。解题第一步永远是检查被积函数在区域内部是否有奇点。

4. **格林公式的 $Q_x - P_y$ 记反**：记忆口诀——"后对前减前对后"，即**第二个函数**对**第一个变量**减去**第一个函数**对**第二个变量**。

5. **高斯公式补面后忘记减去补面积分**：补面法的完整逻辑是 $\iint_\Sigma = \text{（高斯公式算的整体）} - \iint_{\text{补面}}$。

6. **路径无关 vs 积分为零的区别**：$Q_x=P_y$ 保证路径无关（从 $A$ 到 $B$ 的积分值唯一），但不保证沿特定路径的积分为零——除非是封闭曲线。

## 速查公式卡

$$\boxed{\oint_L P\,dx+Q\,dy = \iint_D (Q_x-P_y)\,dA} \quad\text{（格林公式）}$$

$$\boxed{\oiint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy = \iiint_\Omega (P_x+Q_y+R_z)\,dV} \quad\text{（高斯公式）}$$

$$\boxed{S_D = \frac{1}{2}\oint_L (x\,dy - y\,dx)} \quad\text{（面积公式）}$$

$$\boxed{V_\Omega = \frac{1}{3}\oiint_\Sigma (x\,dydz+y\,dzdx+z\,dxdy)} \quad\text{（体积公式）}$$

$$\boxed{Q_x = P_y \;\text{（单连通域）} \iff \text{路径无关} \iff \exists u,\; du=Pdx+Qdy} \quad\text{（全微分判定）}$$
