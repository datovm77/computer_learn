## 第三章：重积分

### 3.1 二重积分的概念与性质

#### 从一重积分说起

你已经学过一重积分 $\int_a^b f(x)\,dx$，它的几何意义是曲线 $y=f(x)$ 下方的面积。

现在把问题升一维：给定平面区域 $D$ 上的函数 $f(x,y)$，想求曲面 $z=f(x,y)$ 下方、$D$ 上方的**体积**。

直觉做法：

1. 把区域 $D$ 切成很多个小方块，每块面积为 $\Delta A_i$
2. 在每块上取一点 $(x_i, y_i)$，用 $f(x_i, y_i)$ 近似该小块对应的高度
3. 每个小柱体体积 ≈ $f(x_i, y_i) \cdot \Delta A_i$
4. 全部加起来，取极限

这就是**二重积分**的定义：

$$\iint_D f(x,y)\,dA = \lim_{\lambda \to 0} \sum_{i=1}^n f(x_i, y_i)\,\Delta A_i$$

其中 $\lambda$ 是最大小块的直径趋于零。符号 $dA$（或 $d\sigma$）表示面积微元。

> **直觉总结：** 一重积分 = 线上求面积；二重积分 = 面上求体积。  
> 但二重积分不只能求体积，只要能写成"在区域上对函数积分"的形式都可以用。

#### 二重积分的几何意义

- 当 $f(x,y) \geq 0$ 时，$\iint_D f\,dA$ = 曲面 $z=f$ 下方的体积
- 当 $f(x,y) = 1$ 时，$\iint_D 1\,dA = S_D$（区域 $D$ 的面积）
- 当 $f$ 正负交替时，积分值 = 正体积 − 负体积（带符号的体积）

#### 核心性质

这些性质和一重积分几乎完全一样，理解了不用死记：

| 性质 | 公式 | 理解 |
|------|------|------|
| **线性性** | $\iint(af+bg)\,dA = a\iint f\,dA + b\iint g\,dA$ | 积分可以拆开、提常数 |
| **区域可加性** | $D=D_1\cup D_2 \Rightarrow \iint_D = \iint_{D_1}+\iint_{D_2}$ | 把区域切开分别算再相加 |
| **比较性质** | $f \leq g \Rightarrow \iint f\,dA \leq \iint g\,dA$ | 函数大，积分也大 |
| **估值不等式** | $mS \leq \iint_D f\,dA \leq MS$ | $m,M$ 是 $f$ 在 $D$ 上的最小最大值，$S$ 是 $D$ 的面积 |
| **中值定理** | $\iint_D f\,dA = f(\xi,\eta)\cdot S_D$ | $D$ 上某点的函数值乘以面积，等于积分值 |

#### 对称性（重要！常出简答题）

**结论：** 若积分区域 $D$ 关于 $y$ 轴对称（即 $(x,y)\in D \Leftrightarrow (-x,y)\in D$），则：

$$\iint_D f(x,y)\,dA = \begin{cases} 0 & f(-x,y)=-f(x,y) \quad \text{（$f$ 关于 $x$ 是奇函数）} \\ 2\iint_{D_1} f\,dA & f(-x,y)=f(x,y) \quad \text{（$f$ 关于 $x$ 是偶函数）} \end{cases}$$

其中 $D_1$ 是 $D$ 在 $y$ 轴右侧的部分。类似地对 $x$ 轴对称也有对应结论。

**为什么？** 奇函数在对称区域上正负抵消，偶函数则翻倍。和一重积分的对称性完全相同。

> **做题口诀：** 看到对称区域，先检查被积函数的奇偶性，能化简就化简，这往往是出题人埋的"捷径"。

**例：** 计算 $\iint_D (x^3y^2 + \sin x + y)\,dA$，$D$ 是单位圆盘 $x^2+y^2\leq 1$。

直接算很麻烦，先用对称性逐项拆开：

- $x^3 y^2$：$D$ 关于 $y$ 轴对称，$x^3y^2$ 关于 $x$ 是奇函数 → 积分为 $0$
- $\sin x$：同理关于 $x$ 是奇函数 → 积分为 $0$
- $y$：$D$ 关于 $x$ 轴对称，$y$ 关于 $y$ 是奇函数 → 积分为 $0$

$$\iint_D (x^3y^2 + \sin x + y)\,dA = 0$$

> **启示：** 三项全是奇函数，整个积分直接归零，一步不用算。对称性是重积分里最值钱的"捷径"。

### 3.2 二重积分的计算：3方法1手段

**核心思路：** 二重积分最终都要化成两次一元积分（"累次积分"）来计算，区别只在于用什么坐标系、以什么顺序积。

**"3方法"：直角坐标、极坐标、换元法**  
**"1手段"：交换积分次序**

---

#### 方法一：直角坐标（化为累次积分）

**基本想法：** 把二维区域 $D$ 用不等式描述，固定一个变量，让另一个变量在某个范围内变化，就能把二重积分化成两个一元积分嵌套。

根据区域形状，分两种写法：

**X型区域**（竖着切：固定 $x$，$y$ 在上下两条曲线之间变化）

$$\iint_D f\,dA = \int_a^b \left[\int_{y_1(x)}^{y_2(x)} f(x,y)\,dy\right] dx$$

读法：先对 $y$ 从 $y_1(x)$ 积到 $y_2(x)$（把 $x$ 看常数），再对 $x$ 从 $a$ 积到 $b$。

**Y型区域**（横着切：固定 $y$，$x$ 在左右两条曲线之间变化）

$$\iint_D f\,dA = \int_c^d \left[\int_{x_1(y)}^{x_2(y)} f(x,y)\,dx\right] dy$$

**怎么选？三步走：**
1. **画图**，画出积分区域 $D$ 的草图
2. 看区域边界：上下边界容易写 → 用X型；左右边界容易写 → 用Y型
3. 看被积函数：哪个方向先积更好算就用哪个

**例：** 计算 $\iint_D xy\,dA$，$D$ 由 $y=x^2$ 和 $y=x$ 围成。

区域：$0 \leq x \leq 1$，$x^2 \leq y \leq x$（X型区域）

$$\iint_D xy\,dA = \int_0^1 dx \int_{x^2}^{x} xy\,dy = \int_0^1 x \cdot \frac{y^2}{2}\Big|_{x^2}^{x} dx = \int_0^1 x \cdot \frac{x^2-x^4}{2}\,dx = \frac{1}{2}\int_0^1(x^3-x^5)dx = \frac{1}{24}$$

---

#### 方法二：极坐标

**为什么需要极坐标？** 当积分区域是圆形/扇形，或被积函数含 $x^2+y^2$ 时，直角坐标的积分限会很复杂，换成极坐标后往往豁然开朗。

**换元公式：**

$$x = r\cos\theta, \quad y = r\sin\theta, \quad x^2+y^2 = r^2$$

**面积微元的变化（重点！）：**

直角坐标下 $dA = dx\,dy$，极坐标下：

$$dA = r\,dr\,d\theta$$

多出来的 $r$ 是 Jacobi 行列式，几何上理解：极坐标的小面积块不是正方形，它是"扇形小块"，面积约等于 $r\,\Delta r\,\Delta\theta$。

**计算公式：**

$$\iint_D f(x,y)\,dA = \int_{\alpha}^{\beta} d\theta \int_{r_1(\theta)}^{r_2(\theta)} f(r\cos\theta, r\sin\theta)\cdot r\,dr$$

**什么时候用极坐标？**
- 积分区域是圆、半圆、扇形、圆环
- 被积函数含 $x^2+y^2$、$\sqrt{x^2+y^2}$、$\arctan\frac{y}{x}$ 等

> ⚠️ **极坐标最常见错误：忘写那个 $r$！** 每次换极坐标都要在被积函数后面乘以 $r$。

**例：** 计算 $\iint_D e^{-(x^2+y^2)}\,dA$，$D$ 为圆盘 $x^2+y^2 \leq 1$。

换极坐标：$r$ 从 $0$ 到 $1$，$\theta$ 从 $0$ 到 $2\pi$

$$= \int_0^{2\pi}d\theta\int_0^1 e^{-r^2}\cdot r\,dr = 2\pi \cdot \left[-\frac{1}{2}e^{-r^2}\right]_0^1 = \pi(1-e^{-1})$$

---

#### 方法三：换元法（一般变量替换）

**本质：** 通过换元把复杂区域/函数变成简单形式。极坐标是换元法的特例。

令 $x = x(u,v)$，$y = y(u,v)$，则：

$$\iint_D f(x,y)\,dA = \iint_{D'} f(x(u,v), y(u,v)) \cdot |J|\,du\,dv$$

其中 **Jacobi 行列式**（面积缩放因子）：

$$J = \frac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix} \dfrac{\partial x}{\partial u} & \dfrac{\partial x}{\partial v} \\[6pt] \dfrac{\partial y}{\partial u} & \dfrac{\partial y}{\partial v} \end{vmatrix}$$

**验证：** 极坐标 $x=r\cos\theta,\, y=r\sin\theta$ 的 Jacobi 行列式正好是 $r$，所以 $dA = r\,dr\,d\theta$。

**使用场景：** 当积分区域是椭圆、平行四边形等，通过线性变换可以化成标准圆或矩形。

**例：** 计算 $\iint_D dA$，$D$ 是椭圆 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}\leq 1$（即求椭圆面积）。

令 $x = a u$，$y = b v$，则区域变成单位圆盘 $u^2+v^2\leq 1$。Jacobi 行列式：

$$J = \begin{vmatrix} a & 0 \\ 0 & b \end{vmatrix} = ab$$

$$\iint_D dA = \iint_{u^2+v^2\leq 1} ab\,du\,dv = ab\cdot\pi = \pi ab$$

这正是椭圆面积公式。换元把椭圆"压回"单位圆，Jacobi 行列式 $ab$ 记录了面积的缩放比例。

---

#### 1手段：交换积分次序

**什么情况下需要？** 有些积分，内层积不出来（没有初等函数原函数），但交换积分顺序后反而可以积。

**典型例子：** $\int_0^1 dx \int_x^1 e^{y^2}\,dy$ — 内层 $\int e^{y^2}\,dy$ 没有初等原函数，无法直接算。

**交换步骤：**

1. **从积分限还原区域 $D$**：原式说明 $0 \leq x \leq 1$，$x \leq y \leq 1$，即区域是 $\{0\leq x\leq y,\, 0\leq y\leq 1\}$
2. **画图**，确认区域形状（这里是三角形）
3. **换方向描述**：固定 $y$，$x$ 从 $0$ 到 $y$，$y$ 从 $0$ 到 $1$

$$\int_0^1 dx \int_x^1 e^{y^2}\,dy = \int_0^1 dy \int_0^y e^{y^2}\,dx = \int_0^1 y e^{y^2}\,dy = \frac{1}{2}(e-1)$$

> **口诀：** 内层积不出来 → 画图 → 交换次序。画图是关键，不画图容易搞错积分限。

### 3.3 三重积分（4方法1手段）

#### 概念

二重积分是在二维区域（平面）上积分，三重积分是在三维区域（空间体）上积分：

$$\iiint_\Omega f(x,y,z)\,dV = \lim_{\lambda\to 0}\sum f(x_i,y_i,z_i)\,\Delta V_i$$

**物理意义：**
- $f=1$ 时，$\iiint_\Omega dV = $ 区域 $\Omega$ 的体积
- $f=\rho(x,y,z)$（密度）时，积分值 = 质量

---

#### 方法一：直角坐标·投影法（先二后一）

**思路：** 把三重积分变成"先做二重积分，再做一元积分"。

固定 $z$，在高度 $z$ 处的截面 $D_z$ 上先做二重积分，再对 $z$ 积分：

$$\iiint_\Omega f\,dV = \int_{z_1}^{z_2} dz \iint_{D_z} f(x,y,z)\,dA$$

**步骤：**
1. 确定 $z$ 的范围 $[z_1, z_2]$
2. 对每个固定的 $z$，确定截面 $D_z$ 的形状（用 $x,y$ 表示）
3. 内层做二重积分，外层对 $z$ 积分

**例：** $\Omega$ 是由 $z=x^2+y^2$（抛物面）和 $z=1$（平面）围成的区域。

- $z$ 范围：$0 \leq z \leq 1$
- 截面 $D_z$：$x^2+y^2 \leq z$（半径为 $\sqrt{z}$ 的圆盘）

$$\iiint_\Omega dV = \int_0^1 dz\iint_{D_z}dA = \int_0^1 \pi(\sqrt{z})^2\,dz = \pi\int_0^1 z\,dz = \frac{\pi}{2}$$

---

#### 方法二：直角坐标·化三次积分（先一后二）

**思路：** 把三重积分直接展开成三次一元积分。

$$\iiint_\Omega f\,dV = \int_a^b dx \int_{y_1(x)}^{y_2(x)} dy \int_{z_1(x,y)}^{z_2(x,y)} f(x,y,z)\,dz$$

从里到外依次对 $z$、$y$、$x$ 积分。

**适用：** 区域是长方体或能直接写出三个方向的积分限时。

---

**例1（长方体区域）：** 计算 $\iiint_\Omega xyz\,dV$，$\Omega = \{0\leq x\leq 1,\, 0\leq y\leq 2,\, 0\leq z\leq 3\}$。

积分限都是常数，直接展开成三次积分：

$$\iiint_\Omega xyz\,dV = \int_0^1 x\,dx \cdot \int_0^2 y\,dy \cdot \int_0^3 z\,dz = \frac{1}{2}\cdot 2\cdot \frac{9}{2} = \frac{9}{2}$$

---

**例2（圆柱体区域）：** 计算 $\iiint_\Omega (x^2+y^2)\,dV$，$\Omega = \{x^2+y^2\leq 4,\ 0\leq z\leq 3\}$。

**先一后二**：固定 $(x,y)$，先对 $z$ 积分，再对 $(x,y)$ 在投影区域上做二重积分。

**第一步：** 对于投影区域 $D: x^2+y^2\leq 4$ 内的任意一点 $(x,y)$，$z$ 从 $0$ 到 $3$：

$$\iiint_\Omega (x^2+y^2)\,dV = \iint_D \left[\int_0^3 (x^2+y^2)\,dz\right] dA$$

**第二步：** 内层对 $z$ 积分时，把 $x^2+y^2$ 看作常数：

$$\int_0^3 (x^2+y^2)\,dz = (x^2+y^2)\cdot z\Big|_{0}^{3} = 3(x^2+y^2)$$

**第三步：** 剩下二重积分，投影区域是圆盘，用极坐标处理：

$$\iiint_\Omega (x^2+y^2)\,dV = \iint_{x^2+y^2\leq 4} 3(x^2+y^2)\,dA = 3\int_0^{2\pi}d\theta\int_0^2 r^2\cdot r\,dr$$

**第四步：** 逐层计算：

$$= 3\cdot 2\pi \cdot \int_0^2 r^3\,dr = 6\pi \cdot \frac{r^4}{4}\Big|_0^2 = 6\pi \cdot \frac{16}{4} = 24\pi$$

> **与柱坐标对照：** 这道题用柱坐标更直接（一次换元到位），本题演示的是"先一后二"也能做——关键在于第一步选定内层积分变量后，把外层变量看作常数处理。

---

#### 方法三：柱坐标

**换元公式：**

$$x = r\cos\theta,\quad y = r\sin\theta,\quad z = z, \qquad dV = r\,dr\,d\theta\,dz$$

即：在 $xy$ 平面用极坐标，$z$ 方向不变。

**什么时候用：** 区域或被积函数含 $x^2+y^2$，但 $z$ 不对称（不是球体）。

典型区域：圆柱体、圆锥、旋转抛物面。

**例：** $\Omega = \{x^2+y^2\leq 4,\, 0\leq z\leq 3\}$，求 $\iiint_\Omega (x^2+y^2)z\,dV$。

$$= \int_0^{2\pi}d\theta\int_0^2 r\,dr\int_0^3 r^2 z\,dz = 2\pi\int_0^2 r^3\,dr\cdot\int_0^3 z\,dz = 2\pi\cdot 4\cdot\frac{9}{2} = 36\pi$$

---

#### 方法四：球坐标

**换元公式：**

$$x = \rho\sin\phi\cos\theta,\quad y = \rho\sin\phi\sin\theta,\quad z = \rho\cos\phi$$

$$\rho^2 = x^2+y^2+z^2, \qquad dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta$$

- $\rho \geq 0$：到原点的距离
- $\phi \in [0,\pi]$：与正 $z$ 轴的夹角（仰角的补角）
- $\theta \in [0, 2\pi]$：在 $xy$ 平面上的方位角

> ⚠️ **记牢：** $dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta$，两个因子 $\rho^2$ 和 $\sin\phi$ 缺一不可。

**什么时候用：** 积分区域是球、半球、球壳，或被积函数含 $x^2+y^2+z^2$。

**例：** 求球体 $\rho\leq a$ 的体积。

$$V = \int_0^{2\pi}d\theta\int_0^{\pi}\sin\phi\,d\phi\int_0^a\rho^2\,d\rho = 2\pi\cdot 2\cdot\frac{a^3}{3} = \frac{4}{3}\pi a^3 \checkmark$$

---

#### 1手段：利用对称性

和二重积分完全类似。若区域 $\Omega$ 关于坐标面（如 $xOy$ 面）对称，且被积函数关于 $z$ 是奇函数，则积分为零；若是偶函数，则积分等于一半区域上积分的两倍。

**轮换对称性（常考！）：** 若区域关于 $x,y,z$ 完全对称（如球体 $x^2+y^2+z^2\leq a^2$），则：

$$\iiint_\Omega x^2\,dV = \iiint_\Omega y^2\,dV = \iiint_\Omega z^2\,dV = \frac{1}{3}\iiint_\Omega (x^2+y^2+z^2)\,dV$$

---

#### 方法选择速查

| 区域特征 | 推荐方法 |
|----------|----------|
| 长方体、四面体等规则多面体 | 直角坐标化三次积分 |
| 由曲面 $z=f(x,y)$ 上下围成 | 投影法（先二后一） |
| 含 $x^2+y^2$，柱形区域 | 柱坐标 |
| 球形区域，含 $x^2+y^2+z^2$ | 球坐标 |

### 3.4 重积分的应用

重积分不只是数学游戏，它直接对应物理中的质量、重心、转动惯量等概念。理解了物理背景，公式自然就记住了。

#### 几何应用

| 应用 | 公式 | 理解 |
|------|------|------|
| 平面区域面积 | $S = \iint_D dA$ | 被积函数=1，积分=面积 |
| 立体体积 | $V = \iiint_\Omega dV$ | 被积函数=1，积分=体积 |
| 曲面面积 | $S = \iint_D \sqrt{1 + z_x^2 + z_y^2}\,dA$ | 曲面"拉伸"程度用斜率修正 |

**曲面面积公式怎么来的？**  
曲面 $z=f(x,y)$ 上的一小块，投影到 $xy$ 平面面积为 $\Delta A$，但曲面是倾斜的，实际面积要乘以"倾斜因子" $\sqrt{1+z_x^2+z_y^2}$。这个因子来自法向量的模长，坡度越大，因子越大。

#### 物理应用

**质量：** 平面薄片密度为 $\mu(x,y)$（单位面积质量），则总质量：
$$m = \iint_D \mu(x,y)\,dA$$

**质心（重心）：** 密度分布不均匀时，质心坐标：
$$\bar{x} = \frac{1}{m}\iint_D x\,\mu\,dA, \qquad \bar{y} = \frac{1}{m}\iint_D y\,\mu\,dA$$

直觉：质心是"加权平均位置"，密度大的地方贡献更多。

**转动惯量：** 薄片绕 $x$ 轴旋转的惯量（$y$ 是到 $x$ 轴的距离）：
$$I_x = \iint_D y^2\,\mu\,dA, \qquad I_y = \iint_D x^2\,\mu\,dA$$

**例：** 密度均匀（$\mu=1$）的半圆盘 $D: x^2+y^2\leq a^2,\ y\geq 0$，求质心 $\bar{y}$。

由对称性 $\bar{x}=0$。面积 $m = \frac{1}{2}\pi a^2$。

$$\bar{y} = \frac{1}{m}\iint_D y\,dA$$

用极坐标：$r$ 从 $0$ 到 $a$，$\theta$ 从 $0$ 到 $\pi$

$$\iint_D y\,dA = \int_0^\pi d\theta\int_0^a r\sin\theta\cdot r\,dr = \int_0^\pi\sin\theta\,d\theta\cdot\int_0^a r^2\,dr = 2\cdot\frac{a^3}{3} = \frac{2a^3}{3}$$

$$\bar{y} = \frac{2a^3/3}{\pi a^2/2} = \frac{4a}{3\pi}$$

这就是半圆盘质心离直径的距离，结果只跟半径 $a$ 有关，与直觉一致（越大的半圆盘，质心越高）。

#### 曲面面积公式详解（含例题）

**公式回顾：** 曲面 $z=f(x,y)$ 在 $xy$ 平面投影区域 $D$ 上的面积：
$$S = \iint_D \sqrt{1 + f_x^2 + f_y^2}\,dA$$

**为什么是这个公式？**  
曲面上一小块 $\Delta S$ 投影到 $xy$ 平面得 $\Delta A$，两者夹角 $\gamma$ 满足 $\Delta A = \Delta S \cdot |\cos\gamma|$。曲面法向量 $\vec{n}=(-f_x,-f_y,1)$，其模长 $|\vec{n}| = \sqrt{1+f_x^2+f_y^2}$，而 $\cos\gamma = \frac{\vec{n}\cdot\vec{k}}{|\vec{n}|} = \frac{1}{\sqrt{1+f_x^2+f_y^2}}$，所以 $\Delta S = \frac{\Delta A}{|\cos\gamma|} = \sqrt{1+f_x^2+f_y^2}\,\Delta A$。微元累加即得面积公式。

> 曲面也可用 $x=g(y,z)$ 或 $y=h(x,z)$ 表示，公式对称：
> $$S = \iint_{D_{yz}} \sqrt{1+g_y^2+g_z^2}\,dydz,\qquad S = \iint_{D_{xz}} \sqrt{1+h_x^2+h_z^2}\,dxdz$$

**例1：** 求锥面 $z = \sqrt{x^2+y^2}$ 被柱面 $x^2+y^2 = 2x$ 所割下部分的面积。

**解：** 锥面 $z = \sqrt{x^2+y^2}$，则
$$z_x = \frac{x}{\sqrt{x^2+y^2}},\quad z_y = \frac{y}{\sqrt{x^2+y^2}}$$
$$\sqrt{1+z_x^2+z_y^2} = \sqrt{1+\frac{x^2}{x^2+y^2}+\frac{y^2}{x^2+y^2}} = \sqrt{1+1} = \sqrt{2}$$

所以 $dS = \sqrt{2}\,dA$。锥面在 $xy$ 平面的投影区域 $D$ 由 $x^2+y^2=2x$ 所围，即 $(x-1)^2+y^2 = 1$（圆心在 $(1,0)$ 半径为 $1$ 的圆盘）。

$$S = \iint_D \sqrt{2}\,dA = \sqrt{2}\cdot \text{Area}(D) = \sqrt{2}\cdot \pi\cdot 1^2 = \sqrt{2}\pi$$

> **关键：** 锥面的 $\sqrt{1+z_x^2+z_y^2}$ 恰好是常数 $\sqrt{2}$，面积直接简化为投影面积乘以 $\sqrt{2}$。

**例2：** 求球面 $x^2+y^2+z^2 = a^2$ 被柱面 $x^2+y^2 = ax$ 所割下部分的面积（维维亚尼曲线所围球面部分）。

**解：** 由对称性，先算第一卦限部分再 4 倍。上半球面 $z=\sqrt{a^2-x^2-y^2}$，投影 $D: x^2+y^2 \leq ax,\ y\geq 0$（半圆盘）。
$$z_x = \frac{-x}{\sqrt{a^2-x^2-y^2}},\quad z_y = \frac{-y}{\sqrt{a^2-x^2-y^2}}$$
$$\sqrt{1+z_x^2+z_y^2} = \sqrt{1+\frac{x^2+y^2}{a^2-x^2-y^2}} = \frac{a}{\sqrt{a^2-x^2-y^2}}$$

一卦限面积：
$$S_1 = \iint_D \frac{a}{\sqrt{a^2-x^2-y^2}}\,dA$$

换极坐标：$x^2+y^2=ax \Rightarrow r = a\cos\theta$，$\theta$ 从 $0$ 到 $\frac{\pi}{2}$，$r$ 从 $0$ 到 $a\cos\theta$。
$$S_1 = a\int_0^{\frac{\pi}{2}}d\theta\int_0^{a\cos\theta} \frac{r}{\sqrt{a^2-r^2}}\,dr = a\int_0^{\frac{\pi}{2}}\left[-\sqrt{a^2-r^2}\right]_0^{a\cos\theta}d\theta$$
$$= a\int_0^{\frac{\pi}{2}}\left(a - a\sin\theta\right)d\theta = a^2\left[\theta + \cos\theta\right]_0^{\frac{\pi}{2}} = a^2\left(\frac{\pi}{2} - 1\right)$$

总面积 $S = 4S_1 = 4a^2\left(\dfrac{\pi}{2} - 1\right) = 2a^2(\pi - 2)$。

> **点评：** 经典考题，关键在代公式得 $\frac{a}{\sqrt{a^2-x^2-y^2}}$ 后正确使用极坐标，$r$ 从 $0$ 到 $a\cos\theta$ 的积分限由柱面方程决定。

## 第四章：曲线积分与曲面积分

### 四类积分一眼看清

在进入各节之前，先把第四章的四类积分放在一起，建立全局视野。

#### 核心对比表

| | **第一类（无方向）** | **第二类（有方向）** |
|---|---|---|
| **曲线积分** | $\int_L f\,ds$ | $\int_L P\,dx+Q\,dy$ |
| **曲面积分** | $\iint_\Sigma f\,dS$ | $\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy$ |

#### 怎么辨别这四类积分

先看积分区域，再看微元：

1. 积分区域是曲线 $L$，且微元是 $ds$ → **第一类曲线积分**
2. 积分区域是曲线 $L$，且出现 $dx,dy$ → **第二类曲线积分**
3. 积分区域是曲面 $\Sigma$，且微元是 $dS$ → **第一类曲面积分**
4. 积分区域是曲面 $\Sigma$，且出现 $dydz,dzdx,dxdy$ → **第二类曲面积分**

> **一句话口诀：**  
> $ds,dS$ 是普通长度/面积，所以**无方向**；  
> $dx,dy,dydz,dzdx,dxdy$ 是有符号的投影微元，所以**有方向**。

#### 四类经典例题

**例1：第一类曲线积分**

计算 $\displaystyle \int_L (x+y)\,ds$，其中 $L$ 是从 $(0,0)$ 到 $(1,1)$ 的直线段。

**辨别：** 积分区域是曲线 $L$，微元是 $ds$，所以是**第一类曲线积分**。它表示沿曲线对密度 $x+y$ 称重，不考虑方向。

参数化直线段：
$$x=t,\quad y=t,\quad 0\leq t\leq 1$$

于是：
$$ds=\sqrt{(dx)^2+(dy)^2}=\sqrt{1^2+1^2}\,dt=\sqrt2\,dt$$

所以：
$$\int_L (x+y)\,ds=\int_0^1 (t+t)\sqrt2\,dt=\sqrt2$$

如果把路径反过来，从 $(1,1)$ 走到 $(0,0)$，结果仍然是 $\sqrt2$。

---

**例2：第二类曲线积分**

计算 $\displaystyle \int_L y\,dx+x\,dy$，其中 $L$ 是从 $(0,0)$ 到 $(1,1)$ 的直线段。

**辨别：** 积分区域是曲线 $L$，微元是 $dx,dy$，所以是**第二类曲线积分**。它表示向量场沿路径做功，必须看方向。

仍取参数化：
$$x=t,\quad y=t,\quad 0\leq t\leq 1$$

则：
$$dx=dt,\quad dy=dt$$

所以：
$$\int_L y\,dx+x\,dy=\int_0^1 (t\cdot 1+t\cdot 1)\,dt=\int_0^1 2t\,dt=1$$

如果路径反向，结果变为 $-1$。

---

**例3：第一类曲面积分**

计算 $\displaystyle \iint_\Sigma z\,dS$，其中 $\Sigma$ 是平面 $z=1$ 在单位圆盘 $x^2+y^2\leq 1$ 上方的部分。

**辨别：** 积分区域是曲面 $\Sigma$，微元是 $dS$，所以是**第一类曲面积分**。它表示曲面上的面密度积分，不考虑曲面的上侧或下侧。

因为曲面是水平平面 $z=1$，所以：
$$dS=dxdy$$

投影区域是单位圆盘 $D:x^2+y^2\leq 1$，并且 $z=1$，因此：
$$\iint_\Sigma z\,dS=\iint_D 1\,dxdy=\pi$$

如果把曲面取下侧，结果仍然是 $\pi$。

---

**例4：第二类曲面积分**

计算 $\displaystyle \iint_\Sigma z\,dxdy$，其中 $\Sigma$ 是平面 $z=1$ 在单位圆盘 $x^2+y^2\leq 1$ 上方的部分，取上侧。

**辨别：** 积分区域是曲面 $\Sigma$，微元是 $dxdy$，所以是**第二类曲面积分**。它表示向量场穿过曲面的通量，必须看曲面的侧。

取上侧时，$dxdy$ 为正：
$$\iint_\Sigma z\,dxdy=\iint_D 1\,dxdy=\pi$$

如果改取下侧，则：
$$\iint_\Sigma z\,dxdy=-\iint_D 1\,dxdy=-\pi$$

所以第二类曲面积分最核心的特点就是：**换侧会变号**。

#### 本质区别

| 维度 | 第一类 | 第二类 |
|---|---|---|
| **物理模型** | 沿曲线/曲面**称重**（密度×长度/面积） | 力沿曲线做**功**；流体穿曲面的**通量** |
| **积分微元** | $ds$（弧长，恒正）；$dS$（面积，恒正） | $dx,dy$（有符号）；$dydz,dzdx,dxdy$（有符号） |
| **方向性** | **无关**：反向结果不变 | **有关**：反向结果变号 |
| **快捷定理** | 参数化后化为定积分 | 格林公式（平面）/ 高斯公式（空间）/ 斯托克斯公式 |

#### 两类之间的联系

$$\int_L P\,dx+Q\,dy = \int_L (P\cos\alpha + Q\cos\beta)\,ds \qquad \text{（曲线）}$$

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy = \iint_\Sigma (P\cos\alpha+Q\cos\beta+R\cos\gamma)\,dS \qquad \text{（曲面）}$$

其中 $(\cos\alpha,\cos\beta)$ / $(\cos\alpha,\cos\beta,\cos\gamma)$ 分别是正向单位切向量 / 正侧单位法向量。

> **规律**：第二类 = 第一类把被积函数换成"向量场在切/法方向的投影"。第二类比第一类多了方向投影这一步，所以有方向性。

#### 四条方向结论（必背）

1. 第一类曲线积分 → 与方向**无关**
2. 第二类曲线积分 → 反向**变号**
3. 第一类曲面积分 → 与侧**无关**
4. 第二类曲面积分 → 反侧**变号**

---

### 4.1 第一类曲线积分（对弧长的曲线积分）

#### 概念：沿曲线"称重"

想象一根弯曲的铁丝，铁丝上每个位置的线密度（每单位长度的质量）不同，用函数 $f(x,y)$ 表示。那么铁丝的总质量就是：

$$\int_L f(x,y)\,ds$$

这里 $ds$ 是弧长微元——极短的一小段弧的长度。把每小段的密度乘以长度再全部加起来，就是总质量。这就是**第一类曲线积分**（也叫对弧长的曲线积分）。

**关键特征：**
- $ds$ 是弧长微元，**永远非负**（无论曲线走哪个方向，长度都是正的）
- 因此，第一类曲线积分**与曲线方向无关**

$$\int_{L} f\,ds = \int_{L^-} f\,ds \quad \text{（$L^-$ 是 $L$ 的反向）}$$

---

#### 计算方法：参数化曲线

**核心思路：** 把曲线用参数 $t$ 表示，把 $ds$ 用 $dt$ 表示，化为普通一元积分。

设曲线 $L$：$x=x(t)$，$y=y(t)$，$t$ 从 $\alpha$ 到 $\beta$，则弧长微元：

$$ds = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt = \sqrt{x'^2(t)+y'^2(t)}\,dt$$

所以：

$$\int_L f(x,y)\,ds = \int_\alpha^\beta f\bigl(x(t),y(t)\bigr)\sqrt{x'^2(t)+y'^2(t)}\,dt$$

**注意：** 参数化后积分下限 $\alpha < \beta$（保证 $t$ 是增加的，$ds>0$），若原曲线是反向的，先参数化再积分即可，不用担心符号。

---

#### 三种常用情形

**情形1：** 曲线由 $y=y(x)$ 给出，$x$ 从 $a$ 到 $b$：

$$\int_L f\,ds = \int_a^b f(x,y(x))\sqrt{1+y'^2(x)}\,dx$$

**情形2：** 曲线由 $x=x(y)$ 给出，$y$ 从 $c$ 到 $d$：

$$\int_L f\,ds = \int_c^d f(x(y),y)\sqrt{x'^2(y)+1}\,dy$$

**情形3：** 极坐标曲线 $r=r(\theta)$，$\theta$ 从 $\alpha$ 到 $\beta$：

$$ds = \sqrt{r^2(\theta)+r'^2(\theta)}\,d\theta$$

---

#### 例题

**例：** 计算 $\int_L (x^2+y^2)\,ds$，$L$ 是圆 $x^2+y^2=a^2$（完整一圈）。

参数化：$x=a\cos t$，$y=a\sin t$，$t\in[0,2\pi]$

$$ds = \sqrt{(-a\sin t)^2+(a\cos t)^2}\,dt = a\,dt$$

在圆上 $x^2+y^2 = a^2$（常数），所以：

$$\int_L (x^2+y^2)\,ds = \int_0^{2\pi} a^2 \cdot a\,dt = a^3 \cdot 2\pi = 2\pi a^3$$

> **技巧：** 被积函数在曲线上是常数时，直接乘以弧长即可。圆的弧长 $= 2\pi a$，所以结果是 $a^2 \times 2\pi a$。

**例（被积函数非常数）：** 计算 $\int_L y\,ds$，$L$ 是抛物线 $y=x^2$ 上从 $(0,0)$ 到 $(1,1)$ 的一段。

曲线由 $y=y(x)$ 给出，用情形1：$y'=2x$，$\sqrt{1+y'^2}=\sqrt{1+4x^2}$。

$$\int_L y\,ds = \int_0^1 x^2\sqrt{1+4x^2}\,dx$$

这是普通定积分（可用三角换元或查表），重点是体会"先把 $ds$ 换成 $\sqrt{1+y'^2}\,dx$，再把 $y$ 用 $x^2$ 代入"这一标准流程。

> **对比体会方向无关性：** 若把 $L$ 反向（从 $(1,1)$ 到 $(0,0)$），参数化时仍取 $x$ 从 $0$ 到 $1$，结果完全相同——这正是第一类"与方向无关"的体现。

---

### 4.2 第二类曲线积分（对坐标的曲线积分）

#### 概念：力做的功

一个力 $\vec{F}=(P,Q)$ 推着质点沿曲线 $L$ 移动，做了多少功？

在直线匀速运动中，功 $= \vec{F}\cdot\vec{d}$（力点乘位移）。在曲线运动中，把路径切成无数小段，每段位移向量 $d\vec{r}=(dx, dy)$，力做的微元功是 $\vec{F}\cdot d\vec{r} = P\,dx + Q\,dy$，全部积起来就是总功：

$$W = \int_L P\,dx + Q\,dy$$

这就是**第二类曲线积分**（也叫对坐标的曲线积分）。

**关键特征：** 第二类曲线积分**与方向有关**——顺着走是做正功，倒着走是做负功：

$$\int_{L^-} P\,dx+Q\,dy = -\int_L P\,dx+Q\,dy$$

这和第一类截然不同，一定要记住。

---

#### 计算方法：参数化

设曲线 $L$：$x=x(t)$，$y=y(t)$，$t$ 从 $\alpha$（起点）到 $\beta$（终点），则：

$$\int_L P\,dx+Q\,dy = \int_\alpha^\beta \Bigl[P(x(t),y(t))\cdot x'(t) + Q(x(t),y(t))\cdot y'(t)\Bigr]dt$$

**注意：** 这里 $t$ 的上下限对应起点和终点，$\alpha$ 可以大于 $\beta$（路径方向决定上下限，不像第一类要求 $\alpha<\beta$）。

---

#### 两类曲线积分的联系

设曲线 $L$ 的切向量方向余弦为 $(\cos\alpha, \cos\beta)$（即单位切向量），则：

$$\int_L P\,dx+Q\,dy = \int_L (P\cos\alpha + Q\cos\beta)\,ds$$

右边是第一类曲线积分。直觉：力在切线方向的分量，乘以弧长，就是功。

---

#### 例题

**例：** 计算 $\int_L y\,dx - x\,dy$，$L$ 是从 $A(1,0)$ 到 $B(0,1)$ 的直线段。

参数化：$x=1-t$，$y=t$，$t$ 从 $0$ 到 $1$，则 $dx=-dt$，$dy=dt$

$$= \int_0^1 \bigl[t\cdot(-1) - (1-t)\cdot 1\bigr]dt = \int_0^1(-t-1+t)\,dt = \int_0^1(-1)\,dt = -1$$

**如果走反方向**（从 $B$ 到 $A$），结果是 $+1$，符号相反。

---

### 两类曲线积分对比小结

| | 第一类 $\int_L f\,ds$ | 第二类 $\int_L P\,dx+Q\,dy$ |
|---|---|---|
| **微元** | $ds=\sqrt{x'^2+y'^2}\,dt$（恒正） | $dx=x'dt,\;dy=y'dt$（有正负） |
| **方向** | 无关，$\int_{L^-}=\int_L$ | 有关，$\int_{L^-}=-\int_L$ |
| **积分上下限** | 保证 $\alpha<\beta$（$ds>0$） | 上下限 = 起终点对应参数，可 $\alpha>\beta$ |
| **物理原型** | 弯铁丝的质量 | 力沿曲线做的功 |
| **平面封闭快捷** | 无特殊公式 | 格林公式 $\oint=\iint_D(Q_x-P_y)\,dA$ |

---

### 4.3 格林公式 & 积分路径无关

#### 格林公式

**一句话：** 把沿封闭曲线的线积分，转化成区域内部的二重积分。

设 $D$ 是平面上的有界闭区域，$L$ 是其边界，取**正向**（逆时针方向，使区域始终在左手边），$P(x,y)$、$Q(x,y)$ 在 $D$ 上有连续偏导数，则：

$$\oint_L P\,dx + Q\,dy = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dA$$

**怎么记？** 右边是 $Q$ 对 $x$ 的偏导减去 $P$ 对 $y$ 的偏导，顺序是"$Q$ 在前减 $P$ 在后"，和字母排列 $P,Q$ 交叉。

**为什么成立（直觉）？** 这是微积分基本定理的二维推广：边界上的积分等于内部"变化率"的积分。右边那个量 $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}$ 正是向量场 $(P,Q)$ 的"二维旋度"，描述场的旋转程度。

---

#### 格林公式的使用方法

**情形一：曲线封闭，直接用**

曲线积分是沿封闭曲线的，直接套公式转为二重积分。

**情形二：曲线不封闭，补线法**

路径不封闭时，补一段简单路径（如直线段）使之封闭，然后：

$$\int_{L\text{（原路径）}} = \oint_{L+L_0\text{（封闭）}} - \int_{L_0\text{（补的路径）}}$$

**情形三：区域有洞（点处分母为零）**

若 $P,Q$ 在某点（如原点）没有连续偏导，而该点在区域内，要在点外围再挖一个小圆，用"大减小"处理。

---

#### 例题

**例 1（情形一：曲线封闭，直接用）：** 计算 $\oint_L (x^2-y)\,dx + (y^2+x)\,dy$，$L$ 是圆 $x^2+y^2=1$ 的正向（逆时针）。

$P = x^2-y$，$Q = y^2+x$，则：
$$\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 1 - (-1) = 2$$

$$\oint_L = \iint_{x^2+y^2\leq 1} 2\,dA = 2\cdot\pi\cdot 1^2 = 2\pi$$

直接计算这个积分要参数化，麻烦得多；格林公式两行搞定。

**例 2（情形二：曲线不封闭，补线法）：** 计算 $\int_L -y\,dx + x\,dy$，其中 $L$ 是抛物线 $y=x^2$ 从 $(0,0)$ 到 $(1,1)$ 的弧段。

这条曲线不封闭。补上直线段 $L_0$：从 $(1,1)$ 回到 $(0,0)$，这样 $L+L_0$ 围成由 $y=x^2$ 与 $y=x$ 夹成的区域 $D$，方向为正向。

设 $P=-y$，$Q=x$，则：
$$\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 1 - (-1) = 2$$

所以：
$$\oint_{L+L_0} -y\,dx + x\,dy
= \iint_D 2\,dA
= 2\int_0^1(x-x^2)\,dx
= \frac13$$

再算补线 $L_0$。令 $x=t,\ y=t,\ t:1\to 0$，则 $dx=dy=dt$：
$$\int_{L_0} -y\,dx + x\,dy
= \int_1^0(-t+t)\,dt
= 0$$

因此：
$$\int_L -y\,dx + x\,dy
= \oint_{L+L_0} - \int_{L_0}
= \frac13$$

**例 3（情形三：区域有洞，挖小圆）：** 计算
$$\oint_L \frac{-y}{x^2+y^2}\,dx+\frac{x}{x^2+y^2}\,dy$$
其中 $L$ 是圆 $x^2+y^2=R^2$ 的正向（逆时针），$R>0$。

这里 $P=\dfrac{-y}{x^2+y^2}$，$Q=\dfrac{x}{x^2+y^2}$，在原点无定义，不能直接在整个圆盘上用格林公式。挖去原点附近的小圆 $C_\varepsilon:x^2+y^2=\varepsilon^2$，得到环形区域。

在环形区域内：
$$\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}=0$$

注意环形区域的正向边界是：外圈 $L$ 逆时针，内圈 $C_\varepsilon$ 顺时针。由格林公式：
$$\int_L + \int_{C_\varepsilon\text{（顺时针）}}=0$$

所以：
$$\int_L=\int_{C_\varepsilon\text{（逆时针）}}$$

令小圆逆时针参数方程为 $x=\varepsilon\cos t,\ y=\varepsilon\sin t,\ 0\leq t\leq 2\pi$，则：
$$dx=-\varepsilon\sin t\,dt,\quad dy=\varepsilon\cos t\,dt$$

代入：
$$\int_L
=\int_0^{2\pi}
\left[
\frac{-\varepsilon\sin t}{\varepsilon^2}(-\varepsilon\sin t)
+\frac{\varepsilon\cos t}{\varepsilon^2}(\varepsilon\cos t)
\right]dt
=\int_0^{2\pi}1\,dt
=2\pi$$

这个例子说明：有奇点在区域内部时，不能直接把整个区域套进格林公式，必须先把奇点挖掉。

---

#### 积分路径无关

**问题：** 什么情况下，从点 $A$ 到点 $B$ 的曲线积分，不管走什么路，结果都一样？

**等价条件（在单连通域 $D$ 内，四个条件互相等价）：**

| 条件 | 表述 |
|------|------|
| ① | $\int_L P\,dx+Q\,dy$ 与路径无关（只与端点有关） |
| ② | 沿 $D$ 内任意封闭曲线 $\oint = 0$ |
| ③ | $\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$ 在 $D$ 内处处成立 |
| ④ | 存在函数 $u(x,y)$ 使得 $du = P\,dx + Q\,dy$ |

**实际做题：** 先验证条件③（最容易验证），若成立则路径无关，再求势函数 $u$。

**单连通域：** 区域内没有"洞"（不包含奥运五环那种带孔区域）。有洞时条件③不够，可能还有问题。

---

#### 求势函数的方法

已知 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$，求 $u$ 使得 $u_x = P$，$u_y = Q$。

**方法：折线积分法**

取固定点 $(x_0, y_0)$（一般取原点），沿折线先水平再竖直：

$$u(x,y) = \int_{x_0}^x P(t, y_0)\,dt + \int_{y_0}^y Q(x, s)\,ds$$

**例：** $P = 2xy$，$Q = x^2$，验证路径无关并求势函数。

验证：$P_y = 2x = Q_x = 2x$ ✓

取 $(x_0,y_0)=(0,0)$：
$$u = \int_0^x 2t\cdot 0\,dt + \int_0^y x^2\,ds = 0 + x^2 y = x^2 y$$

验证：$u_x = 2xy = P$，$u_y = x^2 = Q$ ✓

> **技巧：** 路径无关时，$\int_A^B P\,dx+Q\,dy = u(B) - u(A)$，和牛顿-莱布尼茨公式完全类似。

**综合例（验证→求势函数→算值）：** 计算 $\int_L (2xy+y^2)\,dx + (x^2+2xy)\,dy$，$L$ 是从 $A(0,0)$ 到 $B(1,2)$ 的任意路径。

第一步，验证路径无关：$P=2xy+y^2$，$Q=x^2+2xy$，
$$P_y = 2x+2y, \qquad Q_x = 2x+2y \quad\Rightarrow\quad P_y=Q_x \checkmark$$
全平面是单连通域，故路径无关。

第二步，求势函数（取 $(0,0)$ 起点的折线积分法）：
$$u(x,y) = \int_0^x P(t,0)\,dt + \int_0^y Q(x,s)\,ds = \int_0^x 0\,dt + \int_0^y (x^2+2xs)\,ds = x^2 y + xy^2$$

验证：$u_x = 2xy+y^2 = P$，$u_y = x^2+2xy = Q$ ✓

第三步，用 $u(B)-u(A)$ 直接出结果：
$$\int_L = u(1,2)-u(0,0) = (1\cdot 2 + 1\cdot 4) - 0 = 6$$

> **体会：** 一旦确认路径无关，就完全不用管 $L$ 长什么样，只需端点坐标，这正是势函数（势能）的威力。

### 4.4 第一类曲面积分（对面积的曲面积分）

#### 概念：曲面上"称重"

铁丝称重是第一类曲线积分，那薄壳（曲面）称重呢？

给定空间曲面 $\Sigma$，其上每点 $(x,y,z)$ 的面密度为 $f(x,y,z)$（单位面积质量）。把曲面切成无数小块，每块面积 $\Delta S_i$，在每块上取一点乘以密度，加总取极限：

$$\iint_\Sigma f(x,y,z)\,dS$$

这是**第一类曲面积分**（对面积的曲面积分）。

**关键特征：**
- $dS$ 是面积微元，**永远非负**
- 第一类曲面积分**与曲面的侧（方向）无关**——面密度不管从哪面看都一样

---

#### 计算方法

设曲面 $\Sigma$ 由方程 $z = z(x,y)$ 给出，投影到 $xy$ 平面上的区域为 $D_{xy}$，则：

$$\iint_\Sigma f(x,y,z)\,dS = \iint_{D_{xy}} f\bigl(x,y,z(x,y)\bigr)\sqrt{1+z_x^2+z_y^2}\,dA$$

**面积微元的来历：**

曲面微元 $dS$ 是一小块斜面，它在 $xy$ 平面的投影面积是 $dA$，两者关系是：

$$dS = \frac{dA}{\cos\gamma} = \sqrt{1+z_x^2+z_y^2}\,dA$$

其中 $\cos\gamma$ 是曲面法向量与 $z$ 轴的夹角余弦。曲面越陡（偏导越大），这个放大因子越大。

**如果曲面用 $x=x(y,z)$ 或 $y=y(x,z)$ 给出：**

$$dS = \sqrt{1+x_y^2+x_z^2}\,dydz \quad \text{或} \quad dS = \sqrt{1+y_x^2+y_z^2}\,dxdz$$

---

#### 选哪种方法？

第一类曲面积分的关键不是方向，而是把 $dS$ 换成平面区域上的面积微元。

常见做法：

| 曲面形式 | 推荐方法 | 面积微元 |
|---|---|---|
| $z=z(x,y)$ | 投影到 $xy$ 面 | $dS=\sqrt{1+z_x^2+z_y^2}\,dxdy$ |
| $x=x(y,z)$ | 投影到 $yz$ 面 | $dS=\sqrt{1+x_y^2+x_z^2}\,dydz$ |
| $y=y(x,z)$ | 投影到 $xz$ 面 | $dS=\sqrt{1+y_x^2+y_z^2}\,dxdz$ |
| 柱面、球面、锥面 | 参数方程 | $dS=|\vec r_u\times \vec r_v|\,du\,dv$ |

**选择原则：**
- 谁能写成单值函数，就优先投影到对应坐标面。
- 投影区域越简单越好，例如圆盘用极坐标，矩形区域用直角坐标。
- 球面、柱面这类天然带参数的曲面，直接参数化通常更快。

---

#### 参数方程法

若曲面由两个参数给出：

$$\vec r(u,v)=\bigl(x(u,v),y(u,v),z(u,v)\bigr),\quad (u,v)\in D$$

则第一类曲面积分为：

$$\iint_\Sigma f(x,y,z)\,dS
=\iint_D f\bigl(x(u,v),y(u,v),z(u,v)\bigr)\,|\vec r_u\times \vec r_v|\,dudv$$

其中：

$$dS=|\vec r_u\times \vec r_v|\,dudv$$

这里的叉乘只用来算面积放大倍数，不涉及曲面正侧，所以取长度，结果永远非负。

---

#### 常见曲面的 $dS$

**1. 平面 $Ax+By+Cz+D=0$**

若写成 $z=z(x,y)$，则：

$$dS=\sqrt{1+z_x^2+z_y^2}\,dxdy$$

特别地，若平面为 $z=ax+by+c$，则：

$$dS=\sqrt{1+a^2+b^2}\,dxdy$$

**2. 圆柱面 $x^2+y^2=a^2$**

参数方程：

$$x=a\cos\theta,\quad y=a\sin\theta,\quad z=z$$

面积微元：

$$dS=a\,d\theta\,dz$$

**3. 球面 $x^2+y^2+z^2=a^2$**

参数方程：

$$x=a\sin\varphi\cos\theta,\quad y=a\sin\varphi\sin\theta,\quad z=a\cos\varphi$$

面积微元：

$$dS=a^2\sin\varphi\,d\varphi\,d\theta$$

**4. 锥面 $z=\sqrt{x^2+y^2}$**

投影到 $xy$ 面，记 $r=\sqrt{x^2+y^2}$，则：

$$dS=\sqrt2\,dxdy$$

---

#### 利用对称性简化

若曲面 $\Sigma$ 关于 $xOy$ 面对称（即曲面上 $(x,y,z)$ 和 $(x,y,-z)$ 都在上面），则：
- 被积函数 $f$ 关于 $z$ 是奇函数 → 积分为 0
- 被积函数 $f$ 关于 $z$ 是偶函数 → 积分等于上半部分的两倍

---

#### 例题

**例 1（图形曲面：先求 $dS$）：** 计算 $\iint_\Sigma z\,dS$，其中 $\Sigma$ 为抛物面 $z=x^2+y^2$ 在圆柱 $x^2+y^2\leq 1$ 内的部分。

曲面写成 $z=z(x,y)=x^2+y^2$，投影区域为：

$$D:x^2+y^2\leq 1$$

先求偏导：

$$z_x=2x,\qquad z_y=2y$$

所以：

$$dS=\sqrt{1+4x^2+4y^2}\,dxdy$$

原积分变成：

$$\iint_D (x^2+y^2)\sqrt{1+4x^2+4y^2}\,dxdy$$

换极坐标：

$$= \int_0^{2\pi}\int_0^1 r^2\sqrt{1+4r^2}\cdot r\,dr\,d\theta$$

$$=2\pi\int_0^1 r^3\sqrt{1+4r^2}\,dr$$

令 $u=1+4r^2$，则：

$$\int_0^1 r^3\sqrt{1+4r^2}\,dr
=\frac1{32}\int_1^5(u-1)u^{1/2}\,du$$

所以：

$$\iint_\Sigma z\,dS
=\frac{\pi(25\sqrt5+1)}{60}$$

> **技巧：** 图形曲面题的固定步骤是：写投影区域 $D$ → 算 $z_x,z_y$ → 代入 $\sqrt{1+z_x^2+z_y^2}$。

**例 2（圆柱面：用参数方程）：** 计算 $\iint_\Sigma (x^2+y^2+z^2)\,dS$，其中 $\Sigma$ 是圆柱面 $x^2+y^2=a^2$，$0\leq z\leq h$ 的侧面。

圆柱面适合参数化：

$$x=a\cos\theta,\quad y=a\sin\theta,\quad z=z$$

其中：

$$0\leq \theta\leq 2\pi,\qquad 0\leq z\leq h$$

圆柱面的面积微元：

$$dS=a\,d\theta\,dz$$

又因为在圆柱面上：

$$x^2+y^2=a^2$$

所以：

$$\iint_\Sigma (x^2+y^2+z^2)\,dS
=\int_0^{2\pi}\int_0^h(a^2+z^2)a\,dz\,d\theta$$

$$=2\pi a\left(a^2h+\frac{h^3}{3}\right)$$

> **技巧：** 柱面题不要硬投影成上下两片，直接用 $\theta,z$ 参数最干净。

**例 3（锥面：投影后用极坐标）：** 计算 $\iint_\Sigma z\,dS$，其中 $\Sigma$ 是锥面 $z=\sqrt{x^2+y^2}$，$0\leq z\leq a$ 的部分。

锥面投影到 $xy$ 平面是圆盘：

$$D:x^2+y^2\leq a^2$$

记 $r=\sqrt{x^2+y^2}$，曲面上 $z=r$。对锥面 $z=\sqrt{x^2+y^2}$，有：

$$dS=\sqrt2\,dxdy$$

因此：

$$\iint_\Sigma z\,dS
=\iint_D r\sqrt2\,dxdy$$

换极坐标：

$$=\int_0^{2\pi}\int_0^a r\sqrt2\cdot r\,dr\,d\theta
=2\pi\sqrt2\cdot\frac{a^3}{3}
=\frac{2\sqrt2\pi a^3}{3}$$

> **技巧：** 锥面 $z=r$ 的面积放大因子是 $\sqrt2$，之后基本就是极坐标二重积分。

**例 4（球面片：球坐标面积元）：** 计算 $\iint_\Sigma z^2\,dS$，其中 $\Sigma$ 是上半球面 $x^2+y^2+z^2=a^2,\ z\geq 0$。

上半球可参数化为：

$$x=a\sin\varphi\cos\theta,\quad y=a\sin\varphi\sin\theta,\quad z=a\cos\varphi$$

参数范围：

$$0\leq \theta\leq 2\pi,\qquad 0\leq \varphi\leq \frac{\pi}{2}$$

球面面积微元：

$$dS=a^2\sin\varphi\,d\varphi\,d\theta$$

所以：

$$\iint_\Sigma z^2\,dS
=\int_0^{2\pi}\int_0^{\pi/2}a^2\cos^2\varphi\cdot a^2\sin\varphi\,d\varphi\,d\theta$$

$$=2\pi a^4\int_0^{\pi/2}\cos^2\varphi\sin\varphi\,d\varphi
=\frac{2\pi a^4}{3}$$

> **技巧：** 球面题只要看到 $x^2+y^2+z^2=a^2$，优先想球坐标面积元 $a^2\sin\varphi$。

**例 5（对称性：少算很多）：** 计算 $\iint_\Sigma (x^2+y^2)\,dS$，$\Sigma$ 是球面 $x^2+y^2+z^2=a^2$。

由轮换对称性（球面关于 $x,y,z$ 完全对称）：

$$\iint_\Sigma x^2\,dS = \iint_\Sigma y^2\,dS = \iint_\Sigma z^2\,dS$$

所以：

$$\iint_\Sigma (x^2+y^2)\,dS = \frac{2}{3}\iint_\Sigma(x^2+y^2+z^2)\,dS = \frac{2}{3}\iint_\Sigma a^2\,dS = \frac{2}{3}a^2\cdot 4\pi a^2 = \frac{8\pi a^4}{3}$$

（球面面积 $= 4\pi a^2$）

> **技巧：** 遇到球面上的积分，先用轮换对称性看能不能把 $x^2+y^2$ 或 $x^2+y^2+z^2$ 凑出来，常常能大幅简化。

---

### 4.5 第二类曲面积分（对坐标的曲面积分）

#### 概念：流体穿过曲面的流量

水在流动，曲面 $\Sigma$ 横在水流中。问：单位时间内，有多少水**穿过**这个曲面？

这就是**通量**（flux）。计算通量时，方向很重要——从正面穿过是正的，从背面穿过是负的，所以曲面必须指定"哪面是正面"（即曲面的**侧**）。

设流速场 $\vec{F} = (P, Q, R)$，曲面 $\Sigma$ 上面积微元向量 $d\vec{S} = (dydz,\, dzdx,\, dxdy)$（方向是法向量方向），则通量：

$$\Phi = \iint_\Sigma \vec{F}\cdot d\vec{S} = \iint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy$$

这就是**第二类曲面积分**。

**关键特征：**
- 与曲面的**侧（方向）有关**，取反侧结果变号
- $dydz$、$dzdx$、$dxdy$ 是**有向面积微元**（可正可负）

---

#### 有向面积微元的理解

$dxdy$ 不是普通面积，它是法向量在 $z$ 方向分量乘以面积微元：

$$dxdy = \cos\gamma\,dS$$

其中 $\cos\gamma$ 是法向量与 $z$ 轴夹角的余弦。取上侧（法向量朝上）时 $\cos\gamma > 0$，$dxdy > 0$；取下侧时 $\cos\gamma < 0$，$dxdy < 0$。

---

#### 计算方法

**1. 投影到 $xy$ 面**

设曲面 $\Sigma$：$z = z(x,y)$，投影到 $D_{xy}$。

**取上侧（法向量朝上）：**

$$\iint_\Sigma R(x,y,z)\,dxdy = +\iint_{D_{xy}} R(x,y,z(x,y))\,dxdy$$

**取下侧（法向量朝下）：**

$$\iint_\Sigma R(x,y,z)\,dxdy = -\iint_{D_{xy}} R(x,y,z(x,y))\,dxdy$$

**完整公式（上侧取正号，下侧取负号）：**

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy = \pm\iint_{D_{xy}}\left(-Pz_x - Qz_y + R\right)dxdy$$

推导：把 $dydz = -z_x\,dxdy$，$dzdx = -z_y\,dxdy$ 代入（这来自曲面方程的隐函数关系）。

**2. 投影到 $yz$ 面**

若曲面写成 $x=x(y,z)$，投影到 $D_{yz}$。

**取右侧（法向量 $x$ 分量为正）：**

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy
=\iint_{D_{yz}}\left(P-Qx_y-Rx_z\right)dydz$$

**取左侧（法向量 $x$ 分量为负）：**

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy
=-\iint_{D_{yz}}\left(P-Qx_y-Rx_z\right)dydz$$

**3. 投影到 $xz$ 面**

若曲面写成 $y=y(x,z)$，投影到 $D_{xz}$。

**取前侧（法向量 $y$ 分量为正）：**

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy
=\iint_{D_{xz}}\left(-Py_x+Q-Ry_z\right)dxdz$$

**取后侧（法向量 $y$ 分量为负）：**

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy
=-\iint_{D_{xz}}\left(-Py_x+Q-Ry_z\right)dxdz$$

> **记忆口诀：** 投影到哪个坐标面，就看法向量在垂直于该坐标面的轴上是正还是负。上侧/右侧/前侧取 $+$，下侧/左侧/后侧取 $-$。

---

#### 方向怎么判断？

第二类曲面积分最容易错在方向。判断正侧时，只看法向量的大致方向：

| 曲面侧 | 法向量特征 | 公式取号 |
|---|---|---|
| 上侧 | $n_z>0$ | $+$ |
| 下侧 | $n_z<0$ | $-$ |
| 右侧 | $n_x>0$ | $+$ |
| 左侧 | $n_x<0$ | $-$ |
| 前侧 | $n_y>0$ | $+$ |
| 后侧 | $n_y<0$ | $-$ |
| 封闭曲面外侧 | 法向量朝区域外部 | 通常用高斯公式 |
| 封闭曲面内侧 | 法向量朝区域内部 | 外侧结果取负 |

**关键提醒：**
- 第一类曲面积分换侧不变。
- 第二类曲面积分换侧一定变号。
- 题目没说明曲面的侧时，第二类曲面积分通常还不能唯一确定。

---

#### 参数方程法

若曲面由参数方程给出：

$$\vec r(u,v)=\bigl(x(u,v),y(u,v),z(u,v)\bigr),\quad (u,v)\in D$$

取正侧由 $\vec r_u\times \vec r_v$ 决定，则：

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy
=\iint_D \vec F(\vec r(u,v))\cdot(\vec r_u\times \vec r_v)\,dudv$$

其中 $\vec F=(P,Q,R)$。

如果 $\vec r_u\times \vec r_v$ 的方向和题目指定的正侧相反，就整体加负号：

$$\iint_\Sigma \vec F\cdot d\vec S
=-\iint_D \vec F(\vec r(u,v))\cdot(\vec r_u\times \vec r_v)\,dudv$$

> **和第一类参数法的区别：** 第一类用 $|\vec r_u\times \vec r_v|$，只取长度；第二类用 $\vec r_u\times \vec r_v$，保留方向。

---

#### 两类曲面积分的联系

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy = \iint_\Sigma (P\cos\alpha+Q\cos\beta+R\cos\gamma)\,dS$$

左边是第二类，右边是第一类。$(\cos\alpha,\cos\beta,\cos\gamma)$ 是曲面正侧的单位法向量。

---

#### 例题

**例 1（只含 $dxdy$，直接投影）：** 计算 $\iint_\Sigma z\,dxdy$，$\Sigma$ 是球面 $x^2+y^2+z^2=1$ 的上半部分，取上侧。

上半球：$z = \sqrt{1-x^2-y^2}$，投影区域 $D_{xy}: x^2+y^2\leq 1$，取上侧取正号。

$$= \iint_{D_{xy}} \sqrt{1-x^2-y^2}\,dxdy$$

换极坐标：$r$ 从 $0$ 到 $1$，$\theta$ 从 $0$ 到 $2\pi$：

$$= \int_0^{2\pi}d\theta\int_0^1 \sqrt{1-r^2}\cdot r\,dr = 2\pi\cdot\left[-\frac{1}{3}(1-r^2)^{3/2}\right]_0^1 = 2\pi\cdot\frac{1}{3} = \frac{2\pi}{3}$$

如果改取下侧，结果立刻变成：

$$-\frac{2\pi}{3}$$

这就是第二类曲面积分“换侧变号”的体现。

**例 2（投影到 $xy$ 面：完整公式）：** 计算

$$\iint_\Sigma x\,dydz+y\,dzdx+z\,dxdy$$

其中 $\Sigma$ 是平面 $x+y+z=1$ 在第一卦限内的部分，取上侧。

将平面写成：

$$z=1-x-y$$

投影区域为：

$$D_{xy}:x\geq0,\ y\geq0,\ x+y\leq1$$

有：

$$z_x=-1,\qquad z_y=-1$$

取上侧，用公式：

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy
=\iint_{D_{xy}}(-Pz_x-Qz_y+R)\,dxdy$$

这里 $P=x,\ Q=y,\ R=z=1-x-y$，所以：

$$-Pz_x-Qz_y+R=x+y+(1-x-y)=1$$

因此：

$$\iint_\Sigma x\,dydz+y\,dzdx+z\,dxdy
=\iint_{D_{xy}}1\,dxdy
=\frac12$$

> **技巧：** 平面片题常常会出现大量抵消，先别急着展开复杂积分。

**例 3（投影到 $yz$ 面：右侧取正）：** 计算

$$\iint_\Sigma x\,dydz+y\,dzdx+z\,dxdy$$

其中 $\Sigma$ 是平面 $x+y+z=1$ 在第一卦限内的部分，取右侧。

这次把平面写成：

$$x=1-y-z$$

投影区域为：

$$D_{yz}:y\geq0,\ z\geq0,\ y+z\leq1$$

有：

$$x_y=-1,\qquad x_z=-1$$

取右侧，用公式：

$$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy
=\iint_{D_{yz}}(P-Qx_y-Rx_z)\,dydz$$

这里 $P=x=1-y-z,\ Q=y,\ R=z$，所以：

$$P-Qx_y-Rx_z=(1-y-z)+y+z=1$$

因此：

$$\iint_\Sigma x\,dydz+y\,dzdx+z\,dxdy
=\iint_{D_{yz}}1\,dydz
=\frac12$$

> **注意：** 同一个平面片，取上侧和取右侧不是同一个方向。这个例子结果刚好相同，是因为向量场和曲面比较特殊，不能当成一般规律。

**例 4（参数方程法：圆柱侧面通量）：** 计算

$$\iint_\Sigma x\,dydz+y\,dzdx+z\,dxdy$$

其中 $\Sigma$ 是圆柱面 $x^2+y^2=a^2,\ 0\leq z\leq h$ 的侧面，取外侧。

取参数方程：

$$\vec r(\theta,z)=(a\cos\theta,\ a\sin\theta,\ z)$$

参数范围：

$$0\leq\theta\leq2\pi,\qquad 0\leq z\leq h$$

计算叉乘：

$$\vec r_\theta=(-a\sin\theta,\ a\cos\theta,\ 0),\qquad \vec r_z=(0,0,1)$$

$$\vec r_\theta\times \vec r_z=(a\cos\theta,\ a\sin\theta,\ 0)$$

这个方向正好朝圆柱外侧。

向量场 $\vec F=(x,y,z)$，代入曲面后：

$$\vec F(\vec r)=(a\cos\theta,\ a\sin\theta,\ z)$$

所以：

$$\vec F(\vec r)\cdot(\vec r_\theta\times \vec r_z)
=a^2\cos^2\theta+a^2\sin^2\theta
=a^2$$

因此：

$$\iint_\Sigma x\,dydz+y\,dzdx+z\,dxdy
=\int_0^{2\pi}\int_0^h a^2\,dz\,d\theta
=2\pi a^2h$$

> **技巧：** 柱面、球面这类曲面，用参数法往往比硬套投影公式更稳。

**例 5（封闭曲面的提示：优先想高斯公式）：** 计算

$$\oiint_\Sigma x\,dydz+y\,dzdx+z\,dxdy$$

其中 $\Sigma$ 是球面 $x^2+y^2+z^2=a^2$，取外侧。

这是封闭曲面，下一节会系统讲高斯公式。这里先看结论：

$$\oiint_\Sigma x\,dydz+y\,dzdx+z\,dxdy
=\iiint_\Omega (1+1+1)\,dV$$

其中 $\Omega$ 是半径为 $a$ 的球体，所以：

$$=3\cdot \frac{4}{3}\pi a^3=4\pi a^3$$

> **技巧：** 第二类曲面积分遇到封闭曲面，优先检查能不能用高斯公式，不要急着把球面拆成上下两半。

---

### 两类曲面积分对比小结

| | 第一类 $\iint_\Sigma f\,dS$ | 第二类 $\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy$ |
|---|---|---|
| **微元** | $dS=\sqrt{1+z_x^2+z_y^2}\,dxdy$（恒正） | $dxdy=\cos\gamma\,dS$（有正负） |
| **方向** | 无关，翻转曲面结果不变 | 有关，反侧变号 |
| **投影公式** | $\iint_{D_{xy}}f(x,y,z(x,y))\sqrt{1+z_x^2+z_y^2}\,dxdy$ | $\pm\iint_{D_{xy}}(-Pz_x-Qz_y+R)\,dxdy$ |
| **正负号规则** | 无需考虑 | 上侧/前侧/右侧取 $+$；下侧/后侧/左侧取 $-$ |
| **物理原型** | 薄壳的质量 | 流体穿过曲面的通量 |
| **封闭曲面快捷** | 无特殊公式 | 高斯公式 $\oiint=\iiint_\Omega(P_x+Q_y+R_z)\,dV$ |

> **与曲线积分类比**：第一类曲面 ↔ 第一类曲线（都无方向，都乘"拉伸因子"）；第二类曲面 ↔ 第二类曲线（都有方向，都有"大公式"转化为重积分）。

---

### 4.6 高斯公式

#### 概念：三维版的格林公式

格林公式把**平面封闭曲线**的积分转化为**区域内部**的二重积分。  
高斯公式把**封闭曲面**的积分转化为**空间体内部**的三重积分。

设 $\Omega$ 是空间有界闭区域，$\Sigma$ 是其边界曲面，取**外侧**（法向量朝外），$P,Q,R$ 在 $\Omega$ 上有连续偏导数，则：

$$\oiint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy = \iiint_\Omega \left(\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}\right)dV$$

右边括号内的量叫做向量场的**散度**：

$$\text{div}\,\vec{F} = \frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}$$

**物理直觉：** 穿出封闭曲面的总通量 = 内部所有"源"的强度之和。散度就是单位体积的"涌出量"。

---

#### 高斯公式的使用步骤

**步骤一：** 检查散度是否好计算，若是，考虑用高斯公式。

**步骤二：** 判断曲面是否封闭。
- 若封闭：直接用公式，算三重积分
- 若不封闭：**补一块简单曲面**（通常是平面片）使之封闭

**步骤三（补面情形）：**

$$\iint_{\Sigma\text{（原）}} = \oiint_{\Sigma+\Sigma_0\text{（封闭）}} - \iint_{\Sigma_0\text{（补的）}}$$

即：高斯公式算出封闭曲面的结果，再减去补的那块曲面的积分。

---

#### 例题

**例 1（封闭曲面，直接用）：** 计算 $\oiint_\Sigma x\,dydz + y\,dzdx + z\,dxdy$，$\Sigma$ 是球面 $x^2+y^2+z^2=a^2$ 外侧。

散度：$\frac{\partial x}{\partial x}+\frac{\partial y}{\partial y}+\frac{\partial z}{\partial z} = 1+1+1 = 3$

$$= \iiint_{x^2+y^2+z^2\leq a^2} 3\,dV = 3\cdot\frac{4}{3}\pi a^3 = 4\pi a^3$$

**例 2（长方体封闭面）：** 计算
$$\oiint_\Sigma x^2\,dydz+y^2\,dzdx+z^2\,dxdy$$
其中 $\Sigma$ 是长方体 $0\leq x\leq a,\ 0\leq y\leq b,\ 0\leq z\leq c$ 的外侧。

设 $P=x^2,\ Q=y^2,\ R=z^2$，则：

$$\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}=2x+2y+2z$$

由高斯公式：

$$\oiint_\Sigma x^2\,dydz+y^2\,dzdx+z^2\,dxdy
=\iiint_\Omega (2x+2y+2z)\,dV$$

分开算：

$$=bc\int_0^a2x\,dx+ac\int_0^b2y\,dy+ab\int_0^c2z\,dz$$

$$=a^2bc+ab^2c+abc^2=abc(a+b+c)$$

> **技巧：** 长方体封闭面如果逐面计算要分 6 个面；高斯公式只算一个三重积分。

**例 3（散度为 0）：** 计算
$$\oiint_\Sigma yz\,dydz+zx\,dzdx+xy\,dxdy$$
其中 $\Sigma$ 是任意分片光滑封闭曲面，取外侧。

设 $P=yz,\ Q=zx,\ R=xy$，则：

$$\frac{\partial P}{\partial x}=0,\qquad
\frac{\partial Q}{\partial y}=0,\qquad
\frac{\partial R}{\partial z}=0$$

所以散度为 $0$。由高斯公式：

$$\oiint_\Sigma yz\,dydz+zx\,dzdx+xy\,dxdy
=\iiint_\Omega 0\,dV=0$$

> **技巧：** 高斯公式不是一定为了算复杂三重积分；如果散度为 $0$，封闭曲面的通量直接为 $0$。

**例 4（非封闭曲面，补面）：** 计算 $\iint_\Sigma z^2\,dxdy$，$\Sigma$ 是锥面 $z=\sqrt{x^2+y^2}$（$0\leq z\leq 1$）的**下侧**。

锥面不封闭，补上顶盖 $\Sigma_0$：$z=1$，$x^2+y^2\leq 1$，取**上侧**。

封闭区域 $\Omega$：$\sqrt{x^2+y^2}\leq z\leq 1$，散度 $= \frac{\partial}{\partial z}(z^2)=2z$（这里只有 $R=z^2$，$P=Q=0$）。

第一步，对封闭曲面用高斯公式（外侧），化为三重积分，用柱坐标算：
$$\oiint_{\Sigma+\Sigma_0} z^2\,dxdy = \iiint_\Omega 2z\,dV = \int_0^{2\pi}d\theta\int_0^1 r\,dr\int_r^1 2z\,dz$$

内层：$\int_r^1 2z\,dz = 1-r^2$，于是
$$= 2\pi\int_0^1 (1-r^2)\,r\,dr = 2\pi\left[\frac{r^2}{2}-\frac{r^4}{4}\right]_0^1 = 2\pi\cdot\frac{1}{4} = \frac{\pi}{2}$$

第二步，减去补面 $\Sigma_0$（$z=1$，上侧）上的积分：
$$\iint_{\Sigma_0} z^2\,dxdy = \iint_{D: x^2+y^2\leq 1} 1\,dA = \pi$$

第三步，原积分 = 封闭结果 − 补面结果：
$$\iint_\Sigma z^2\,dxdy = \frac{\pi}{2} - \pi = -\frac{\pi}{2}$$

> **检查方向**：补面 $\Sigma_0$ 取上侧，与外侧朝向一致（顶盖朝外就是朝上），所以"封闭 = 原（下侧锥面）+ 上侧顶盖"成立，减号不要写错。

**例 5（半球面补底面）：** 计算
$$\iint_\Sigma x\,dydz+y\,dzdx+z\,dxdy$$
其中 $\Sigma$ 是上半球面 $x^2+y^2+z^2=a^2,\ z\geq 0$，取外侧。

上半球面不封闭，补上底面 $\Sigma_0:z=0,\ x^2+y^2\leq a^2$。对半球体来说，底面的外侧是**下侧**。

封闭曲面 $\Sigma+\Sigma_0$ 的散度为：

$$\frac{\partial x}{\partial x}+\frac{\partial y}{\partial y}+\frac{\partial z}{\partial z}=3$$

由高斯公式：

$$\oiint_{\Sigma+\Sigma_0} x\,dydz+y\,dzdx+z\,dxdy
=\iiint_\Omega 3\,dV$$

半球体体积为 $\dfrac{2}{3}\pi a^3$，所以：

$$\oiint_{\Sigma+\Sigma_0}=3\cdot\frac{2}{3}\pi a^3=2\pi a^3$$

再看补面 $\Sigma_0$。在底面上 $z=0$，且取下侧，只有 $z\,dxdy$ 这一项可能与上下侧有关，但 $z=0$，所以：

$$\iint_{\Sigma_0} x\,dydz+y\,dzdx+z\,dxdy=0$$

因此：

$$\iint_\Sigma x\,dydz+y\,dzdx+z\,dxdy
=2\pi a^3-0=2\pi a^3$$

> **技巧：** 半球、抛物面帽、锥面侧面这类非封闭曲面，通常补一个平面圆盘最省事。

### 4.7 斯托克斯公式、散度、旋度、通量

本节是对前面知识的整合与延伸，同时引入场论的基本概念。

---

#### 斯托克斯公式

**一句话：** 把空间封闭曲线的线积分，转化为以该曲线为边界的曲面上的面积分。

这是格林公式在三维空间的推广（格林公式 = 斯托克斯公式在平面上的特例）。

设 $\Sigma$ 是以有向闭曲线 $L$ 为边界的曲面，方向满足**右手定则**（右手四指沿 $L$ 弯曲，大拇指指向 $\Sigma$ 的正侧法向量），则：

$$\oint_L P\,dx+Q\,dy+R\,dz = \iint_\Sigma \begin{vmatrix} \cos\alpha & \cos\beta & \cos\gamma \\[4pt] \dfrac{\partial}{\partial x} & \dfrac{\partial}{\partial y} & \dfrac{\partial}{\partial z} \\[4pt] P & Q & R \end{vmatrix} dS$$

展开（用有向面积微元写更清晰）：

$$\oint_L P\,dx+Q\,dy+R\,dz = \iint_\Sigma \left(\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z}\right)dydz + \left(\frac{\partial P}{\partial z}-\frac{\partial R}{\partial x}\right)dzdx + \left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dxdy$$

**记忆技巧：** 括号内每项都是"后字母对前坐标偏导 减 前字母对后坐标偏导"，按 $(y,z)\to(z,x)\to(x,y)$ 轮换。

**右手定则直觉：** 想象螺旋桨叶片——叶片转动方向（$L$）和推进方向（法向量）满足右手定则。

---

#### 例题

**例：** 计算 $\oint_L y\,dx + z\,dy + x\,dz$，$L$ 是平面 $x+y+z=1$ 与三个坐标面围成的三角形边界，从 $z$ 轴正向看去取逆时针方向。

$P=y,\ Q=z,\ R=x$。先算旋度各分量：

$$\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z} = 0-1 = -1,\quad \frac{\partial P}{\partial z}-\frac{\partial R}{\partial x} = 0-1 = -1,\quad \frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y} = 0-1 = -1$$

取 $L$ 所围的平面块 $\Sigma$（即 $x+y+z=1$ 在第一卦限的三角形），其正侧法向量与 $L$ 的逆时针方向满足右手定则，指向 $(1,1,1)$ 一侧，单位法向量 $\vec{n}=\frac{1}{\sqrt3}(1,1,1)$，即 $\cos\alpha=\cos\beta=\cos\gamma=\frac{1}{\sqrt3}$。

$$\oint_L = \iint_\Sigma (-1)(dydz+dzdx+dxdy) = \iint_\Sigma (-1)(\cos\alpha+\cos\beta+\cos\gamma)\,dS = -\sqrt3\iint_\Sigma dS$$

三角形 $\Sigma$ 三个顶点为 $(1,0,0),(0,1,0),(0,0,1)$，是边长 $\sqrt2$ 的等边三角形，面积 $=\frac{\sqrt3}{4}(\sqrt2)^2=\frac{\sqrt3}{2}$。

$$\oint_L = -\sqrt3\cdot\frac{\sqrt3}{2} = -\frac{3}{2}$$

> **要点**：旋度三个分量都是常数时，斯托克斯公式右边就是"旋度 $\cdot$ 法向量 $\times$ 面积"，不必逐项投影。难点在确定法向量方向（由 $L$ 的方向 + 右手定则定）。

---

#### 三大场论概念

这三个概念贯穿整个场论，物理意义非常清晰。

##### 散度（Divergence）—— 衡量"涌出程度"

$$\text{div}\,\vec{F} = \nabla \cdot \vec{F} = \frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}$$

**物理意义：** 单位体积内流体的净涌出量。

| 散度值 | 含义 |
|--------|------|
| $> 0$ | 该点是**源**：流体从这里涌出 |
| $< 0$ | 该点是**汇**：流体在这里消失 |
| $= 0$ | **无源场**：流体既不产生也不消失 |

高斯公式的本质：$\oiint_\Sigma \vec{F}\cdot d\vec{S} = \iiint_\Omega \text{div}\,\vec{F}\,dV$，即"穿出封闭面的总通量 = 内部散度的积分"。

##### 旋度（Curl / Rotation）—— 衡量"旋转程度"

$$\text{rot}\,\vec{F} = \nabla \times \vec{F} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\[4pt] \dfrac{\partial}{\partial x} & \dfrac{\partial}{\partial y} & \dfrac{\partial}{\partial z} \\[4pt] P & Q & R \end{vmatrix}$$

展开：

$$\text{rot}\,\vec{F} = \left(\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z}\right)\vec{i} + \left(\frac{\partial P}{\partial z}-\frac{\partial R}{\partial x}\right)\vec{j} + \left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)\vec{k}$$

**物理意义：** 流场中某点处流体微元的旋转角速度（的两倍）。旋度方向 = 旋转轴方向（右手定则）。

**重要结论：**

$$\text{rot}\,\vec{F} = \vec{0} \iff \text{无旋场} \iff \text{存在势函数（保守场）} \iff \text{积分路径无关}$$

斯托克斯公式的本质：$\oint_L \vec{F}\cdot d\vec{r} = \iint_\Sigma \text{rot}\,\vec{F}\cdot d\vec{S}$，即"沿边界曲线的环量 = 曲面上旋度的积分"。

##### 通量（Flux）—— 穿过曲面的流量

$$\Phi = \iint_\Sigma \vec{F}\cdot d\vec{S} = \iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy$$

**物理意义：** 单位时间内穿过曲面 $\Sigma$（沿正侧方向）的流体体积。

- $\Phi > 0$：流体净流向正侧
- $\Phi < 0$：流体净流向负侧
- $\Phi = 0$：进出平衡

---

#### 三大公式的统一视角

| 公式 | 内容 | 维度 |
|------|------|------|
| **牛顿-莱布尼茨** | $\int_a^b f'\,dx = f(b)-f(a)$ | 1D：点 → 线 |
| **格林公式** | $\oint_L = \iint_D$（旋度→面积） | 2D：曲线 → 面 |
| **高斯公式** | $\oiint_\Sigma = \iiint_\Omega$（散度→体积） | 3D：曲面 → 体 |
| **斯托克斯公式** | $\oint_L = \iint_\Sigma$（旋度→曲面） | 3D：曲线 → 曲面 |

它们都是**广义斯托克斯定理**的特例：边界上的积分 = 内部某种"导数"的积分。

## 总结：方法选择速查表

### 二重积分

| 情况 | 推荐方法 |
|------|----------|
| 普通区域 | 直角坐标累次积分，**先画图** |
| 含 $x^2+y^2$，区域是圆/扇形/环 | 极坐标，记得乘 $r$ |
| 内层积分无初等原函数（如 $e^{x^2}$）| 交换积分次序 |
| 区域关于坐标轴对称 | 先判断被积函数奇偶性 |

### 三重积分

| 情况 | 推荐方法 |
|------|----------|
| 长方体、一般多面体 | 直角坐标三次积分 |
| 由上下曲面围成，截面好描述 | 投影法（先二后一） |
| 含 $x^2+y^2$，柱形/圆锥体 | 柱坐标，记得乘 $r$ |
| 球体、含 $x^2+y^2+z^2$ | 球坐标，记得乘 $\rho^2\sin\phi$ |

### 曲线积分

| 情况 | 推荐方法 |
|------|----------|
| 第一类（对弧长） | 参数化，$ds = \sqrt{x'^2+y'^2}\,dt$ |
| 第二类（对坐标），任意路径 | 参数化，注意方向 |
| 第二类，封闭曲线 | 格林公式 |
| 第二类，验证路径无关 | 检查 $P_y = Q_x$；无关则求势函数 |
| 第二类，空间曲线 | 斯托克斯公式转为曲面积分 |

### 曲面积分

| 情况 | 推荐方法 |
|------|----------|
| 第一类（对面积） | 投影，$dS = \sqrt{1+z_x^2+z_y^2}\,dxdy$ |
| 第二类（对坐标），不封闭 | 投影法，上侧取正号/下侧取负号 |
| 第二类，封闭曲面 | 高斯公式转为三重积分 |
| 第二类，非封闭但可补 | 补面后用高斯公式，再减补面 |

## 易错点汇总

**坐标换元：**
- 极坐标：$dA = r\,dr\,d\theta$，**那个 $r$ 永远不能忘**
- 柱坐标：$dV = r\,dr\,d\theta\,dz$，同上
- 球坐标：$dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta$，**两个因子都不能少**

**方向问题：**
- 第二类曲线积分：反向变号 $\int_{L^-} = -\int_L$
- 格林公式：边界正向 = 逆时针（区域在左手边）
- 高斯公式：边界曲面取**外侧**（法向量朝外）
- 斯托克斯公式：曲线方向和曲面侧满足**右手定则**
- 第二类曲面积分：上侧取正，下侧取负

**对称性：**
- 两件事缺一不可：① 区域对称 ② 被积函数是奇函数 → 积分才为零
- 只看区域对称不看函数是最常见的错误

**格林/高斯公式补面：**
- 补完面后，原积分 = 高斯公式结果 **减去** 补面上的积分（不是加！）
- 补面时要注意补面的方向与整体外侧一致

**路径无关：**
- 条件 $P_y = Q_x$ 只在**单连通域**内才能保证路径无关
- 若区域有洞（如去掉原点），需要额外判断

## 知识体系一览

```
一重积分（线）
    ↓ 升维到平面
二重积分（面） ← 直角坐标 / 极坐标 / 换元
    ↓ 升维到空间
三重积分（体） ← 直角坐标 / 柱坐标 / 球坐标

曲线积分：
    第一类（弧长，无方向）→ 参数化
    第二类（坐标，有方向）→ 参数化 / 格林公式（平面）/ 斯托克斯公式（空间）

曲面积分：
    第一类（面积，无方向）→ 投影
    第二类（坐标，有方向）→ 投影 / 高斯公式（封闭）

三大公式：格林（2D旋度）、高斯（3D散度）、斯托克斯（3D旋度）
    共同本质：边界上的积分 = 内部"导数"的积分
```
