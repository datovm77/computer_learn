# 高数(下) 补充：微分方程完整教程

> **写给你的话：** 微分方程不是什么新物种——它不过是一个含有未知函数及其导数的等式。你要做的事情，就是把藏在导数关系里的函数"猜出来"。如果说积分是"倒着走一步"，那解微分方程就是"倒着走整条路"。

---

## 第一章：基本概念

### 什么是微分方程？

包含自变量 $x$、未知函数 $y=y(x)$ 及其导数 $y', y'', \ldots$ 的等式，称为**微分方程**。

$$y' + 2y = e^x \qquad\qquad y'' + y = 0$$

- **阶：** 方程中出现的最高阶导数的阶数。$y'+2y=e^x$ 是一阶，$y''+y=0$ 是二阶。
- **解：** 使方程成恒等式的函数 $y(x)$。
- **通解：** 含有与方程阶数相同个数的**任意常数**的解。
- **特解：** 由初始条件确定了所有常数后的具体解。

> **类比：** 不定积分 $\int f\,dx = F(x)+C$ 含一个任意常数——它其实就是最简单的一阶微分方程 $y'=f(x)$ 的通解。

---

## 第二章：一阶微分方程

### 2.1 可分离变量方程

**形式：** $\frac{dy}{dx} = f(x)g(y)$

**核心思路：** 把含 $x$ 的移到一边，含 $y$ 的移到另一边，两边同时积分。

**步骤：**

$$\frac{dy}{g(y)} = f(x)\,dx \implies \int\frac{dy}{g(y)} = \int f(x)\,dx + C$$

**例 1：** 解 $y' = xy$

$$\frac{dy}{y} = x\,dx \implies \ln|y| = \frac{x^2}{2}+C_1 \implies y = Ce^{x^2/2}$$

（其中 $C=\pm e^{C_1}$，可以取任意非零常数；连同 $y=0$ 也是解，合并写为 $y=Ce^{x^2/2}$，$C$ 为任意常数。）

**例 2：** 解 $y'=\frac{y}{x}$，满足 $y(1)=2$

$$\frac{dy}{y}=\frac{dx}{x} \implies \ln|y|=\ln|x|+C_1 \implies y=Cx$$

代入初始条件：$2=C\cdot 1$，$C=2$。**特解：$y=2x$**

**例 3：** 解 $(1+x^2)\,dy = (1+y^2)\,dx$

$$\frac{dy}{1+y^2} = \frac{dx}{1+x^2} \implies \arctan y = \arctan x + C$$

即 $y = \tan(\arctan x + C)$。

> **易错：** 分离变量时，如果 $g(y)=0$ 的某个 $y_0$ 使分母为零，需要单独验证 $y\equiv y_0$ 是否也是解（通常是）。

---

### 2.2 齐次方程

**形式：** $y' = \varphi\!\left(\frac{y}{x}\right)$

**特征：** 方程右边可以写成 $y/x$ 的函数。

**识别方法：** 把右端的 $x,y$ 同时替换为 $tx, ty$，如果 $t$ 全部消去，就是齐次方程。

**解法：** 令 $u = \frac{y}{x}$，则 $y=ux$，$y'=u+xu'$。

代入后方程变为：$u + xu' = \varphi(u)$，即 $xu'=\varphi(u)-u$——这是关于 $u$ 和 $x$ 的可分离变量方程。

**例：** 解 $xy' = y + \sqrt{x^2+y^2}$

$$y' = \frac{y}{x}+\sqrt{1+\frac{y^2}{x^2}}$$

令 $u=y/x$，$y'=u+xu'$：

$$u+xu'=u+\sqrt{1+u^2} \implies xu'=\sqrt{1+u^2}$$

分离变量：$\frac{du}{\sqrt{1+u^2}}=\frac{dx}{x}$

$$\ln(u+\sqrt{1+u^2})=\ln|x|+C_1$$

$$u+\sqrt{1+u^2}=Cx \implies \frac{y}{x}+\sqrt{1+\frac{y^2}{x^2}}=Cx$$

$$y+\sqrt{x^2+y^2}=Cx^2$$

---

### 2.3 一阶线性方程

**形式：** $y' + P(x)y = Q(x)$

这是最重要的一阶方程类型。

**通解公式：**

$$\boxed{y = e^{-\int P\,dx}\left[\int Q\cdot e^{\int P\,dx}\,dx + C\right]}$$

**推导思路（常数变易法）：**

先解齐次方程 $y'+Py=0$：分离变量得 $y_0 = Ce^{-\int P\,dx}$。

然后把常数 $C$ 换成函数 $C(x)$（这就是"常数变易"），代回原方程求 $C(x)$。

**例 1：** 解 $y' + y = e^x$

$P=1$，$Q=e^x$。$\int P\,dx = x$。

$$y = e^{-x}\left[\int e^x\cdot e^x\,dx + C\right] = e^{-x}\left[\frac{1}{2}e^{2x}+C\right] = \frac{1}{2}e^x + Ce^{-x}$$

**例 2：** 解 $y' - \frac{2y}{x} = x^2$，$y(1)=0$

$P=-\frac{2}{x}$，$Q=x^2$。$\int P\,dx = -2\ln x$。$e^{\int P\,dx}=x^{-2}$。

$$y = x^2\left[\int x^2\cdot x^{-2}\,dx + C\right] = x^2(x+C) = x^3+Cx^2$$

初始条件 $y(1)=0$：$1+C=0$，$C=-1$。**特解：$y=x^3-x^2$**

**例 3（伯努利方程）：** 解 $y' + y = xy^2$

这不是标准线性方程（因为有 $y^2$）。**伯努利方程**的形式是 $y'+P(x)y=Q(x)y^n$。

先看特殊解：$y\equiv0$ 是解。对 $y\neq0$，做代换 $z=y^{1-n}=y^{-1}$，$z'=-y^{-2}y'$：

$$-z'+z=x \implies z'-z=-x$$

这是线性方程！$P=-1$，$Q=-x$：

$$z=e^x\left[\int(-x)e^{-x}\,dx+C\right]=e^x\left[(x+1)e^{-x}+C\right]=x+1+Ce^x$$

$$y=\frac{1}{z}=\frac{1}{x+1+Ce^x}$$

连同特殊解 $y\equiv0$。

---

### 2.4 全微分方程

**形式：** $P(x,y)\,dx + Q(x,y)\,dy = 0$，且 $\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}$

此时左边恰好是某函数 $u(x,y)$ 的全微分：$du = P\,dx+Q\,dy$。

通解就是 $u(x,y)=C$。

**求 $u$ 的方法：** 和求势函数相同（折线积分法）。

$$u(x,y) = \int_{x_0}^x P(t,y_0)\,dt + \int_{y_0}^y Q(x,s)\,ds$$

第二段积分中的 $x$ 是终点横坐标，表示沿折线先从 $(x_0,y_0)$ 走到 $(x,y_0)$，再走到 $(x,y)$。

**例：** 解 $(2xy+1)\,dx + (x^2+2y)\,dy = 0$

验证：$P_y=2x=Q_x$ ✓，是全微分方程。

$$u=\int_0^x(2ty_0+1)\,dt + \int_0^y(x^2+2s)\,ds$$

取 $y_0=0$：

$$u=\int_0^x 1\,dt + \int_0^y(x^2+2s)\,ds = x + x^2y + y^2$$

通解：$x^2y + y^2 + x = C$

## 第三章：可降阶的高阶方程

### 3.1 $y^{(n)}=f(x)$ 型

直接逐次积分 $n$ 次。

**例：** $y'''=e^x$

$$y''=e^x+C_1, \quad y'=e^x+C_1x+C_2, \quad y=e^x+\frac{C_1}{2}x^2+C_2x+C_3$$

### 3.2 $y''=f(x,y')$ 型（不显含 $y$）

令 $p=y'$，则 $y''=p'$，方程化为一阶方程 $p'=f(x,p)$。

**例：** 解 $xy''+y'=0$

令 $p=y'$：$xp'+p=0$，即 $(xp)'=0$，$xp=C_1$，$p=\frac{C_1}{x}$。

$$y=C_1\ln|x|+C_2$$

### 3.3 $y''=f(y,y')$ 型（不显含 $x$）

令 $p=y'$，把 $x$ 换成 $y$ 做自变量：$y''=p\frac{dp}{dy}$。

**例：** 解 $yy''+(y')^2=0$

令 $p=y'$：$y\cdot p\frac{dp}{dy}+p^2=0$，即 $yp'+p=0$（假设 $p\neq 0$，其中 $p'=\frac{dp}{dy}$）。

$$\frac{dp}{p}=-\frac{dy}{y} \implies p=\frac{C_1}{y} \implies \frac{dy}{dx}=\frac{C_1}{y}$$

$$y\,dy=C_1\,dx \implies \frac{y^2}{2}=C_1 x+C_2$$

常数解 $y\equiv C$ 也包含在 $C_1=0$ 的情形中。

## 第四章：二阶线性微分方程

### 4.1 基本理论

**一般形式：** $y'' + P(x)y' + Q(x)y = f(x)$

- $f(x)=0$：齐次方程
- $f(x)\neq 0$：非齐次方程

### 解的结构

**齐次方程 $y''+Py'+Qy=0$：**
- 如果 $y_1, y_2$ 是两个**线性无关**的解，则通解为 $y=C_1y_1+C_2y_2$

**非齐次方程 $y''+Py'+Qy=f$：**
- 通解 $=$ 对应齐次方程的通解 $+$ 非齐次方程的一个特解
- $$y = C_1y_1+C_2y_2+y^*$$

**叠加原理：** 如果 $y_1^*$ 是 $y''+Py'+Qy=f_1$ 的特解，$y_2^*$ 是 $y''+Py'+Qy=f_2$ 的特解，则 $y_1^*+y_2^*$ 是 $y''+Py'+Qy=f_1+f_2$ 的特解。

---

### 4.2 常系数齐次方程

**形式：** $y'' + py' + qy = 0$（$p,q$ 为常数）

**核心方法：特征方程**

$$r^2 + pr + q = 0$$

根据特征根 $r_1, r_2$ 的类型写出通解：

| 特征根类型 | 通解 |
|------------|------|
| 两个不等实根 $r_1\neq r_2$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| 两个相等实根 $r_1=r_2=r$ | $y = (C_1 + C_2 x)e^{rx}$ |
| 共轭复根 $r=\alpha\pm\beta i$ | $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ |

**例 1：** 解 $y''-5y'+6y=0$

特征方程：$r^2-5r+6=0$，$(r-2)(r-3)=0$，$r_1=2,r_2=3$。

通解：$y=C_1e^{2x}+C_2e^{3x}$

**例 2：** 解 $y''-4y'+4y=0$

特征方程：$r^2-4r+4=0$，$(r-2)^2=0$，$r=2$（重根）。

通解：$y=(C_1+C_2x)e^{2x}$

**例 3：** 解 $y''+2y'+5y=0$

特征方程：$r^2+2r+5=0$，$r=\frac{-2\pm\sqrt{4-20}}{2}=-1\pm 2i$。

$\alpha=-1$，$\beta=2$。通解：$y=e^{-x}(C_1\cos 2x+C_2\sin 2x)$

---

### 4.3 常系数非齐次方程：待定系数法

**形式：** $y'' + py' + qy = f(x)$

关键在于根据 $f(x)$ 的形式**猜特解的形式**，然后代入确定系数。

---

#### 类型一：$f(x) = P_m(x)e^{\lambda x}$

$P_m(x)$ 是 $m$ 次多项式，$\lambda$ 是常数。

**特解形式：**

$$y^* = x^k \cdot Q_m(x) \cdot e^{\lambda x}$$

其中 $Q_m(x)$ 是**待定** $m$ 次多项式，$k$ 的取值：

| $\lambda$ 与特征根的关系 | $k$ |
|---------------------------|-----|
| $\lambda$ 不是特征根 | $k=0$ |
| $\lambda$ 是单特征根 | $k=1$ |
| $\lambda$ 是重特征根 | $k=2$ |

> **口诀：** $k$ = $\lambda$ 作为特征根的**重数**。

**例 1：** 解 $y''-2y'-3y=3x+1$

特征方程：$r^2-2r-3=0$，$r_1=-1,r_2=3$。齐次通解：$C_1e^{-x}+C_2e^{3x}$。

$f(x)=(3x+1)e^{0\cdot x}$，$\lambda=0$ 不是特征根，$k=0$，$m=1$。

设 $y^*=ax+b$，代入：$0-2a-3(ax+b)=3x+1$

$$-3ax-(2a+3b)=3x+1 \implies a=-1,\; b=\frac{1}{3}$$

特解：$y^*=-x+\frac13$。

通解：$y=C_1e^{-x}+C_2e^{3x}-x+\frac{1}{3}$

**例 2：** 解 $y''-2y'+y=xe^x$

特征方程：$r^2-2r+1=0$，$r=1$（重根）。齐次通解：$(C_1+C_2x)e^x$。

$f(x)=xe^x$，$\lambda=1$ 是二重特征根，$k=2$，$m=1$。

设 $y^*=x^2(ax+b)e^x=(ax^3+bx^2)e^x$。

代入后（过程较长，逐步算）：

$y^*=(ax^3+bx^2)e^x$

$y^{*\prime}=(3ax^2+2bx)e^x+(ax^3+bx^2)e^x=(ax^3+(3a+b)x^2+2bx)e^x$

$y^{*\prime\prime}=(3ax^2+2(3a+b)x+2b)e^x+(ax^3+(3a+b)x^2+2bx)e^x$

$=(ax^3+(6a+b)x^2+(6a+4b)x+2b)e^x$

代入 $y''-2y'+y$：

$=[ax^3+(6a+b)x^2+(6a+4b)x+2b]e^x - 2[ax^3+(3a+b)x^2+2bx]e^x + [ax^3+bx^2]e^x$

$= [6ax+2b]e^x = xe^x$

所以 $6a=1$，$2b=0$，即 $a=\frac16$，$b=0$。

特解：$y^*=\frac{1}{6}x^3 e^x$。

通解：$y=(C_1+C_2x)e^x+\frac{1}{6}x^3e^x$

---

#### 类型二：$f(x) = e^{\lambda x}[P_l(x)\cos\omega x + P_n(x)\sin\omega x]$

**最常见特例：** $f(x)=e^{\alpha x}(A\cos\beta x + B\sin\beta x)$

特解形式：

$$y^* = x^k\cdot e^{\alpha x}(a\cos\beta x + b\sin\beta x)$$

$k$ 的取值：
- $\alpha+\beta i$ 不是特征根 → $k=0$
- $\alpha+\beta i$ 是特征根 → $k=1$

> **注意：** 即使 $f(x)$ 只含 $\cos$ 或只含 $\sin$，特解中**两者都要设**。

**例：** 解 $y''+y=\cos x$

特征方程：$r^2+1=0$，$r=\pm i$。$\alpha=0,\beta=1$，$\alpha+\beta i=i$ 是特征根，$k=1$。

设 $y^*=x(a\cos x+b\sin x)$。

$y^{*\prime}=(a\cos x+b\sin x)+x(-a\sin x+b\cos x)$

$y^{*\prime\prime}=2(-a\sin x+b\cos x)+x(-a\cos x-b\sin x)$

代入 $y^{*\prime\prime}+y^*$：

$=2(-a\sin x+b\cos x)+x(-a\cos x-b\sin x)+x(a\cos x+b\sin x)$

$=2(-a\sin x+b\cos x)=\cos x$

所以 $-2a=0$，$2b=1$，即 $a=0$，$b=\frac12$。

特解：$y^*=\frac{x}{2}\sin x$

通解：$y=C_1\cos x+C_2\sin x+\frac{x}{2}\sin x$

---

### 4.4 高阶常系数齐次方程（简述）

**$n$ 阶方程** $y^{(n)}+p_1y^{(n-1)}+\cdots+p_ny=0$ 的特征方程为：

$$r^n+p_1r^{n-1}+\cdots+p_n=0$$

| 特征根 | 对应通解项 |
|--------|------------|
| 单实根 $r$ | $Ce^{rx}$ |
| $k$ 重实根 $r$ | $(C_1+C_2x+\cdots+C_kx^{k-1})e^{rx}$ |
| 一对单复根 $\alpha\pm\beta i$ | $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$ |
| 一对 $k$ 重复根 $\alpha\pm\beta i$ | $e^{\alpha x}[(C_1+C_2x+\cdots+C_kx^{k-1})\cos\beta x+(D_1+D_2x+\cdots+D_kx^{k-1})\sin\beta x]$ |

**例：** 解 $y^{(4)}-y=0$

特征方程 $r^4-1=0$：$(r^2-1)(r^2+1)=0$，$r=1,-1,i,-i$。

通解：$y=C_1e^x+C_2e^{-x}+C_3\cos x+C_4\sin x$

## 第五章：欧拉方程

**形式：** $x^2y''+pxy'+qy=f(x)$（系数含 $x$ 的幂次）

**解法：** 令 $x=e^t$（即 $t=\ln x$），把变系数方程化为常系数方程。

关键代换关系：

$$xy'=\frac{dy}{dt}=Dy, \qquad x^2y''=D(D-1)y$$

其中 $D=\frac{d}{dt}$。

**例：** 解 $x^2y''-xy'+y=0$

令 $x=e^t$：$D(D-1)y - Dy + y = 0$，即 $(D^2-2D+1)y=0$。

特征方程 $r^2-2r+1=0$，$r=1$（重根）。

$$y=(C_1+C_2t)e^t = (C_1+C_2\ln x)\cdot x$$

## 第六章：应用举例

### 例 1（增长与衰减模型）

放射性物质的衰变：衰变速率与现有量成正比。

$$\frac{dN}{dt}=-\lambda N \implies N=N_0 e^{-\lambda t}$$

### 例 2（弹簧振动）

质量为 $m$ 的物体挂在弹簧上，弹力 $-kx$，阻尼 $-\mu x'$，外力 $F(t)$：

$$mx''+\mu x'+kx=F(t)$$

无阻尼自由振动（$\mu=0, F=0$）：$x''+\omega^2 x=0$（$\omega=\sqrt{k/m}$），通解 $x=A\cos(\omega t+\varphi)$。

### 例 3（电路方程）

$RLC$ 串联电路，电荷 $q$ 满足：

$$L\frac{d^2q}{dt^2}+R\frac{dq}{dt}+\frac{1}{C}q=E(t)$$

形式和弹簧振动完全相同——电感 ↔ 质量，电阻 ↔ 阻尼，电容倒数 ↔ 弹性系数。

## 总结速查表

| 方程类型 | 识别特征 | 解法 |
|----------|----------|------|
| 可分离变量 | $y'=f(x)g(y)$ | 分离后两边积分 |
| 齐次方程 | $y'=\varphi(y/x)$ | 令 $u=y/x$ |
| 一阶线性 | $y'+Py=Q$ | 公式法或常数变易法 |
| 伯努利 | $y'+Py=Qy^n$ | 令 $z=y^{1-n}$ 化为线性 |
| 全微分 | $P_y=Q_x$ | 求势函数 $u$，通解 $u=C$ |
| 可降阶 | 缺 $y$ 或缺 $x$ | 令 $p=y'$ 降阶 |
| 常系数齐次 | $y''+py'+qy=0$ | 特征方程 |
| 常系数非齐次 | $y''+py'+qy=f(x)$ | 齐次通解 + 待定系数特解 |
| 欧拉方程 | $x^2y''+pxy'+qy=f$ | 令 $x=e^t$ |

---

## 易错点

1. **可分离变量时别忘了 $g(y)=0$ 的特殊解。**
2. **一阶线性公式的积分因子是 $e^{\int P\,dx}$ 不是 $e^{P}$。**
3. **待定系数法中 $k$ 的取值：看 $\lambda$（或 $\alpha+\beta i$）作为特征根的重数。**
4. **特解中 $\cos$ 和 $\sin$ 必须同时出现**——即使 $f(x)$ 只含其中一个。
5. **欧拉方程代换后 $x^2y''=D(D-1)y$，不是 $D^2 y$。**
6. **非齐次方程通解 = 齐次通解 + 特解**——不能只写特解。
