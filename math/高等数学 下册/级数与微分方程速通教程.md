## §4.7 斯托克斯公式 & 场论

### 斯托克斯公式

$$\oint_L P\,dx+Q\,dy+R\,dz = \iint_\Sigma (R_y-Q_z)\,dydz+(P_z-R_x)\,dzdx+(Q_x-P_y)\,dxdy$$

- $L$ 与 $\Sigma$ 正侧满足**右手定则**
- 格林公式是 $z=0$ 平面的特例

### 散度 · 旋度 · 通量

| 概念 | 公式 | 物理意义 |
|------|------|----------|
| 散度 | $\text{div}\vec{F}=P_x+Q_y+R_z$ | 涌出量（源/汇） |
| 旋度 | $\text{rot}\vec{F}=(R_y-Q_z,\;P_z-R_x,\;Q_x-P_y)$ | 旋转强度 |
| 通量 | $\Phi=\iint_\Sigma\vec{F}\cdot d\vec{S}$ | 穿过曲面的流量 |

### 三大公式速查

| 公式 | 转化方向 | 算子 |
|------|----------|------|
| 格林 | 平面曲线 → 平面区域 | $Q_x-P_y$ |
| 高斯 | 封闭曲面 → 空间体 | $P_x+Q_y+R_z$ |
| 斯托克斯 | 空间曲线 → 曲面 | 旋度 |

### 恒等式

$$\text{div}(\text{rot}\,\vec{F})=0,\qquad\text{rot}(\nabla u)=\vec{0}$$

### 例题

$\oint_L z\,dx+x\,dy+y\,dz$，$L$ 为平面 $x+y+z=1$ 第一卦限三角形边界，从 $z$ 轴正向看逆时针。

**解：** 旋度 $=(1,1,1)$（常向量）。$\vec{n}=\frac{1}{\sqrt3}(1,1,1)$，三角形面积 $S=\frac{\sqrt3}{2}$。

$$\oint_L=(1,1,1)\cdot\frac{1}{\sqrt3}(1,1,1)\cdot\frac{\sqrt3}{2}=\frac32$$

> 旋度为常向量：结果 = 旋度 · 单位法向量 × 面积。

## §5.1 常数项级数

### 核心定义

- 收敛 $\Leftrightarrow$ 部分和 $S_n$ 有极限
- **必要条件：** $\sum u_n$ 收敛 $\Rightarrow$ $u_n\to 0$（反之不然）

### 重要级数

| 级数 | 结论 |
|------|------|
| $\sum q^n$ | $\|q\|<1$ 收敛（和 $=\frac{1}{1-q}$），$\|q\|\geq1$ 发散 |
| $\sum\frac{1}{n^p}$ | $p>1$ 收敛，$p\leq1$ 发散 |
| $\sum\frac{1}{n}$ | 发散（调和级数） |

### 例题

$\sum_{n=1}^\infty\frac{2^n+3^n}{6^n}$：拆为 $\sum(\frac13)^n+\sum(\frac12)^n=\frac12+1=\frac32$。

## §5.2 审敛法（一）：正项级数

### 五大方法

| 方法 | 结论 | 适用 |
|------|------|------|
| **比较法** | 大收敛→小收敛 | 能直接放缩 |
| **极限比较法** | $\lim\frac{u_n}{v_n}=l\in(0,\infty)$→同敛散 | 分式型 |
| **比值法** | $\rho<1$收敛，$>1$发散 | 含 $n!$、$a^n$ |
| **根值法** | $\rho<1$收敛，$>1$发散 | 含 $n$ 次方 |
| **积分法** | $\sum f(n)$ 与 $\int_1^\infty f(x)dx$ 同敛散 | 比值/根值失效时 |

> $\rho=1$ 时比值/根值法**失效**。

### 例题

$\sum\frac{n^2\cdot 2^n}{3^n}$：比值法 $\rho=\frac23<1$，**收敛**。

## §5.2 审敛法（二）：交错级数

### 莱布尼茨判别法

$\sum(-1)^{n-1}u_n$：① $u_n$ 单调递减 ② $u_n\to 0$ → **收敛**

余项：$|r_n|\leq u_{n+1}$

### 绝对收敛与条件收敛

- $\sum|u_n|$ 收敛 → **绝对收敛**
- $\sum u_n$ 收敛但 $\sum|u_n|$ 发散 → **条件收敛**

**流程：** 先看绝对值级数 → 再看原级数

### 例题

$\sum\frac{(-1)^n\ln n}{n}$：绝对值 $\sum\frac{\ln n}{n}$ 发散（比较调和级数）；原级数莱布尼茨收敛。**条件收敛**。

## §5.3 幂级数（一）：收敛半径与收敛域

### 收敛半径

$$R = \frac{1}{\lim\left|\frac{a_{n+1}}{a_n}\right|} = \frac{1}{\lim\sqrt[n]{|a_n|}}$$

- $|x|<R$：绝对收敛
- $|x|>R$：发散
- $|x|=R$：单独讨论

### 求收敛域步骤

1. 求 $R$
2. 写开区间 $(x_0-R,x_0+R)$
3. 逐个判断端点

### 例题

$\sum\frac{(x-1)^n}{n\cdot 2^n}$：$R=2$，区间 $(-1,3)$。$x=3$：$\sum\frac1n$ 发散；$x=-1$：$\sum\frac{(-1)^n}{n}$ 收敛。**收敛域 $[-1,3)$**。

## §5.3 幂级数（二）：和函数

### 核心技术

| 通项特征 | 方法 |
|----------|------|
| 分子含 $n$ | 逐项求导 |
| 分母含 $n$ | 逐项积分 |

### 万能起点

$$\sum x^n=\frac{1}{1-x},\quad\sum nx^n=\frac{x}{(1-x)^2},\quad\sum\frac{x^n}{n}=-\ln(1-x)$$

### 例题

$S(x)=\sum\frac{x^n}{n+1}$（$|x|<1$）：

$\sum\frac{x^{n+1}}{n+1}=-\ln(1-x)-x$，故 $S(x)=\frac{-\ln(1-x)-x}{x}$（$x\neq 0$），$S(0)=0$。

## §5.4 函数的幂级数展开

### 常用展开（必背）

| 函数 | 展开式 | 收敛域 |
|------|--------|--------|
| $e^x$ | $\sum\frac{x^n}{n!}$ | $(-\infty,+\infty)$ |
| $\sin x$ | $\sum\frac{(-1)^n x^{2n+1}}{(2n+1)!}$ | $(-\infty,+\infty)$ |
| $\cos x$ | $\sum\frac{(-1)^n x^{2n}}{(2n)!}$ | $(-\infty,+\infty)$ |
| $\ln(1+x)$ | $\sum\frac{(-1)^{n-1}x^n}{n}$ | $(-1,1]$ |
| $\frac{1}{1-x}$ | $\sum x^n$ | $(-1,1)$ |
| $(1+x)^\alpha$ | $\sum\binom{\alpha}{n}x^n$ | $(-1,1)$ |
| $\arctan x$ | $\sum\frac{(-1)^n x^{2n+1}}{2n+1}$ | $[-1,1]$ |

### 间接展开方法

1. **代换：** $e^{-x^2}$ → 令 $x\to-x^2$
2. **求导：** $\frac{1}{(1-x)^2}=(\frac{1}{1-x})'$
3. **积分：** $\ln(1+x)=\int_0^x\frac{1}{1+t}dt$
4. **部分分式 + 逐项展开**

### 例题

$\frac{x}{1+x^2}$：在 $\frac{1}{1-t}=\sum t^n$ 中令 $t=-x^2$，得 $\frac{1}{1+x^2}=\sum(-1)^n x^{2n}$，乘 $x$：

$$\frac{x}{1+x^2}=\sum(-1)^n x^{2n+1},\quad |x|<1$$

## §5.5 傅里叶级数

### 傅里叶系数（周期 $2\pi$）

$$a_n=\frac{1}{\pi}\int_{-\pi}^\pi f(x)\cos nx\,dx,\quad b_n=\frac{1}{\pi}\int_{-\pi}^\pi f(x)\sin nx\,dx$$

$$f(x)=\frac{a_0}{2}+\sum_{n=1}^\infty(a_n\cos nx+b_n\sin nx)$$

### 收敛值

- 连续点：$f(x)$
- 间断点：$\frac{f(x^-)+f(x^+)}{2}$

### 奇偶简化

- 偶函数：只有余弦项（$b_n=0$）
- 奇函数：只有正弦项（$a_n=0$）

### 周期 $2l$

$\pi\to l$，$nx\to\frac{n\pi x}{l}$，积分区间 $[-\pi,\pi]\to[-l,l]$。

### 例题

$f(x)=|x|$（$-\pi\leq x\leq\pi$，周期 $2\pi$）：偶函数，$b_n=0$。

$$a_0=\pi,\quad a_n=\frac{2((-1)^n-1)}{n^2\pi}$$

$n$ 偶时 $a_n=0$，$n$ 奇时 $a_n=-\frac{4}{n^2\pi}$。

$$|x|=\frac\pi2-\frac4\pi\sum_{k=0}^\infty\frac{\cos(2k+1)x}{(2k+1)^2}$$

## 补充：微分方程

### 一阶方程

| 类型 | 特征 | 解法 |
|------|------|------|
| 可分离变量 | $y'=f(x)g(y)$ | 分离后积分 |
| 齐次 | $y'=\varphi(y/x)$ | 令 $u=y/x$ |
| 一阶线性 | $y'+Py=Q$ | $y=e^{-\int P}\left[\int Qe^{\int P}dx+C\right]$ |
| 伯努利 | $y'+Py=Qy^n$ | 令 $z=y^{1-n}$ |
| 全微分 | $P_y=Q_x$ | 求势函数 |

### 二阶常系数齐次

$y''+py'+qy=0$，特征方程 $r^2+pr+q=0$：

| 根的类型 | 通解 |
|----------|------|
| 不等实根 $r_1,r_2$ | $C_1e^{r_1x}+C_2e^{r_2x}$ |
| 重根 $r$ | $(C_1+C_2x)e^{rx}$ |
| 复根 $\alpha\pm\beta i$ | $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$ |

### 二阶常系数非齐次（待定系数法）

通解 = 齐次通解 + 特解。

**$f=P_m(x)e^{\lambda x}$：** 设 $y^*=x^k Q_m(x)e^{\lambda x}$，$k$ = $\lambda$ 作为特征根的重数。

**$f=e^{\alpha x}(A\cos\beta x+B\sin\beta x)$：** 设 $y^*=x^k e^{\alpha x}(a\cos\beta x+b\sin\beta x)$，$k=0$（$\alpha+\beta i$ 非特征根）或 $k=1$（是特征根）。

### 可降阶

- 缺 $y$：令 $p=y'$，$y''=p'$
- 缺 $x$：令 $p=y'$，$y''=p\frac{dp}{dy}$

### 欧拉方程

$x^2y''+pxy'+qy=f(x)$：令 $x=e^t$，$xy'=Dy$，$x^2y''=D(D-1)y$

### 例题

解 $y''-3y'+2y=xe^x$。

特征方程 $r^2-3r+2=0$，$r_1=1,r_2=2$。齐次通解：$C_1e^x+C_2e^{2x}$。

$\lambda=1$ 是单特征根（$k=1$，$m=1$）。设 $y^*=x(ax+b)e^x$。代入比较系数：$a=-\frac12$，$b=-1$。

**通解：** $y=C_1e^x+C_2e^{2x}+(-\frac{x^2}{2}-x)e^x$

> $k$ 的确定：$\lambda$ 不是特征根 → $k=0$；单根 → $k=1$；重根 → $k=2$。

## 全局易错点速查

| 易错点 | 正确做法 |
|--------|----------|
| $u_n\to 0$ 就收敛？ | 错！只是必要条件 |
| 比值法 $\rho=1$ | 无法判断，换方法 |
| 幂级数端点 | 必须逐个代入单独判断 |
| 缺项级数求 $R$ | 不能直接用系数公式，对通项用比值法 |
| 傅里叶间断点 | 取左右极限的平均 |
| 待定系数法 $k$ | 看 $\lambda$ 是几重特征根 |
| 特解只设 $\cos$ 不设 $\sin$ | 错！两者必须同时设 |
| 斯托克斯方向 | 曲线与曲面法向量满足右手定则 |
