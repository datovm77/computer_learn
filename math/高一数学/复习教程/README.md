## 怎么用

- **一轮**：只读每章 §1，把 §0 的地图抄一遍当目录。
- **二轮**：做 §2 的例题，先盖住解答自己写，再对 §3 易错清单。
- **三轮**：限时做 §5 自测，答案在文件末尾。

## 校验说明

两轮并发写作 + 并发校验，共复算约 160 道题，修正 40 余处。改动记录在各章 §6。几处值得单独记住的坑：

- **严格 vs 非严格恒成立**：`f(x)>0` 恒成立要 $\Delta<0$，`$\ge 0$` 恒成立才要 $\Delta\le0$；且 $a$ 的符号不能漏（第2章例12、自测4）。
- **不动点 $a^x=x$**：$0<a<1$ 时**有**唯一交点（$0<x<1$ 内），临界值 $e^{1/e}\approx1.4447$ 只管 $a>1$ 一侧（第4章 §1）。
- **辅助角 $\varphi$ 要定象限**：$A\sin\varphi=a$、$A\cos\varphi=b$，只看 $\tan\varphi=b/a$ 会错（$A$ 必须为正，第5章）。
- **$\varphi$ 多解**："最小正 $\varphi$"和"题给区间内的解"是两回事，$\omega\to-\omega$ 时 $\varphi\to\pi-\varphi$（第5章）。
